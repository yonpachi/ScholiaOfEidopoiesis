## 地形と歯車の違い — [決定] 2026-07-20

どちらも **タイムラインのカウント** に紐づくが、発動タイミングが異なる。

| | **地形** | **歯車** |
|---|----------|----------|
| **発動単位** | カウント上の **区間・居場所** | カウント **到達の瞬間** |
| **持続** | 対象がそのカウントにいる **間ずっと** | **一度だけ** |
| **イメージ** | 毒床・炎床（立っている間ずっと影響） | 起爆装置（誰かが到達した瞬間に発動） |
| **v2 の軸** | 持続（範囲・場） | 予約（タイミング指定） |

```
タイムライン:  ...──[8]──[7]──[6]──[5]──...

地形:   カウント6に効果を置く → 6にいる間、継続
歯車:   カウント6に仕掛け   → 6に到達した瞬間に一回のみ
```

**効果の中身**は系統ごとに変えられる。**差は主に「いつ・何回効くか」**。

011 の「特定カウントをエリア指定」（時限爆弾・フィールド毒ガス等）は、歯車（到達時）と地形（滞在中）の両方に接続しうる。

## 戦闘メインでの責務カバー（現状の見立て）

責務定義（014 継承）: ①HP回復 ②直接ダメ ③防護 ④継続デバフ ⑤位置操作 ⑥スタン

### おおむねカバーできている

- 即時ダメ・単体回復（薬・爆弾）
- 継続デバフ（地形・薬・生体模倣）
- カウント操作（料理・地形・歯車）
- 条件反応（札）※新規採用で穴を埋める
- 召喚・身代わり等（召喚）※新規採用で穴を埋める
- ルール弄り（ガラクタ）
- 自己強化（生体模倣）

### まだ薄い（系統定義時に要検討）

| 不足 | メモ |
|------|------|
| **③ 防護専門** | 障壁・装甲・回避の **柱** になる系統がない。旧・印符の役割 |
| **⑤ エンゲージ操作** | タイムラインのカウント操作とは別。**引き付け** は特に未担当。ノックバックは爆弾想定 |
| **広域・複数味方支援** | 単体偏重。料理・札・召喚のレシピで補うか |
| **状態解除（浄化）** | どの系統も未明示。薬の1レシピで足りる可能性 |
| **離脱支援** | 煙幕・回避強化等。③とセットで検討 |

### 意図的に専門系統を作らない

- 連鎖・蓄積（煩雑さ回避）
- デッキ操作（各系統に分散）

**銃・ガラクタ** は器用貧乏／ルール改変で **弱くカバー** しうるが、パーティの柱にはなりにくい設計。

## 系統同士の境界（定義時に参照）

| ペア | 切り分けの軸 |
|------|-------------|
| 地形 ↔ 歯車 | 居る間ずっと vs 到達瞬間のみ |
| 薬 ↔ 札 | 即時に効く vs 条件成立時に発動 |
| 爆弾 ↔ 歯車 | 今すぐ範囲 vs 未来のカウントに仕掛ける |
| 料理 ↔ 歯車／地形 | 対象のカウントを **動かす** vs 場に効果を **置く** |
| 生体模倣 ↔ 召喚 | 自分が変わる vs 別个体が場にいる |
| 銃 ↔ 他全部 | 何でも弱い vs 何かに強い |

## 系統ごとに決める項目（テンプレ・未記入）

各系統の詳細はこのテンプレに沿って **これから** 埋める。

```
【系統名】
■ 一言でいうと
■ 戦闘での主な働き（1〜3個）
■ 得意な責務（①〜⑥）
■ 苦手・やらないこと
■ タイミングの型（即時／カウント持続／到達時一回／条件反応／召喚維持 等）
■ 対象の型（単体／範囲／自分／味方／敵／場）
■ 一長一短（代償・クセ）
■ デッキ操作（なし／弱い／特定レシピのみ）
■ 探索（後日・各系統共通方針に沿って）
■ 他系統との境界
```
