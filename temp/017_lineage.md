## 装備系統 — [見送り] 2026-07-20

11本目として検討したが、**通常の錬金系統の枠組みには入れない**。

### 見送り理由

- 属性・間合・起動時効果・素材タグ紐付け等、**カスタマイズ次元が他系統と比べて圧倒的に多い**
- 1系統の PC が抱えるには大きすぎる。**サプリ級の別メカニクス** になりうる
- 各 PC ごとに武器を作るには素材・タグと個別要件の紐付けが必須 → **1人の PC がパンク** しやすい

### 将来の扱い

| 項目 | 内容 |
|------|------|
| 系統 | **錬金系統には含めない** |
| 入手 | **依頼で作る**／**街の鍛冶屋** を訪れる等の街務 |
| カスタム軸 | 属性・間合・起動時効果・素材タグの紐付け |

### β版

- **武器・防具のカスタマイズは見送り**
- **固定の装備データ** を用意（初期作のみ回す想定）
- キャラ作成時の初期装備選択は維持（`draft/rules/character.md`）
- **③防護** は固定装備が本体。消耗品は補助

## 地形と歯車の違い — [決定] 2026-07-20

| | **地形** | **歯車** |
|---|----------|----------|
| **発動単位** | カウント上の **区間・居場所** | カウント **到達の瞬間** |
| **持続** | 対象がそのカウントにいる **間ずっと** | **一度だけ** |
| **イメージ** | 毒床・炎床 | 起爆装置 |
| **v2 の軸** | 持続（範囲・場） | 予約（タイミング指定） |

```
タイムライン:  ...──[8]──[7]──[6]──[5]──...

地形:   カウント6に効果を置く → 6にいる間、継続
歯車:   カウント6に仕掛け   → 6に到達した瞬間に一回のみ
```

**効果の中身**は系統ごとに変えられる。**差は主に「いつ・何回効くか」**。
