### 専門として選べる系統（7）× 各〜4本 ≒ 28本

| # | 系統 | 動きの核 | 触れる面 |

### β7の役割分担（やることが被らないか）

| 系統 | プレイヤーが考えること | 他と違う点 |
|------|------------------------|------------|
| **薬** | 今この単体をどう直す／削るか | 即時・単体。**短間合**（系統デメリット） |
| **爆弾** | どこに投げて範囲をどう崩すか | 即時（または時限）の範囲物理。味方巻き込み |
| **料理** | 強効果と手番犠牲のトレード | カウント進行が本体の代償 |
| **造園** | どのカウントをどう占有するか | **居る間ずっと**の場。床・壁 |
| **歯車** | どの条件で仕掛けが発火するか | **条件待ち**の機械。時限爆弾ではない |
| **召喚** | 何を場に残しどう働かせるか | **別個体**が残る。自己バフして殴る、ではない |
| **変異** | 誰のデータをどう書き換えるか | **ルール・パラメータの改変**。即時の増減だけではない |

**薄い／近いが許容する差**

- 爆弾の時限 vs 歯車の条件 … 「時間経過だけ」は爆弾、「被ダメ・移動などゲーム内イベント」は歯車
- 造園のバフ床 vs 料理のバフ … 場に乗る／単体に食べさせる＋カウント進行
- 薬の毒 vs 造園のダメ床 … 単体即時付与／カウント滞在
- 料理の強バフ vs 変異の巨大化 … 一時的な有利効果＋カウント進行／**データそのもの**の書き換え＋両刃

## 装備系統 — [見送り] 2026-07-20

11本目として検討したが、**通常の錬金系統の枠組みには入れない**。

### 見送り理由

- 属性・間合・起動時効果・素材タグ紐付け等、**カスタマイズ次元が他系統と比べて圧倒的に多い**
- 1系統の PC が抱えるには大きすぎる。**サプリ級の別メカニクス** になりうる
- 各 PC ごとに武器を作るには素材・タグと個別要件の紐付けが必須 → **1人の PC がパンク** しやすい

### 将来の扱い

| 項目 | 内容 |
|------|------|
| 系統 | **錬金系統には含めない** |
| 入手 | **依頼で作る**／**街の鍛冶屋** を訪れる等の街務 |
| カスタム軸 | 属性・間合・起動時効果・素材タグの紐付け |

### β版

- **武器・防具のカスタマイズは見送り**
- **固定の装備データ** を用意（初期作のみ回す想定）
- キャラ作成時の初期装備選択は維持（`draft/rules/character.md`）

## 造園と歯車の違い — [改定] 2026-07-31

旧決定（2026-07-20）の「造園＝滞在／歯車＝到達時一発」は、**歯車を時限爆弾化する**ため爆弾・造園と差が薄くなる問題があった。

| | **造園** | **歯車**（新） | **爆弾** |
|---|----------|----------------|----------|
| 核 | カウント上の **場**（居る間ずっと） | **条件が揃ったら動く機械** | **いま／時限で爆発・煙・押し** |
| 持続 | 滞在中 | 条件待ち → 発動時は一回が多い | 即時 or 導火線後に一回 |
| やらない | 条件割り込みの主役 | 滞在床・純粋な時限爆弾 | 複雑な条件反応の主役 |

```
造園:  カウント6に床・壁 → 6にいる間、継続
爆弾:  今すぐ範囲に効く／導火線で遅れて効く
歯車:  「被ダメした時」「移動した時」等の条件でバネが外れる
時間軸操作（将来）: カウントそのものを飛ばす・入れ替える等
```

## 対象範囲 × 効果内容（たたき台）— 2026-07-28

**戦闘メイン** の理解。未確定部分は各系統の正式定義で詰める。

### 一覧

| 系統 | 主な対象範囲 | 主な効果内容 | タイミング |
|------|-------------|-------------|-----------|
| **薬** | **単体**（自分／味方／敵） | 即時 **回復** or **ダメージ＋デバフ** | 即時 |
| **爆弾** | **小範囲** | **直接ダメ**／**デバフ**／**スタン値**／カウント操作？ | 即時 |
| **料理** | **単体**（味方・敵） | **高回復 or 強バフ**（代償：**カウント進行**） | 即時＋カウント副作用 |
| **造園** | **特定カウント上の対象** | **継続ダメ**／**判定影響デバフ**／壁・足場 | **滞在中ずっと** |
| **歯車** | **特定カウント到達時の対象** | 一回限りの **ダメ**／**デバフ**／**スタン** 等 | **到達時のみ** |
| **銃** | **単体〜小範囲**（弾・パーツ次第） | **全責務に対応可**だが **効果量は常に弱い** | 即時 |
| **ガラクタ** | **主に自分**（一部は周囲） | **ルール改変**（巨大化・縮小・透明・常時燃焼等） | 即時〜短持続 |
| **生体模倣** | **主に自分**（一部は単体敵） | **自己バフ**／**毒付与**／能力獲得 | 即時〜戦闘中持続 |
| **札** | **貼付・設置した対象** | 条件成立時に **回復**／**ダメ**／**デバフ**／**防護** 等 | **反応** |

## β・料理レシピ方針 — [方向合意] 2026-07-31

**前提（系統の核）**

- 本体は **強めの有利効果**（回復・バフ系）
- **基本代償:** 対象のカウントを強制で進める
- **副次デバフ:** 「満腹」「渇き」などの食・飲関連印記、および足止め的な弱デバフは **本体効果にしない**。料理を使用したときに付く副次として扱う
- 敵にも使える。本体が有利でも「カウント進行＋副次デバフ」で両刃になる

**β用・4種類（効果の方向のみ。名称・数値は未）**

| # | 本体効果の方向 | 備考 |
|---|----------------|------|
| 1 | **強回復** | 単体を大きく回復。カウント強制進行。**最大HP上昇は変異へ移管**（2026-08-05） |
| 2 | **攻撃寄り強バフ** | `<攻撃力上昇：{品質/2}>`。攻撃解決後 −1。進行＋次番。一旦 2026-08-17 |
| 3 | **防御寄り強バフ** | `<装甲：{品質×2}>`。追加HP。進行＋次番。一旦 2026-08-17 |
| 4 | **継続回復** | `<再生：{品質/2}>`。手番開始時に回復して −1。進行＋次番。一旦 2026-08-17 |

各レシピとも **カウント+2（使用時）** と **次手番開始時の本体**。満腹等の副次は一旦なし。

**共通データ欄（仮・2026-08-14）:** `発動: 次番`／`間合: 0~2`／進行 **+2（使用時）**／本体は **次の手番開始時**／対象＝単体。満腹なし。

**採用しない／後回し（ブレスト由来）**

- 満腹・足止めを **本体** にした妨害専用レシピ（副次も一旦本文から外す）
- 上限超えHPなど重い例外ルール（β後でも可）
- 食べるたび強度積み上げ（ガラクタと役割分担が必要なら寄せる）

**次:** 料理β4本文は018で仮止め。残系統は召喚／変異

## β・薬レシピ方針 — [方向合意] 2026-07-31

**料理との差**

| | 薬 | 料理 |
|---|----|------|
| 回復 | **即時**（効果量は料理と同等級も可） | 強い／継続＋カウント進行 |
| 間合 | **`0`**（塗布・打ち込み） | **`0~2`**（仮。多少届く） |
| デバフ | **本体になりうる**（毒など） | 満腹等は副次のみ |
| 代償 | 間合の短さ（位置取りが必要） | カウント強制進行 **+2**（仮） |

**系統の一長一短**

- **長所:** 単体への即時効果（回復・毒・火力・状態安定）を **手軽に** 出せる
- **短所:** **間合が短い**。届くのは **同カウントのみ**（β暫定: `間合: 0`）

**β用・4種類（効果の方向のみ。名称・数値は未）**

| # | 本体効果の方向 | 備考 |
|---|----------------|------|
| 1 | **即時回復** | 単体。回復量＝**品質**（係数なし）。戦闘不能解除は含めない |
| 2 | **印記強度の減少** | 対象の **強度付き印記すべて** を {品質/10} 減らす。0で即時除去（解除効果ではない）。障壁等も対象 |
| 3 | **毒付与** | `<毒：{品質/10}>`（本文記法 2026-08-14）。tick・減衰・再付与は [012](012_marks_tags.md) 議題2 |
| 4 | **単体火力（即時ダメージ）** | **デバフなし**で一旦進める。数値・体感が微妙ならデバフ付与を再検討 |

**共通データ欄（β暫定）:** `発動: 即時`／`間合: 0`（同カウントのみ）／`対象: 単体` — 4本とも同型

**次:** 薬β4本文は018で仮止め。残系統は料理／召喚／変異
