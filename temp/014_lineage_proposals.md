## 4. 設計上の共通論点

各AIが繰り返し触れた設計上の考え方。

### 4-1. 1系統で一人でも戦えるか

- 全員が武器を持つため②は錬金なしで確保済み
- ①回復か③防護のどちらかがあれば最低限の自走が成立
- ①③両方ない系統（焔薬・縛索など）は補完が必要

補完の選択肢：
1. 系統内に防護レシピを1本追加（煙幕弾→`<回避>`付与など）
2. 汎用レシピで最低限の回復を担保
3. 「2人以上向け」と明記してソロ非推奨にする

### 4-2. 同系統2人でも差がつくか

レシピ選択で自然に分かれる。差をつける軸：

| 軸           | 内容                                              |
| ------------ | ------------------------------------------------- |
| 対象         | 自分／単体味方／単体敵／範囲                      |
| タイミング   | 即時 vs 継続 vs 設置後発動                        |
| 消費 vs 想成 | 完成品を消費する vs マナを払って想成する          |
| 重量・段階   | 軽行動で小さく使う vs 重行動で強く使う            |
| 条件付き     | 確実に効く vs 条件を満たすと強い                  |

### 4-3. 1系統選択 vs 2系統選択

複数のAIが「基本は1系統専門で正解」と評価。  
2系統にすると弱点が埋まりすぎて系統の個性が薄れる。  
他系統のレシピ習得は「成長後の特別オプション（副専攻）」として後半に置くのが推奨。

### 4-4. ⑤位置操作の希少性

⑤ノックバックを◎にできるのは焔薬・縛索など少数。  
タイムラインCTとの相性が特に高く、「敵の行動順を操作する」専門系統の強みになる。  
引き付け（前方KB）を実装できるのは縛索のみという案も出ている。

#### 1. 薬（やく）

**品物イメージ：** 瓶詰め液薬・固形薬。飲む・かける・投げる。  
**担当責務：** ①◎ ③○ ④○  
**戦い方：** 自分や味方を回復しながら、毒で敵を削る**持久戦型**。

| レシピ | 責務 | 効果方向性              |
| ------ | ---- | ----------------------- |
| 回復薬 | ①    | 自己・即時大回復        |
| 再生薬 | ①    | 自己・`<再生>`で毎ラウンド小回復 |
| 毒薬   | ④    | `<毒>`付与              |
| 硬化薬 | ③    | `<障壁>`付与            |

**弱点：** ⑤位置操作・⑥スタンがない。相手の行動を止める手段がなく、消耗戦向き。
