**未決:**

## 開示: 基本ダイス

判定ではまず **d10（闇）** を使う。必要に応じて **属性マナ** に対応する **属性ダイス** をプールに追加して振る。

| 属性 | ダイス | 反応条件 | 反応効果 |
| ---- | ------ | -------- | -------- |
| 火 | d4 | 3以上 | **延焼** — 自身を4にし、d4を1個追加して振る |
| 土 | d6 | 6 | **変動** — 他ダイス1個を循環±1または±2 |
| 風 | d8 | 8 | **旋回** — 他ダイス1個を半回転 |
| 水 | d20 | 20 | **流転** — 他ダイス1個を振り直す |
| 闇 | d10 | 10 | **覚醒** — 他ダイス1個を裏返す |
| 光 | d12 | 12 | **昇華** — 他ダイス1個を最大値にする |

- 属性はタグ・印記の表記（`<火>` `<土>` など）と対応
- ダイスプールは原則 **d10（闇）を1個足した状態から** 構築
- **ベース d10 ＝ 闇 d10**（属性・反応条件・反応効果は同一）

**決定事項（プール構築・錬金時の典型）:**

- 錬金時: **レシピに指定された分** だけ属性ダイスを追加して振る
- 錬金時のダイス判定: **マナ消費なし**（マナ消費の有無は錬金別ログ）

**002 では扱わない:**

- 探索時のダイス使用制限（未設計）
- 戦闘でのダイス使用の可否（未確定）

## 開示: 用語

| 用語 | 定義 |
|------|------|
| **循環** | 出目は環状に数える。最大値の次は1、1の前は最大値 |
| **未反応 / 反応済み** | 各ダイスはどちらか一方の状態 |
| **反応可能** | 未反応かつ反応条件を満たしている |
| **循環±k** | 出目を k 進める、または k 戻す |
| **半回転** | 面数 N のダイスを、循環＋(N÷2) だけ進める |
| **裏返す** | 出目を反対側にする（N＋1−出目）。d4 なら 1↔4、2↔3 |
| **振り直す** | そのダイスをもう一度振り、出目を置き換える |
| **澱み** | 読み替え後の値が **1以下** のダイスを **−1** として扱う |

**決定事項:**

- 反応効果で出目が変わっても、**未反応 / 反応済み** の状態は変わらない
- 効果の対象選択時、特に指定がなければ未反応・反応済みを問わず選べる
- **反応そのものは任意** — 反応可能でも適用しなくてよい
- **反応するダイス・効果対象・土の ±1/±2** — いずれも **プレイヤー任意**

## 開示: 判定の流れ

### 1. ダイス決定

ダイスプールにダイスを追加し、今回の判定で振るダイスを決める。

### 2. ダイスロール

プール内のダイスをすべて振り、すべて **未反応** にする。

### 3. 反応

反応可能なダイスがあり、かつプレイヤーが反応を選ぶ限り、次を繰り返す。

1. 反応可能なダイスを1つ選ぶ（**任意**。選ばなければ反応フェーズ終了）
2. そのダイスの反応効果を適用（対象・土の ±1/±2 も **任意**）
3. そのダイスを **反応済み** にする
4. 新たに反応条件を満たした未反応ダイスがあれば、反応可能になる

**連鎖例:** 火（延焼）で追加された d4 が反応条件を満たせば、さらに反応可能（適用するかは任意）。

### 4. 達成値決定

各ダイスの寄与は **次の2段階** で求め、合計を **達成値** とする。

#### （1）出目の読み替え

| ダイス | 換算 |
| ------ | ---- |
| 水（d20） | **⌊出目 ÷ 2⌋**（端数切り捨て） |
| それ以外 | 出目そのまま |

#### （2）澱み

この判定で **澱みが発生する** 場合、読み替え後の値が **1以下** のダイスは **−1** として扱う。

> d20 の出目 2・3 は読み替え後が 1 になるため、澱みの対象になる。

目標値が指定されているとき、**達成値 ≧ 目標値** なら成功、未満なら失敗。

> **2026-07-03:** 達成値は **読み替え → 澱み（換算後1以下→−1）** の2段階に整理。旧 d20「澱み3以下」表記は廃止（数値上は等価）。

## 開示: 属性ダイスと反応効果（詳細）

### 火（d4）— 延焼

- **反応条件:** 3以上
- **反応効果:** 自身の出目を **4** にする。ダイスプールに **d4 を1個追加** して振り、それを未反応として扱う

- **反応条件:** 20
- **反応効果:** 自身以外のダイス1個を選び、**振り直す**

### 闇（d10）— 覚醒

- **反応条件:** 10
- **反応効果:** 自身以外のダイス1個を選び、**裏返す**

### 光（d12）— 昇華

- **反応条件:** 12
- **反応効果:** 自身以外のダイス1個を選び、出目を **最大値** にする

## 議題 3: 判定結果の粒度

**決定事項（ダイスシステムとして）:**

- 出力は **達成値**（各ダイス換算の合計）
- 目標値が指定されていれば **達成値 ≧ 目標値** で成功/失敗

**別ログ:**

- 錬金: 達成値＝アイテム強さ（錬金ログ）
- 探索: 目標値の与え方・制限（探索ログ、未設計）

## 議題 4: エミュレーター（sim）の目的

**決定事項:**

各ダイスの効果・出目を総合的にスコアリングし、強さの統一（バランス）が取れているかを調査する。

- 反応連鎖（特に延焼）を含むモンテカルロ
- 属性ダイス同士のパワーレベル比較
- **反応モデル:** 貪欲最善手（greedy）— `pkg/dice` の実装と sim（part1）の前提
- **意図した強さ順:** d12 > d10 > d6（プール大）> d4 / d8 / d20 > d6（プール小）
- **sim 実装:** `sim/part1/`（限界貢献度・全構成列挙）

## 議題 5: データの置き場

**決定事項:**

- ダイスルールは **凍結** 済み。数値チューニング対象ではない
- **`constants/dice.json` は作らない** — 手続きルールが主で、正は `docs/rules/dice.md`（公開）と `pkg/dice/`（sim）
- コロケーション（`*.json` ↔ `*.md`）は、数値調整が発生するシステム（錬金・戦闘等）に適用する

## 議題 7: 反応フェーズ — 強制処理 — [決定]

**2026-07-03**

### 背景

- 旧ルール: 反応可能でも **反応しなくてよい**（任意打ち切り）
- 半霊・越境の「反応中」タイミングが、打ち切り宣言と曖昧に重なり **ルール上の穴** になっていた
- sim（greedy 全反応）とルールが不一致

### 決定

| 項目 | 内容 |
|------|------|
| 反応の性質 | ダイス同士が互いに影響する **科学的な反応**。PL の任意で打ち切れるもの **ではない** |
| 終了条件 | 反応可能なダイスが **0** になるまで **必ず** 処理を続ける |
| 残る任意性 | 複数反応可能時の **処理順**、効果の **対象**、土の **±1/±2** |

### 半霊への効果

- 「途中で止めて越境」という **裏口** をルール変更で潰す
- 強弱（数値バランス）は別問題。越境の **タイミング解釈** は明確化される
- sim の全反応 greedy モデルと **ルールが一致**
