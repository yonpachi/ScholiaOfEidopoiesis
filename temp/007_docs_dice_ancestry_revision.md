# 007: ダイス・種族ルール文書の比較と改稿

**日付:** 2026-07-03  
**ステータス:** [決定]

## 背景

バックアップ（旧 `checks.md` / `ancestry.md`）と現行 `docs/rules/` を比較し、説明品質を向上させる。

## 方針

- **正:** 現行ルール（[002](002_dice_system.md)、[005](005_races.md)、`pkg/ancestry/score.go`）
- **バックアップから取り込む:** 具体例、フレーバー、パイプライン位置づけ、用語補足
- **戻さない:** 意図的改訂（反応強制、澱み2段階化、収束・手馴・越境の新版）

---

## ダイスルール差分（backup checks.md → docs/rules/dice.md）

### 体裁

| 観点 | バックアップ | 現行 |
| ---- | ------------ | ---- |
| 具体例 | あり | なし → **復活** |
| 澱み | 独立ステップ（d20は出目3以下） | 読み替え→澱みの2段階 |
| 反応 | 任意打ち切り可 | 反応可能が0まで強制（002 議題7） |
| ベース d10 | 属性未明示 | 闇属性と明記 |

### ルール（現行維持）

1. 反応フェーズは反応可能が残る間必ず処理。順序・対象・土の±1/±2のみ任意。
2. 澱みは読み替え後の値が1以下なら−1（旧 d20「3以下」表記と数値等価）。
3. ベース d10 ＝ 闇 d10。

### 改稿内容

- 具体例セクション追加
- 澱み補足（d20 出目2・3）
- 反応の残る任意性を箇条書き化
- 種族能力へのリンク

### 体裁

| 種族 | バックアップ | 現行 |

| 機巧・素読 | d20半減を能力に含む | 換装+澱みスキップのみ |
| 錬生・進化 | 変異（最高値除外+循環+1） | 収束（均質化、反応・澱みスキップ） |

### 改稿内容
