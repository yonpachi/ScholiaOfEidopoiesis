## 合意サマリ

| 項目 | 内容 |
|------|------|
| **除算** | **端数切り捨て**（システムデフォルト。都度記載不要） |
| **演算子** | 四則演算。**×／÷ が ＋／− より優先**。同優先度は **左から** |
| **計算式** | **`{}`** で囲む（例: `{品質/2}` `{品質×3}`） |
| **係数** | 設計用 **DB**（constants/sim）あり。**PL向けは直接数値** を記載 |
| **印記** | `<>` / **タグ** `[]` / **フレーバー** 括弧なし |

---

## 括弧の使い分け — [決定] 2026-07-11

| 括弧 | 用途 | 例 |
|------|------|-----|
| **`<>`** | **印記** | `<火>` `<障壁>` `<特>:` |
| **`[]`** | **タグ** ID | `[癒し]` `[棘]` |
| **`{}`** | **計算式** | `{品質/2}` `{品質×3}` |
| （なし） | **フレーバー** | 「甘い薬草」 |

---

## 計算規則 — [一部決定] 2026-07-11

### 確定

| 規則 | 内容 |
|------|------|
| **除算** | 結果は **端数切り捨て** |
| **演算子優先** | 通常の四則と同じ … **`×` `÷` ＞ `+` `−`**。同順位は **左から** |
| ** `{}` 内** | 変数（`品質` 等）と **数値リテラル** のみ。`{品質×3}` `{品質/2+1}` |

**例（品質=10）:**

| 式 | 結果 |
|----|------|
| `{品質/2}` | 5 |
| `{品質×3+1}` | 31 |
| `{品質+1×2}` | 12（`1×2` が先 → 10+2） |

**未決:** `{(品質+1)×2}` のような ** `{}` ネスト** を許すか。

### 係数と PL 向け表示 — [決定] 2026-07-11

| 層 | 内容 |
|----|------|
| **設計** | `constants/`・sim で **係数 DB** を管理。バランス調整用 |
| **データ** | 効果文は **数値リテラル** … `{品質×3}`（`{品質×回復係数}` のような **名前参照は書かない**） |
| **ルールブック（PL）** | **直接数値** が見える文言 … 「HP を 品質×3 回復」等 |

係数を変更したら **データ／ルールブックの数値を更新** する。PL は係数 ID を意識しない。

### 未決

| 論点 | 内容 |
|------|------|
| `{}` ネスト | `{(品質+1)×2}` を許すか |
| **変数一覧** | `品質` 以外に `{}` 内で使う変数（`行動段階` 等） |
| `強度=` | 右辺は **常に `{}`**（確定に近い） |
| 002 境界 | ダイス達成値 vs 算術 |

---

## 効果文での使用例

```
効果:
  <火> 対象の HP を {品質×3} 回復する
  <特>: 対象に <障壁> を付与する。強度={品質×0.3}
  <特>×<♡>: 対象の HP を {品質/2} 追加回復する
```

（`0.3` は設計係数を **数値として埋め込んだ** 例）
