# 系統候補リスト v2（機能軸・クセ優先）

`txt/flash-idea.md`（自案の草案）と `txt/D1.md`（AI提案）を統合。

## 前提：軸の転換

`014_lineage_proposals.md` は「責務①〜⑥をどう分担するか」という**責務軸**で系統を整理したもの。  
今回はそれとは別の切り口で、**機能軸（何ができるゲームメカニクスか）＋クセ（一長一短・誤用の余地）優先**で候補が上がっている。責務カバーは後付けでよい、という方針。

`txt/D1.md` が既存8系統を機能軸で言い換えた表が起点になっている。

## 3-1. 追加候補：育成・地形操作系統（2026-07-14 発想）

「マインクラフトのSteveがスマブラに参戦した時」のイメージ（ブロックを置く・木を生やす・足場や遮蔽物を戦闘中に作る）から着想。既存候補のどれとも完全には一致せず、2系統の交差点にある。

| 既存候補 | 担うもの | 足りない部分 |
| -------- | -------- | ------------ |
| 菌類（種子・菌床・園芸） | 時間経過での**効果の段階変化**（発芽→開花→結実→枯死） | 戦場オブジェクトの生成・地形操作ではない |
| 建材・模型・陣地装置 | 壁・橋・遮蔽物・砲台・門など**戦場への即時配置** | 「育てる・成長する」手順がない |

| 系統（仮）           | メカニクス軸           | できること（複数）                                                                                   | クセ・代償                                                       |
| -------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| **樹苗・造園**       | 持続（段階成長＋地形生成） | 種を植えて数カウント後に木（壁・遮蔽物・足場）を生やす、育てて大きくすると射線を切る、切り倒すと即席の資材（棒・板）が手に入る | 即効性がない。育つ前に踏まれる・焼かれると失敗する。生えた木は味方も敵も利用できてしまう |

**独自性：** 菌類の「成長段階」と建材の「戦場オブジェクト配置」を組み合わせた、**育てて使う地形操作**という他候補にない動詞（植える・育てる・伐る）を持つ。マインクラフトのブロック配置のような、戦況をリアルタイムで作り変える体験を再現できる。

**010_landscape.md との違い：** 探索スコープの「地景」（霧域に界標を据えてマップ上の土地タイプを拓く）とはスコープが異なる。この候補は**戦闘中・数カウント単位**で発生する即席の地形操作であり、地景システムとは別レイヤーとして扱う。

## 5. 機能軸マトリクス（全候補の分類）

D1末尾の提案（即時／予約／反応／持続／召喚／連鎖／蓄積／カード操作）に沿って全候補を分類。

| 機能軸               | 該当系統                                                       |
| -------------------- | ---------------------------------------------------------------- |
| **即時**             | 薬、爆弾、ポーション、銃                                          |
| **予約**（タイミング指定） | 料理、歯車、蝋燭・灯火                                       |
| **反応**（条件割り込み）   | 札・呪符、鏡・レンズ（一部）                                 |
| **持続**（範囲・スタンス・場） | 香料、生体模倣、ガラクタ、菌類、糸・織物、仮面・衣装、天候瓶、建材・陣地、樹苗・造園 |
| **召喚**             | 人形                                                              |
| **連鎖**（コンボ）   | 印記コンボ、楽器・共鳴器                                          |
| **蓄積**（保存・放出） | 宝石・結晶、廃材・再錬、ガラス・陶器、残響瓶                     |
| **カード操作**       | タロット                                                          |

**観察：** 即時・持続には候補が集中しているが、**反応・召喚・カード操作**は候補が少ない。タロットと札・呪符は「このゲーム（タイムライン＋トランプ）だからこそ成立する」独自性が高く、優先度を上げる価値がある。
