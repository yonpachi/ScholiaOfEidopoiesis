## 目的

レシピ・素材・敵を **多対多の疎な網** にするための **接続口（ポート）** を、βで凍結する。

- 頂点（タグ種・素材名・敵種）は抑える
- 辺（どれがどれに使えるか）を増やす
- 各ポートは **レシピ側 ≥2** かつ **入手側 ≥2**（被り2の一般化）
- β中は **新ポート禁止**。足りなければ要件を既存へ寄せる

※ 020 の「カテゴリ表を先に完成させない」は **換算点の型表** の話。本ファイルの **錬金カテゴリ** とは別。

## レイヤ（何がポートで、何が違うか）

| 層 | 記法イメージ | βでやること | 敵との関係 |
|----|--------------|-------------|------------|
| **カテゴリ（系統）** | `<獣>` 等 | **12で凍結**（議題1）。敵系統≈素材カテゴリ | 素材が1つ持つ。敵は系統1＋個体名 |
| **性質** | 火・水…（マナ属性条件） | **4〜6**。属性寄りスロット | 色ぬる等の特徴と揃えてよい |
| **副作用タグ** | `[ぬるぬる]` 等 | **8〜12**。税・個性 | ドロップに乗る。万能のブレーキ |
| 規定タグ | レシピごと | **ポートにしない**（分解用・使用効果なし） | 敵は落とさない |
| 印記 `<>` | 戦闘・効果文 | **ポートにしない**（012） | 敵の＋1は印記でよい。錬金要件とは別 |
| 特定素材名 | `虹色の羽` | **スパイス**（スロット1〜2割以下） | ボス／シナリオ用。幹線にしない |

## 設計原則（このファイルの前提）

1. タグは語彙、素材は文（2〜3ポートの束）、敵は入手イベント  
2. 増やすなら辺。頂点ではない  
3. 特定素材は例外。カテゴリ／性質が幹線  
4. 万能は副作用と入手コストで削る。専用化で削らない

## 議題 4: 素材束の型 — [方向] 2026-08-28

名前付き素材はあと（15〜25）。束の形だけ固定する。

```
素材
  ├ カテゴリ ちょうど1
  ├ 性質 0〜1
  └ 副作用 0〜1（多いとノイズ。例外で2は慎重）
```

例（仮・名前は後）:

| 束 | カテゴリ | 性質 | 副作用 |
|----|----------|------|--------|
| 無のぬる核 | `<柔>` | — | `[ぬるぬる]` |
| 赤ぬる核 | `<柔>` | 火 | `[ぬるぬる]` |
| 毒ぬる核 | `<柔>` | — | `[毒液]` 等（`[ぬるぬる]` と両立するか要決） |
| こうもり羽 | `<鳥>` | 風? | `[牙血]` or なし |
| 爆弾岩片 | `<鉱>` | 火 | `[火薬]` |

**毒ぬる**のように特徴が強い個体は、副作用を2つ載せると完成品が汚い。  
「特徴は性質 **または** 副作用の片方に寄せ、もう片方はカテゴリだけ」をβの目安にする。

## 調査: ドラクエ／アトリエの敵分類と素材 — 2026-08-28

質問: 素材カテゴリを敵の系統に寄せるべきか。複合敵（鎧オーク等）は確率ドロップか、強い役に限定か。

### ドラゴンクエスト

**系統（family）の役割は主に戦闘。** 錬金ドロップの分類ではない。

| 系統（代表・VIII〜） | 例 | 系統が効くこと |
|----------------------|-----|----------------|
| スライム／獣／鳥／虫／植物／水系 | 定番雑魚 | 特効武器・特技（ドラゴンキラー等） |
| ドラゴン／ゾンビ／悪魔／物質／マシン／エレメント／怪人 | 同上 | 同上 |
| XI | 虫・植物・水系 → **自然系に統合** | 系統が多すぎると圧縮する |

出典: [Monster Families (DQ Wiki)](https://dragon-quest.org/wiki/Monster_Families) / [系統と弱点 DQ8](https://cour89.com/dq8/tips/weakness.php) / [Wikipedia モンスター一覧](https://ja.wikipedia.org/wiki/ドラゴンクエストシリーズのモンスター一覧)

**複合見た目でも系統は1つに決める。**

- スナップドラゴン（植物の見た目）→ それでも **ドラゴン系**
- メタルドラゴン（竜型）→ **マシン系**
- スカルゴン → 作品によりゾンビ／ドラゴンで揺れる（境界は曖昧だが、同時に二系統ではない）

→ DQは「見た目の要素を全部系統に載せる」のではなく、**戦闘上の主アイデンティティを1つ選ぶ**。

### アトリエ（ライザ系・ユミア）

**敵の種族分類** と **素材のカテゴリ** は別レイヤだが、**相関は強い。**

| 敵の分類例 | 落とすもの（例） | 素材カテゴリ例 |
|------------|------------------|----------------|
| ぷに／小型 | ぷにぷに玉・青、きれいな水 | **ぷにぷに** ＋ 採取寄り |
| イタチ／小型 | 新鮮な肉、動物の毛皮、大きな骨 | **動物素材**（複数種） |
| でかぷに／大型 | 複数色のぷに玉＋大ぷに玉 | 同系統の **上位・複数** |
| ゴーレム等 | ゴーレムコア | **鉱石** |
| 甲殻持ち魔獣 | 魔獣の甲殻 | **鉱石／虫**（1素材が複数カテゴリ） |
| 鱗持ち | 魔獣の鱗 | **動物素材／鉱石** |

出典: [ライザ2 魔物データ](https://gamers-high.com/ryza2/data/monster.html) / [ライザ3 素材入手](https://gamerch.com/ryza3/720510) / [ユミア 素材図鑑](https://ds-can.com/yumia/data/sozai.html)

**観察できる設計パターン:**

1. **雑魚種族 ≈ 素材の主カテゴリ1つ**（ぷに→ぷに、獣→動物素材）
2. **多対多は「敵が二系統」ではなく「素材が複数カテゴリ」** で作る（甲殻＝鉱石+虫）
3. **同種族の強い個体**（でかぷに／ユミアの「強敵」牙アイコン）が、同系統のレア・複数種を落とす
4. 採取素材（草・水）も同じカテゴリ網に入る。敵だけが供給源ではない
5. 色違いぷには **性質（属性）寄り** の差。カテゴリは同じ「ぷにぷに」

### このプロジェクトへの写し

| 方針 | 評価 |
|------|------|
| **カテゴリ名を敵系統に寄せる**（12系統） | **決定。** 022 議題1 の表が正 |
| **雑魚は主カテゴリ1つ** | **推奨。** DQの「系統1つ」＋アトリエの「種族→主素材群」 |
| **複合は素材側で跨ぐ**（鎧オーク→`<獣>`素材と`<鉱>`素材、または1素材に獣+鉱） | **アトリエ本流。** 敵系統を2つにしない |
| **複合を確率でカテゴリ切替** | 可能だが、卓TRPGでは「今回何が落ちたか」の揺らぎが増える。アトリエはどちらかというと **ドロップ表に複数行**（肉も骨も） |
| **複合はそこそこ以上** | **併用可。** 雑魚は純粋系統、鎧付き・二要素は役を上げる（ユミア強敵・でかぷに型） |

### 推奨（調査後の提案）

```
敵系統（見た目・戦闘の族）  ──1対多──►  落とす素材名
素材名                      ──1対多──►  カテゴリポート（多くは1、複合素材は2）
カテゴリポート              ──多対多──►  レシピスロット
```

- **雑魚:** 系統1＝主カテゴリ1。特徴＋1は性質／副作用（020どおり）
- **複合（鎧オーク等）:**  
  - **案α:** 固定で素材2種（`<獣>`寄り＋`<鉱>`寄り）。確率は「どちらが来るか」ではなく「2種のうち片方／両方」  
  - **案β:** 1素材にカテゴリ2つ（アトリエの甲殻型）。敵系統は獣のまま  
  - **案γ:** 複合はそこそこ以上のみ。雑魚図鑑を単純に保つ  
- **β採用: 案γ＋α**（2026-08-28 合意）。雑魚は単純、複合は強い役＋ドロップ複数行。案β（1素材2カテゴリ）は例外として後回し
