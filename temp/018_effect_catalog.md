## 書き方方針 — [合意方向] 2026-08-05

**テンプレから作る。** 個別レシピの文章より先に欄を固定する。

| 載せる場所 | 内容 |
|------------|------|
| **本文外（錬金・想成）** | **材料**、**タグ**（規定タグ）、**コスト**（想成時マナ） |
| **本文外（使用時）** | **発動**、距離、対象、（必要なら）設置カウント／トリガー |
| **本文（効果文）** | 対象が決まったあと、何が起きるか（HP増減、印記付与、場の設置、データ改変など） |
| **印記側** | 持続・減衰・強度など「残る状態」の共通ルール |

これは 011 議題17（距離／対象／効果の分離）および 008（材料スロット方式・想成マナ）と一致する。  
欄名はテンプレ用に **材料／タグ／コスト** に短縮（下記）。
011 の旧欄名「タイミング」は、本ファイルでは **発動**（効果の解決の仕方）に読み替える。  
**使用・想成の宣言は自分の手番**（011 議題11）— レシピごとに書かない。  
距離と対象を効果文に混ぜると、造園・歯車・召喚で読みにくくなる。

## アイテム効果テンプレ（消耗品）

```
【仮称】
系統: （薬／爆弾／料理／造園／歯車／召喚／変異 等）
パターンID: （下表 Pxx。複数可）

■ 錬金・想成（本文外）
材料: （008 議題11。各スロットは3種のいずれか・混在可）
  - スロット1: （種別）／（カテゴリ・性質など要求。素材名指定なし）
  - スロット2: …
  - スロット3: …（本数はレシピごと。βでは未定可）
タグ: […]  ※規定タグ（分解用・使用時効果なし）
コスト: （想成時のマナ。属性ごとの個数 or 表記）
  例: 水2 ／ 火1水1 ／ ? など

■ 使用時データ欄（本文外）
発動: （下表のカテゴリ。漢字二文字）
距離: （相対カウント min~max。自身のみなら省略可）
対象: （自身／単体／範囲／… 011の表に従う）
※発動＝設置 または 滞在 … 設置カウント: （絶対 or 相対。記法は後で固定）
※発動＝条件 … トリガー: （被弾／移動／人数変化 等）

■ 効果文（本文）
（数値は ? または {品質×?}。上から順に解決）
  [<属性フラグ>]
  …本文…
  （副次があれば続ける）

■ メモ
クセ／両刃／β制限／未決
```

**補足（008）**

- 錬金時はマナを消費しない。要求は **材料** スロットに入る素材（タグ・カテゴリ条件）
- **コスト** は **想成時** のマナのみ。使用時はマナなし（008 α″）
- β草案では材料・コストとも `?` や「水寄り」程度のメモでよい

## 発動カテゴリ — [決定] 2026-08-05

**欄名:** `発動`（漢字二文字）。**効果がいつ・どう効き始めるか**。使用・想成の宣言タイミングではない。

| 発動 | 意味 | 主な系統 |
|------|------|----------|
| **即時** | 使用・想成の解決と同時 | 薬、爆弾（多く）、料理、変異、召喚 |
| **次番** | 対象の次の手番開始時（1回） | 料理（バフ案・未採否） |
| **設置** | 置いた瞬間に一度効く | 造園（一部） |
| **滞在** | 指定カウントにいる間ずっと | 造園 |
| **条件** | トリガー欄の条件を満たしたとき | 歯車 |
| **時限** | 設置／使用から経過後に一度 | 爆弾 |

**補助欄:** `発動＝条件` のとき **トリガー** を併記。`発動＝設置`／`滞在` のとき **設置カウント** を併記。

### 欄の使い分け（例）

| 系統 | 発動 | データ欄で書くこと | 効果文で書くこと |
|------|------|--------------------|------------------|
| 薬 | **即時** | **距離＝短間合**（系統デメリット）、対象＝単体 | HPを回復する／`<毒>`を付与する |
| 爆弾 | **即時** or **時限** | 距離、対象＝範囲（味方含む） | ダメージ、KB、煙幕の内容 |
| 料理 | **即時**（バフは次番案） | 対象＝単体 | 強回復＋**カウントを進める**＋副次印記 |
| 造園 | **滞在**（＋設置） | 設置カウント、対象＝そのカウント上 | 床効果（または場印記への参照） |
| 歯車 | **条件** | トリガー、貼付／設置の対象 | 発動時に起きること |
| 召喚 | **即時** | 対象＝設置位置など | どの型の個体を出すか（詳細は召喚ルールへ） |
| 変異 | **即時** | 対象＝単体 | データ改変（巨大化等）＋デメリット |

## 効果パターン表（β用・数値なし）

レシピはパターンを1つ以上参照する。効果種別ラベル（「これは回復スキル」）はデータに載せない（011）。

| ID | パターン | 起き方 | 主に使う系統 | 本文／欄 |
|----|----------|--------|--------------|----------|
| P01 | 即時HP回復 | その場でHP増加 | 薬、料理 | 本文 |
| P02 | 即時ダメージ | その場でHP減少 | 薬、爆弾、召喚 | 本文 |
| P03 | 印記付与 | 状態を付ける | 多く | 本文→印記 |
| P04 | 印記の一時抑制／解除 | 不利印記を消す・抑える | 薬 | 本文 |
| P05 | カウント進行 | 対象を後方へ進める | 料理（代償） | 本文 |
| P06 | ノックバック | 後方へ押す | 爆弾 | 本文／効果後 |
| P07 | 場・滞在 | 指定カウントに居る間ずっと | 造園 | 設置欄＋本文／場 |
| P08 | 条件反応 | 条件成立で発動 | 歯車 | 発動＝条件＋トリガー欄＋本文 |
| P09 | データ改変 | 最大HP・サイズ・耐性枠など書き換え | 変異 | 本文＋印記 |
| P10 | 召喚 | 別個体を場に残す | 召喚 | 本文＋召喚ルール |
| P11 | 煙幕・命中制約 | 範囲内で攻撃に判定が要る等 | 爆弾 | 本文／場 |
| P12 | 副次デバフ | 本体に紐づく弱デバフ（満腹等） | 料理 | 本文 |

**廃止した旧案:** 到達時一発（旧E09）は **爆弾の時限** 側。歯車は P08（条件反応）のみ。

## 印記草案メモ（キーワードのみ）

012 の分担に合わせ、**残るもの・条件・属性**の語彙案。強度・減衰ルールは未定。正式一覧は 012 側で後日作成。

### 状態印記（付与されうる）

| 仮名 | イメージ | 主に使う系統 |
|------|----------|--------------|
| `<毒>` | 継続で削る | 薬、造園 |
| `<火傷>` 等 | 属性付き継続 | 属性フラグと併用検討 |
| `<障壁>` | ダメージを吸収・軽減する層 | ③。βは装備本体＋消耗品補助 |
| `<装甲>` | 受けるダメージを下げる | 同上 |
| `<回避>` | 攻撃を受けにくくする | 攻撃経路向け |
| `<再生>` | 毎ラウンド等で少量回復 | 料理④など |
| `<拘束>`／`<鈍足>` | 移動・カウント進行を阻害 | 料理副次、造園② |
| `<満腹>`／`<渇き>` | 食・飲関連の弱デバフ | 料理（P12 副次） |
| `<巨大化>`／`<縮小>` | サイズ・行動ルールの改変 | **変異**（P09） |
| （案）半減／弱点 | 属性耐性の書き換え | **変異**④ |

### 条件・段階印記（効果文の分岐）

| 仮名 | イメージ |
|------|----------|
| `<軽>` `<中>` `<重>` `<特>` | 行動段階（012 確定） |
| `<♤>` `<♡>` `<♢>` `<♣>` | スート条件（012 確定） |
| （案）`<序盤>` `<終盤>` | 現在カウント帯（未採否） |

### 属性フラグ

| 仮名 | イメージ |
|------|----------|
| `<火>` `<水>` `<土>` `<風>` 等 | 効果文先頭。耐性・マナ属性判定に接続 |
