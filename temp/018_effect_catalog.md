## 書き方方針 — [合意方向] 2026-08-05

**テンプレから作る。** 個別レシピの文章より先に欄を固定する。

| 載せる場所               | 内容                                                                 |
| ------------------------ | -------------------------------------------------------------------- |
| **本文外（錬金・想成）** | **材料**、**タグ**（規定タグ）、**コスト**（想成時マナ）             |
| **本文外（使用時）**     | **発動**、**間合**、**対象**、（必要なら）トリガー                   |
| **本文（効果文）**       | 対象が決まったあと、何が起きるか（HP増減、印記付与、データ改変など） |
| **印記側**               | 持続・減衰・強度・**いつ効くか** など「残る状態」の共通ルール        |

これは 011 議題17（間合／対象／効果の分離。旧称・距離）および 008（材料スロット方式・想成マナ）と一致する。  
欄名はテンプレ用に **材料／タグ／コスト** に短縮（下記）。
011 の旧欄名「タイミング」は、本ファイルでは **発動**（効果の解決の仕方）に読み替える。  
**使用・想成の宣言は自分の手番**（011 議題11）— レシピごとに書かない。  
間合と対象を効果文に混ぜると、造園・歯車・召喚で読みにくくなる。

**用語の最小化 — [決定] 2026-08-07**

| 用語             | 意味（これ以外にしない）                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| **間合**         | 使用者基準の相対カウント帯だけ。旧データ欄名「距離」。**カウント中心の半径・AoE には使わない** |
| **コマ**         | キャラクター（戦闘単位）                                                                       |
| **カウント**     | タイムライン上の目盛り＝**エリア**（行動順兼位置）                                             |
| **単体**         | **コマ1つ**のみ。エリアは単体では取れない                                                      |
| **対象**         | 間合内から何を取るか。コマ系（単体・範囲等）と **`カウント`**（エリア）                        |
| **設置カウント** | **設けない**。置き場所は `対象: カウント`                                                      |

`発動: 滞在` ＋ `対象: カウント` … 本文はカウントへ付与。コマへの波及・カウント終了解除は共通ルール（造園節）。

## アイテム効果テンプレ（消耗品）

```
【仮称】
系統: （薬／爆弾／料理／造園／歯車／召喚／変異 等）
パターンID: （下表 Pxx。複数可）

■ 錬金・想成（本文外）
材料: （008 議題11。各スロットは3種のいずれか・混在可）
  - スロット1: （種別）／（カテゴリ・性質など要求。素材名指定なし）
  - スロット2: …
  - スロット3: …（本数はレシピごと。βでは未定可）
タグ: […]  ※規定タグ（分解用・使用時効果なし）
コスト: （想成時のマナ。属性ごとの個数 or 表記）
  例: 水2 ／ 火1水1 ／ ? など

■ 使用時データ欄（本文外）
発動: （下表のカテゴリ。漢字二文字）
間合: （相対カウント min~max。自身のみなら省略可）
対象: （自身／単体／範囲／カウント／… 011の表に従う）
※発動＝条件 … トリガー: （被弾／移動／人数変化 等）
※発動＝滞在 … 対象は通常カウント。設置カウント欄は作らない

■ 効果文（本文）
（数値は ? または {品質×?}。上から順に解決）
  [<属性フラグ>]
  …本文…
  （副次があれば続ける）

■ メモ
クセ／両刃／β制限／未決
```

**効果文の印記記法 — [方向合意] 2026-08-14**

数値が必要な状態印記は、別行の `強度=…` ではなく **印記名の中に書く**。

| 書き方   | 例                                   |
| -------- | ------------------------------------ |
| **採用** | `対象に <毒：{品質/3}> を付与する。` |
| 同様     | `<目潰：{品質/4}>`、`<障壁：5>` 等   |
| 数値なし | `<誘爆>` `<爆発>` など               |

旧草案の `対象に <毒> を付与する。強度={品質/10}` は上記に寄せる（造園等の未改稿は順次）。

**対象: 単体** … 011どおり **敵味方・自身を問わない**。陣営限定が要るときだけ `味方1体`／`敵1体` を使う。誤射・対象ずらしにも耐える。

**補足（008）**

- 錬金時はマナを消費しない。要求は **材料** スロットに入る素材（タグ・カテゴリ条件）
- **コスト** は **想成時** のマナのみ。使用時はマナなし（008 α″）
- β草案では材料・コストとも `?` や「水寄り」程度のメモでよい

## 品質と段階効果 — [方向合意] 2026-08-09

全レシピを段階制にはしない。軸に応じて使い分ける。見本は造園④。

| 軸                   | モデル                     | 例                           |
| -------------------- | -------------------------- | ---------------------------- |
| 連続量               | **一次式**のまま           | 薬① HP=`{品質}`、造園①③ 強度 |
| 離散・両刃・オンオフ | **段階**（帯で行のON/OFF） | 間合、待機、欠点の有無       |

**段階の約束**

- 帯は **2〜3**。本体は **常時オン**（低品質を死にアイテムにしない）
- 上の帯は **効果を足す** か **マイナスを消す**
- 新DSLは作らない。012 の条件行と同じ型（`<品質≥10>:` 等。記法は仮）
- 閾値は仮。008 のマナ1つあたり達成値期待 **約 +5.5** を目安に、あとで sim

| 帯（仮） | 目安                            | 役割                 |
| -------- | ------------------------------- | -------------------- |
| 基本     | 常時                            | レシピの本体         |
| 中       | 品質 ≥ 10 前後（マナ2期待付近） | 欠点減 or 小さな追加 |
| 高       | 品質 ≥ 16〜20（マナ3前後）      | はっきりした追加     |

線形レシピに段階を無理に足さない。

## 発動カテゴリ — [決定] 2026-08-05

**欄名:** `発動`（漢字二文字）。**効果がいつ・どう効き始めるか**。使用・想成の宣言タイミングではない。

| 発動     | 意味                                                    | 主な系統                           |
| -------- | ------------------------------------------------------- | ---------------------------------- |
| **即時** | 使用・想成の解決と同時                                  | 薬、爆弾（多く）、料理、変異、召喚 |
| **次番** | 対象の次の手番開始時（1回）。料理は進行を使用時に先解決 | 料理                               |
| **設置** | 置いた瞬間に一度効く                                    | （造園βでは使わない想定）          |
| **滞在** | `対象: カウント` のマスにいる間ずっと                   | 造園                               |
| **条件** | 本文に書いた条件が満たされたとき（1回など。歯車）       | 歯車                               |
| **時限** | 使用から経過後に一度                                    | 爆弾                               |

**補助欄:** 滞在に設置カウント欄は不要。  
**`発動: 条件`:** 別欄「トリガー」は設けない。**条件も解放内容も本文に書く**（2026-08-11）。

### 欄の使い分け（例）

| 系統 | 発動                     | データ欄で書くこと                                   | 効果文で書くこと                               |
| ---- | ------------------------ | ---------------------------------------------------- | ---------------------------------------------- |
| 薬   | **即時**                 | **間合＝0**、対象＝単体（敵味方可）                  | HP増減／`<毒：…>` 等                           |
| 爆弾 | **即時** or **時限**     | 間合、**対象＝カウント**（その上の全コマ・味方含む） | ダメージ、KB、煙幕の内容                       |
| 料理 | **次番**（進行は使用時） | 間合 `0~2`（仮）、対象＝単体                         | 先に進行+2 → 次手番開始時に本体                |
| 造園 | **滞在**                 | 間合（置き帯）、**対象＝カウント**                   | 印記付与（薬と同型）                           |
| 歯車 | **条件**                 | 間合、対象＝単体                                     | **条件＋そのとき起きること**（本文にまとめる） |
| 召喚 | **即時**                 | 間合、**対象＝カウント**（そこに召喚体を出す）       | 型・固定行動・規定進行                         |
| 変異 | **即時**                 | 間合 `0~1`（仮）、対象＝単体                         | データ改変印記（巨大／縮小／狂化／耐性）       |

### 薬② 印記強度の減少 — [一旦] 2026-08-17

対象の **強度付き印記すべて** を減らす（両刃。障壁等も対象）。0で即時除去。解除効果ではない。

```
【仮称】（未定）
系統: 薬
パターンID: P04

■ 使用時データ欄
発動: 即時
間合: 0
対象: 単体

■ 効果文（本文）
対象が持つ強度付き印記すべての強度を {品質/7} 減らす。
（強度0以下になった印記は除去。解除効果ではない）
```

量 `{品質/7}` 一旦。武器と同じ除数。Q=20 なら **2**（`/10` と同じ）。Q=14 なら2、Q=21 なら3。全部の印記を削るのでこれ以上厚くしない。③毒（n=6）は1本では消えない。Q＜7 は主量0でゴミ。

### 薬③ 毒付与 — [一旦] 2026-08-17

012の `<毒>` 定義に乗せる。薬＝単体即時付与、造園床＝マス滞在。強度は印記内に書く。

```
【仮称】（未定）
系統: 薬
パターンID: P03

■ 使用時データ欄
発動: 即時
間合: 0
対象: 単体

■ 効果文（本文）
対象に <毒：{品質/3}> を付与する。
```

**`<毒>`（012・再掲）:** 自分の手番開始時に強度ぶんHPダメ → 強度−1。0で除去。βに猛毒なし。

#### カウント全体KB（E）— [検討] 2026-08-16

着地したカウント上の **全員** をノックバックするギミック。

### 用語（コマ／カウント／単体）— [方向合意] 2026-08-07

タイムライン上の **カウント** は、行動順の目盛りであると同時に **エリア**（シノビガミ的）でもある。

| 語                 | 意味                                                   |
| ------------------ | ------------------------------------------------------ |
| **コマ**           | キャラクター（戦闘単位）。間合内から取る「人」側の対象 |
| **カウント**       | タイムライン上のマス＝エリア。行動順と位置を兼ねる     |
| **単体**           | **コマ1つ** のみ。エリア（カウント）は単体では取れない |
| **対象: カウント** | エリアを1つ選ぶ。単体・範囲（コマ列）とは別種          |

### 共通ルール: カウントへの付与 — [方向合意] 2026-08-07

効果文が `対象に <印記> を付与する` であり、かつデータ欄が `対象: カウント` のとき:

1. 付与先は **選んだカウント（エリア）** である
2. 「カウントに印記が付いている」とは、そのマスに **効果が載っている** 状態を指す
3. そのマスにいる **コマ** は、載っている印記／固有効果の適用対象になる（入ったら適用、出たら適用終了）
4. いつ効くかは、**再利用印記なら 012**、**固有効果ならそのレシピ本文**
5. カウント上の印記は **tick 減衰しない**（造園③の障壁型は **被ダメで消費**。減衰とは別）
6. 指定カウントが **終了** したとき、そのカウントから当該印記は **消える**
7. 強度 0（障壁消費しきり等）でもその効果は消える（カウント終了を待たない）
8. 指定カウント終了時は **コマがいない**（行動・待機移動で離脱済み）前提。よって終了処理は印記の **消滅のみ**（その回のダメージ対象はいない）

βではカウント専用の物理オブジェクトを必須とせず、上記と同値な処理でよい。

**テンプレ上の読み（造園β共通・間合仮）:**

```
発動: 滞在
間合: 0~3
対象: カウント
効果:
  対象に <印記>（仮）を付与する。強度={品質/10}
```

（本文の「対象」＝カウント。コマへの波及は共通ルール。）

**タイミングの記載場所 — [方向合意] 2026-08-07（2026-08-09 例外追記）**

| 置き場              | 内容                                                                                           |
| ------------------- | ---------------------------------------------------------------------------------------------- |
| **印記定義（012）** | 再利用する状態の「いつ効くか」（カウント進行／手番開始／被弾時 等）、減衰、強度の意味          |
| **効果文（本文）**  | どの印記を乗せるか・強度式。**独自性が強い滞在効果**は本文に書いてよい（印記カタログ化しない） |
| **共通ルール**      | カウント付与の意味・入退場・カウント終了時解除                                                 |
| **戦闘中の確率**    | **基本は 1d10**（002 本パイプラインは使わない）。命中・回避印記も同系統の予定。回数増は許容    |

### 「ただの遅延アイテム」にしない — [方向] 2026-08-11

薬・爆弾に載る効果（毒付与・ダメ・KB単体）を、トリガー付きで貼るだけだと **「あとで発火する同じアイテム」** になり、歯車の芯が薄い。

歯車が他系統と違う点はペイロードより次:

| 差                         | 意味                                                       |
| -------------------------- | ---------------------------------------------------------- |
| **手番を使わず発火**       | 合図の瞬間にアクションを消費しない                         |
| **事前投資**               | 貼って待つ。タイミングの読みがプレイ                       |
| **合図を参照する**         | 攻撃者・回避した事実など、**いま起きた出来事**を効果に使う |
| **出来事そのものをいじる** | 受けたダメを減らす／押し返す／その行動の待機を変える、など |

**④追撃 — [方向合意] 2026-08-12**

- 解放: 回避したコマのHPを **{品質}** 減らす（単体相当。誘爆なし）

**③反撃 — 拡充案 — 2026-08-11（追記）**

KB・待機+1・短いデバフだけだと弱い。毒返しも不採用。候補:

| 方向                  | 解放の例                                                            | 強さの出方                                           |
| --------------------- | ------------------------------------------------------------------- | ---------------------------------------------------- |
| **A. 鏡**             | いま受けたダメと同量（or 半分）を攻撃者へ                           | 重い被弾ほど重い反撃                                 |
| **B. 無効化**         | いまの攻撃ダメを0／大幅減                                           | 一撃を飲み込む。①と近接注意                          |
| **C. 行動奪い**       | 攻撃者の手番終了／待機を大きく足す                                  | テンポ破壊。重い                                     |
| **D. 位置の逆転**     | カウント入替／攻撃者を後方へ                                        | 間合・CTを崩す。⑤の穴                                |

| **F. 回避の勢い**     | 回避成功後、次の攻撃が強い（1回）                                   | かわした報酬                                         |
| **G. 狭い条件で強く** | 被弾かつ間合0 など                                                  | 条件が狭いぶん強化                                   |
| **H. 糸（案）**       | 自身がKBされたとき、**同カウントにいたコマ1体**のカウント／待機を+1 | 吹き飛ばされながら糸を撃つ。弱めだがフレーバーが良い |

βで特に見たいのは **A・B・D・E・H**。

**H 糸 — [反撃枠・採用] 2026-08-11**

- トリガー: **A05 ノックバックされた**
- 解放: KB直前（または直後）に **同じカウントにいたコマ1体** を選び、そのコマの進行を **+1**（待機+1 or カウント強制進行。用語は統一が要）
- フレーバー: 吹き飛ばされた拍子に緊急で糸を撃ち、誰かを引っ張って遅らせる
- 独りなら対象なし → 発火しても効果なし、or 発火自体しない（要決）

**対案との比較**

|            | 同カウント1体を+1（糸） | 次の自分のKBを−1（錨）     |
| ---------- | ----------------------- | -------------------------- |
| フレーバー | 糸を撃つ                | 踏ん張る／おもり           |
| 反応らしさ | 他者を参照する          | 出来事そのものを減らす     |
| 強さ       | 弱め・状況依存          | 弱め・自分得               |
| 向き       | **Hの本体向き**         | 段階の追加、または別レシピ |

→ フレーバー優先なら **糸を本体**。錨は品質帯で足すか、別本。

**品質（段階・仮）**

離散なので一次式は使わない（造園④と同型）。

| 帯（閾値仮） | 効果                               |
| ------------ | ---------------------------------- |
| 基本         | 同カウントにいたコマ1体の進行 +1   |
| 中 **≥15**   | さらに、今回受けたKBを **1減らす** |
| 高 **≥25**   | 進行が **+2**（2体からは採らない） |

「進行」が待機値なのかカウント強制移動なのかは、料理のP05と揃えてから用語固定。

①守／②少数の遅延強打／③位置テンポ／④攻撃保険。

##### 爆弾④

**指定カウント到来の時限**を④に置く（全員巻き込み）。歯車と被らない。

##### 採らない（β）

- 歯車の空カウント罠
- 歯車の「遅延爆発」（手番終了N回・同カウント全員）
- 歯車②の感圧（入室）案 … **不採用**（2026-08-13、次撃の強ダメを採用）

爆弾④は **指定カウント到来の時限** で歯車と被らない。

##### 対案: 行動のたびダメージ — [検討] 2026-08-13

貼った **単体** が何かを行うたびにダメージ、という案。少数狙いに直結する。

|              | 感圧（入室1体）          | 行動税（この対案）                  |
| ------------ | ------------------------ | ----------------------------------- |
| 誰が決めるか | 誰が入ってくるか（盤面） | **誰に貼るか**（対象指定）          |
| 爆弾との差   | 全員 vs 入室1体          | 全員 vs **指定1体が動き続ける限り** |
| 歯車①③④      | 待ち受けで直交           | 呪いで直交。貼り先が敵向き          |

**よい点**

- 「特定の対象にだけ絞る」が一番素直
- 薬`<毒>`＝手番開始で時間経過、造園床＝マスに居る、ここは **自分が動いた代償** → 芯が違う
- 動かなければ削られない、という選択が生まれる

**懸念**

| 論点               | 内容                                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| **1回発火ルール**  | 現行歯車は条件成立で1回解消。たびたびなら **例外** or 強度減衰で寿命を付ける                            |
| **遅延毒禁止**     | 以前「あとで削る毒」は歯車に載せない寄り。時間経過ダメにすると薬③と被る。**行動に紐づける**なら差は残る |
| **「何か」の定義** | 広すぎると毎回削れて動けない。攻撃／手番行動／移動、どれかに絞る必要                                    |

**「何か」の候補**

| 絞り               | 手触り                            |
| ------------------ | --------------------------------- |
| 攻撃したとき       | 殴るたびに反動。④外れとも対になる |
| 手番で行動したとき | 何をしても税。強い                |
| 待機移動したとき   | 動くたびに。狭い                  |

**寿命の付け方（たびたびにする場合）**

- 強度＝品質。発火のたびダメージ＆強度−1（`<目潰>`と同型の減衰）
- または N 回で消滅（Nは小さめ固定）

**所見:** 方向としては感圧より **少数狙いの芯に合う**。ただし「遅延毒」に見えないよう、トリガーは **行動** に限定し、1回発火ルールは **強度つきの繰り返し** として例外を明示した方がよい。広すぎる「何でも」より **攻撃したとき** が安全。
