# 019: 効果文の生成方式（ルール文構築方針）

**日付:** 2026-08-06

**関連:** [018_effect_catalog.md](018_effect_catalog.md) / [012_marks_tags.md](012_marks_tags.md) / [013_expression.md](013_expression.md) / [008_alchemy.md](008_alchemy.md)

## 背景

効果文・ルール文の課題:

- 情報の **記載順** がバラつきやすい（ルルブあるある）
- **誤字・表記ゆれ**（動詞・助詞・印記表記）
- 書き方を変えたとき **一括更新** しづらい

018 では効果の **型**（P01〜P12）と **欄の分離**（発動・間合・対象は本文外）を進めてきた。次は **読める日本語の出力** を、構造化データから **生成** する方針を採用する。

---

## 方針サマリ — [方向合意] 2026-08-06

| 項目 | 内容 |
|------|------|
| **正（Source of Truth）** | 構造化データ（JSON / CSV / seeds）。意味・引数・パターン ID |
| **生成物** | ルルブ・データ表示用の **読める文章**（箇条書きではない段落・文） |
| **テンプレ** | コーパス（日本語フレーズ集）＋ パターン別文型（P01〜P12） |
| **一括変更** | コーパス／文型を直して **全レシピ再生成** |
| **印記の中身** | 効果文には書かない。012 の印記定義を **参照**（生成でも分離） |
| **完全 DSL** | **作らない**（018 と同趣旨）。限られたパターンからの **テンプレ組み立て** |
| **例外** | 真に unique な行は `custom` オーバーライド可（lint 警告想定） |

**いまのスコープ（継続）:** 効果文の **非数値部分** と **書き方ルール**。材料・タグ・コストは数値経済（DPS・マナ）確定後。

---

## 二層モデル

### 1. 意味層（機械向け・正）

レシピごとに事実のみ保持する。

```json
{
  "recipe_id": "medicine_heal",
  "lineage": "medicine",
  "use": { "timing": "instant", "reach": 0, "target": "single" },
  "effects": [
    { "pattern": "P01", "amount": { "expr": "quality" } }
  ]
}
```

### 2. 表現層（人間向け・生成物）

コーパス＋引数から **文章** を組み立てる。最終出力は **箇条書きにしない**（段落・文）。

**出力例（薬①・イメージ）:**

```
使用時——発動は即時、間合い0、対象は単体。
対象のHPを品質分回復する。
```

（接続詞・句読点・欄見出しの文体は `phrasing_ja` で一括管理）

---

## 情報の出す順番（統一案・草案）

### レシピカード全体

1. 名称・系統（任意）
2. **使用時** … 発動 → 間合 → 対象 →（トリガー。滞在時は対象＝カウントで置き場所を兼ねる）
3. **効果** … 効果行を上から（012 の手続き順と一致）
4. **錬金** … 材料 → タグ → コスト（経済確定後。順序は生成時に固定）

### 効果1行の中

```
[属性フラグ] [条件:] 主文。修飾句。
```

パターンごとに **修飾句の型と順序** を固定（例: 付与 → 強度=）。

## 配置案（プロジェクト整合）

| 役割 | 置き場（案） |
|------|----------------|
| パターン文型 P01〜P12 | `constants/effect_patterns.json` |
| 日本語コーパス | `constants/phrasing_ja.json` |
| レシピ定義 | `data/seeds/recipes.csv`（または同等） |
| 生成スクリプト | `scripts/render_item_text.py` |
| 生成先 | `docs/` 断片 or seeds の表示列 |

DB でもよいが、β では **constants + seeds + script** から始める。

## `{品質/10}` の扱い（013 連携）

| モード | 用途 |
|--------|------|
| **data** | DB・解決用 … `強度={品質/10}` |
| **prose** | ルルブ用（必要なら）… 013 の端数切り捨て説明を展開 |

β では data モード（`{}` そのまま）でも可。013 の「PL向け直接数値」と両立させる。

## 生成する／しない

| 対象 | 方針 |
|------|------|
| レシピ効果カード | **生成**（主対象） |
| 印記共通ルール（012） | **手書き**（参照先） |
| 戦闘・錬金の叙述ルール | **手書き**（生成の前提） |
| 物語・世界観 | **手書き** |
