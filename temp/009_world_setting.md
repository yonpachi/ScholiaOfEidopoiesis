## 確定：世界の成立（設計者のみ）

### 基本原則

- 世界に **実体は本質的に存在しない**
- **意識を持つ者**（人間に限らない）の認識の蓄積と共有によって世界が **縁取られていく**
- **共通認識があるときだけ**、その場所に世界は「そこにある」
- 世界自体が存在するかは分からない — 認識が成立させる

### 認識の濃淡

人によって「そこに世界がどこまで存在するか」はバラバラ。

| 例 | 認識の厚み |
| --- | --- |
| 「あの方角には火山がある」 | 薄い |
| 「麓は火山灰で覆われている」 | やや厚い |
| 「あの木には私が掘った落書きがある」 | 確定的 |
| 引きこもりにとっての世界 | 自分の部屋だけ、かもしれない |

### 光と影（設計者のみ）

- 意識ある者が誰も訪れなければ、そこは **霧域のまま**
- 闇が光の前に現れると、**光と影** が生まれる
- 影があること ＝ そこに実体がある ＝ **存在がある**
- 光の中に物があって影が生まれるのではない — **光の中に闇があることで影が生じ、影が物体の存在を導く**

### 光と闇

文字通りの明暗ではない。**既知・存在** と **未知・可能性** の対比。

| | 光 | 闇 |
| --- | --- | --- |
| 本質 | あるもの、存在するもの | 考察・思考・未知・可能性 |
| 誤解しやすい点 | 完璧・全能ではない | 不完全ではない |
| 世界での役割 | 常に世界に満ち、ただ存在する | 解釈と可能性を与え、世界に形をつくる |

- **自我＝闇** — 意識を持つ者は闇を内包する
- PC が常に **d10（闇）** を振るのはこの性質の表れ

## 確定：スコーリオン

### 語源

- **scholion**（スコーリオン）— 写本の余白や行間に書かれた **注釈**
- **scholia**（スコーリア）— その複数形。ゲーム名「想成のスコーリア」の語源

### 世界形成との対応

| 段階 | 比喩 | 内容 |
| --- | --- | --- |
| 元の状態 | 余白のみ | 霧域 |
| 途中 | 注釈の積み重ね | 意識ある者の解釈・考察 |
| 確定 | 本文 | 共通認識となった場所・地景 |

### 界標用スコーリオン

**成立（設計者のみ — 旧案 2026-07-05）:**

1. 様々な者が霧域を訪れ、調査・考察を繰り返す
2. 「どのような場所か」の認識が徐々に収束
3. 注釈が一定量積み重なり **スコーリオンとして表出**
4. 界標に据える → その認識に形を与える（地景が拓かれる）

特定の誰かの認識が効くのではない。**様々な意識が干渉し、余白を埋めることで自然に収束・表出する。**

> 例：虹色の羽を拾う → 密林っぽいという認識が積み重なる → 極彩色の鳥が住まうジャングルという結論 → 誰かの手元にスコーリオンが現れる

**ルール方針（2026-07-07 — 議論中）:**

- **自然析出より街での作成** の方が PL に分かりやすい
- 探索・ボス等で **界標SC用の材料** を集め、**錬金で界標用SCを作成** → 霧域に据える
- GM が霧域／地景ごとに **解放条件** を設ける（ゲーム性・進行のノブ）
- 世界観（認識の収束）は **材料入手・調査のフレーバー** として残せる

**住人の見方（PL 向け可・要更新）:** 工房で作った道標を霧域に据えると地景が拓かれる（詳細は地景ログ）

### 想成（アイテム）— 2026-07-09 更新

- **想成用スコーリオンは廃止**（008 議題12）
- 錬金で作った **完成品そのもの** が個人の注釈の結晶
- 想成 ＝ 当該完成品を **携行** ＋ マナ → 効果（アイテムは消費しない）
- 界標用スコーリオン（場所の注釈）とは **別系統**

### 区別と効果の条件

- 両者とも遺物らしい見た目。入手場所が違うので持ち主は区別できる
- **何であるかを認識できない** → ガラクタ
- **使い道を規定できない** → 効果なし
- 認識世界の原則：**知覚と用途の規定** が効果の前提

## 確定：霧域・地景・街

| 場所 | 状態 | 備考 |
| --- | --- | --- |
| **霧域** | 余白。収束前 | 同じ場所に辿り着けない = 認識が収束していないから |
| **地景** | 界標で形を与えられた場所 | スコーリオン据置で拓かれる |
| **街** | 本文として確立しつつある | 長い注釈の積み重ね |

**PC 拠点の街：** 霧域探索で「長く続く道」と認識された道の端点に拓かれた開拓最前線。多くの者が住み、本文足り得るに至った。

**「認識がなくなる」とは：** 誰も知覚しなくなること ＝ そこに世界はない。

### 隣接地景とイベント

- 周囲が霧域のみ → **ランダム**（隣が未知 = 何が起きてもおかしくない）
- 隣接地景あり → **隣接地景イベント**（何があるか分かる = 何が起きるか想像できる）
- **本人が何を知っているか** の影響が大きい

### 世界のスコープ

- 他の集落・国・文明は **存在する**
- ただし **ルールに記載しない** — 街の由来・背景は GM と PC の設定による
- 霧域は **どこまでも広がる**（未開拓領域のメタファー）。世界の意識が大きさを結論づければ限りが生まれる
- 外部から街へたどり着くには、霧域の中に生成された **「歩ける一本の細い道」** を辿るしかない

## 確定：マナと四元素

### マナ

- 住人が世界のでき方について共有している **共通見解の形態**（認識の枠組み）
- 将来、原子論が支配的になれば **四元素 → 原子** へ移行する（設定上の時代変化）

### 四元素（住人層の常識）

- すべての物体は **火・土・風・水** の四元素からできていると誰でも知っている
- 物体を細かくすると **マナ** に置き換わる / マナを集めると何かが生まれる
- 四元素を知る ≠ 錬金できる。非錬金師には錬金は **魔法に見える**
- 錬金の到達点 ≒ **物を作り出せる** 程度（物体の形を書き換える力はない）

| 元素 | キーワード | 時間性 | 錬金イメージ | ルール反応 |
| --- | --- | --- | --- | --- |
| **火** | 熱、増殖 | 瞬発 | 起こす | 延焼 |
| **水** | 冷、減衰 | 緩慢・循環 | 替える | 流転 |
| **土** | 静、蓄積 | 長期 | 留める | 変動 |
| **風** | 動、消耗 | 一過性 | 運ぶ | 旋回 |

### 光・闇と四元素の関係

| 古典参照 | 本設定 |
| --- | --- |
| 四元素＝地上の万物 | **火土風水マナ** ＝ 住人の材料論 |
| エーテル＝天界・変形しない | **光** ＝ ただ存在するもの（材料ではない） |
| （古典に相当なし） | **闇** ＝ 解釈・可能性（形を与える働き） |

**住人・錬金師の見方（PL 向け可）：**

| | 光のマナ | 闇のマナ |
| --- | --- | --- |
| 存在 | 分解でたまに混じる。少ない | どこにでも感じるが掴みにくい |
| 体感 | 定まっている・変わりにくい | 定まらない・霧域で濃い |
| 錬金師の実務 | 反応しづらい | 反応の制御が難しい |
| 評価 | 使い道がわかっていない | 同上 |

**学者・錬金師の派閥（どちらも完全には正しくない）：**

| 派閥 | 主張 |
| --- | --- |
| マナ未知説 | 光・闇もマナの一種。使い道が不明なだけ |
| 非マナ説 | そもそもマナとは別物では |

**意図的に書かないこと（設計者のみ）：** 光＝世界の存在基底、闇＝形を与える解釈層、エーテル比喩。

## 確定：生物・意識

### 生物の位置づけ

- 霧域・地景に現れる生き物は **野生生物・原住民** と同じ扱い
- 生き物はマナからできている。化物だから特別なのではない
- 知っている者が訪れると「何かいるはず」という認識が働き、野生生物が現れ始める

### 意識を持つ者はすべて主体

- 意識を獲得した存在はすべて **世界を形作る主体**
- 地景について考え・見聞きすること自体が **注釈を貯める行為**
- 地景の住人が「街の住人は敵だ」と認識すれば、その認識は街に影響を及ぼす

### 機巧（マキナ）の設計者向け解釈

- 機械・計測器には **自我＝闇がない** — 尺度に沿って計測・操作を返すだけ
- 機巧は **機械に闇（知性）が宿った存在**
- 「素読」＝ 知性を意識的に持ち出さず、**ただ手順に沿って計測・操作する**
- → d12（光）を振れ、澱みなし。他種族は闇が介入せざるを得ない

### 使い魔

- 特定のマナを多く含み、人間と友好的な関係を築けた生き物
- 生きているだけでそのマナの入出力が大きく、**周囲にマナが漏れ出て漂う**
- 主人はその近くで、そのマナを **呼び出しやすくなる**
