## 議題 8-A: アイテムの本体論 — 3 モデル案

**目的:** 「錬金で何が生まれるか」「実体と想成の関係」を一貫した物語で説明する。

### モデル α: 二層（想型 + 実体）

```
錬金成功
  ├─ 実体 … 物質としての完成品（使用で消費・フル効果）
  └─ 想型 … 錬金師の中に刻まれる「形」（成功の副産物。消えない）
```

| 項目 | 内容 |
|------|------|
| **想成** | 想型 ＋ マナ → 不完全な再構成（弱い・一時的） |
| **実体** | 物質そのものを使う → フル効果 |
| **上限** | 想型の数 **に上限なし**（覚えたものはいつでも想成可）。制限は **マナ・アクション・弱さ** |
| **持ち込み** | **実体の物理在庫** のみ上限（瓶が重い・ポーチが有限 — 自然） |
| **フレーバー** | タイトル「想成のスコーリア」と直結。「一度成功した形は、マナがあれば再び呼べるが、完成品の力には及ばない」 |
| **弱点** | 想成が強すぎると実体の価値が下がる → **数値 tuning** で調整 |

**PL 向け説明（1 文）:** 「錬金で初めて形を掴む。あとはマナで粗く再現できるが、本物を使う方がずっと強い。」

---

### モデル β: 触媒（携行媒体）

```
錬金成功
  └─ 実体 … 通常は液体・道具として1個
       （任意）一部を「触媒」に封じる → 携行用の小さな媒体
```

| 項目 | 内容 |
|------|------|
| **想成** | **所持触媒** から発動（マナ消費）。触媒に **品質・副作用** が記録されている |
| **実体** | 触媒にしない分 → 通常アイテムとして消費使用 |
| **上限** | **触媒の所持数** に上限（小さく持てる数だけ — 物理的に妥当） |
| **レシピ記憶** | 触媒がなければ **その品は想成不可**（作ったことがある＝触媒を作った、とも言える） |
| **フレーバー** | 「マナだけでは形が定まらない。一度作った essence を触媒に留めておく」 |
| **弱点** | 「1回錬金で想成可能」の Round 1 合意と要調整 — **初回錬金で触媒1個も同時生成** 等で吸収可能 |

**用語候補:** 触媒 / 録符 / 端媒（依代より「媒体」と明示）

**PL 向け説明（1 文）:** 「強い想成には、工房で作った触媒が要る。触媒はポーチに数個だけ。」

---

### モデル γ: 単層（実体のみ・想成は実体の使い方）

```
錬金成功 → 実体1個のみ
  ├─ 実体使用 … 消費・フル効果
  └─ 想成使用 … 同じ実体を「展開」して消費せず弱効果（1個で2通り？）
       or 実体を手元に置かずマナだけ支払い（実体在庫が要る？）
```

| 項目 | 内容 |
|------|------|
| **想成** | 実体を **鍵** として参照。在庫0なら想成不可 |
| **上限** | 実体在庫 ＋ 携行上限 |
| **フレーバー** | シンプル。アトリエ（マリー）に最も近い |
| **弱点** | Round 1「1回錬金でいつでも想成」と **矛盾しやすい**。在庫切れ＝使えない |

**→ 現合意との整合が難しく、優先度低**

### Round 5: スコーリオン統合案 — α + 携行上限（2026-07-03）

### Round 6: 三層分離 — 錬金 / スコーリオン作成 / 想成（2026-07-03）

**ユーザー案:** 錬金はマナ非消費。**スコーリオン作成** でマナ消費 → 良さそう。  
**懸念:** レシピが「育つ」ニュアンスと両立するか。

#### 三層モデル（整理案）

```
┌─────────────────────────────────────────────────────────┐
│ ① 錬金（工房・手番）                                      │
│    消費: 素材のみ（マナなし）                              │
│    得る: 想型（知識）・熟練度+1・実体1個                    │
│    → レシピはここで「育つ」（スコーリオン不要）              │
└─────────────────────────────────────────────────────────┘
                          ↓ 任意・別手番
┌─────────────────────────────────────────────────────────┐
│ ② スコーリオン作成（工房・手番）                           │
│    消費: マナ ＋（空の想成用スコーリオン？ 素材？）         │
│    得る: その時点の想型を写した **注釈済みスコーリオン** 1個 │
│    → 携行枠を消費。想成の「鍵」                            │
└─────────────────────────────────────────────────────────┘
                          ↓ 探索・戦闘
┌─────────────────────────────────────────────────────────┐
│ ③ 想成（現地）                                            │
│    要: 注釈済みスコーリオン（当該レシピ）＋ マナ            │
│    効果: 弱い（実体より劣る）                              │
│    → スコーリオンが無いレシピは **現地で想成不可**           │
└─────────────────────────────────────────────────────────┘
```

| 層 | マナ | レシピ成長 | スコーリオン |
|----|------|-----------|-------------|
| 錬金 | **なし** | **熟練度↑**（想型が育つ） | 不要 |
| SC作成 | **あり**（案） | 当時の想型を **写す** | **生成** |
| 想成 | **あり** | 参照するのは **スコーリオンに写った形** | **必要** |

**「育つ」の説明（PL 向け）:**

> 何度も錬金すれば、そのレシピは **上手くなる**（工房のノート・腕）。  
> 想成用スコーリオンは **その時点の形の写し**。  
> 腕が上がったら、**新しいスコーリオンに書き直す**（マナが要る）。

→ 熟練度は **錬金だけ** で育ち、スコーリオンは **携行用のスナップショット**。  
古いスコーリオンを持ったままでも **知識・熟練度は工房側で進む** が、**現地想成の効果は古い写しのまま** — 更新には②が要る。

- ② と ③ のマナコスト関係

## 議題 11: 材料スロット方式 — [決定] 2026-07-07

**概要:** レシピごとに **材料スロット** を設け、スロット種別ごとに副作用の付き方が変わる。  
地景用SC・消耗品・想成用SCは **同一錬金パイプライン**、レシピが成果物タイプを決める。

### レシピの構成

| 要素 | 内容 |
|------|------|
| 材料スロット | 複数。各スロットは3種のいずれか（**混在可**） |
| 規定タグ | 完成品に必ず付くタグ（**本体**）。分解時マナ算出の根拠 |
| 想成マナ | ダイスプール ＋ 想成コスト |
| 目標値 | レシピごと |
| 成果物タイプ | 消耗品 / 想成用SC / 界標用SC 等 |

### 材料スロット3種

各スロットに **素材を1つ** 投入する。

| スロット種別 | 記述例 | 投入条件 | 副作用 |
|-------------|--------|----------|--------|
| **特定素材** | `虹色の羽` | その素材のみ | **なし**（このスロット由来） |
| **カテゴリタグ** | `<草>` | 当該カテゴリを持つ素材1つ | 投入素材の **全タグ** が副作用 |
| **性質タグ** | `火` 等 | 当該タグを持つ素材1つ | **指定タグ以外** のタグが副作用 |

- シナリオ錬金 → **特定素材** スロット
- 地景SC → 霧域固有素材（特定）＋ 性質／カテゴリタグを組み合わせ

**例 — 界標用SC（概念）:**

```
スロット1: 虹色の羽（特定）           → 副作用なし
スロット2: <霧域の手がかり>（カテゴリ）→ 投入品の全タグが副作用
スロット3: 火山（性質）               → 火山以外のタグが副作用
規定タグ:  <密林地景>
成果物:    界標用スコーリオン
```

### 完成品のタグ

| 種類 | 内容 |
|------|------|
| **規定タグ** | レシピに記載。完成品の **本体** |
| **副作用タグ** | スロットルールで付与。使用時の副次効果 |

### 分解・マナ

- 分解時のマナ算出は **規定タグのみ**
- **副作用タグは分解に含めない**

### 副作用の引き継ぎ

- **デフォルト: 次の錬金に引き継がない**（完成品ごとに副作用は完結）
- 特記がある場合のみ例外（呪い・工房汚染等 — 未設計）

### 旧ルールからの変更

| 旧 | 新 |
|----|-----|
| レシピ＝必要タグ、素材完全自由 | **スロット方式** |
| 必須外タグ全部副作用 | **スロット種別** で副作用範囲が決まる |

### 未決

- 性質タグとカテゴリタグの **データ上の区別**
- 同一素材の **複数スロットへの重複使用**
- 副作用タグの **使用時効果**
- 想成用SC — 錬金直接出力か
- `constants/alchemy.json` のスロット記述形式
