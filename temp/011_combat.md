## 議題 2: タイムライン — [一部決定] 2026-07-09

**採用:** backup の **タイムライン CT**（カウント進行・待機値・ラウンド周回・初期カウント 1d10÷2・同カウント PC 先）。

**2026-07-09 追記 — エンゲージ（データ欄名は間合）:**

タイムラインは **手番順・行動コスト（待機値）** に加え、**エンゲージ（キャラ間の相対位置）** も同一カウント軸上で管理する。シノビガミのベロシティシステムを参考に、カウント位置＝相対間合の代理とする。アイテム／武器データの欄名は **間合**（旧称・距離）。

| 項目 | 内容 |
|------|------|
| **間合の方向** | **後方のみ** 有効。自分の手番中、自身より手前（小さいカウント側）にキャラは存在しない |
| **同カウント** | 間合 **0**。同プロットに複数いれば範囲 `0` でも全員対象になりうる |
| **間合の変化** | 待機値による後方移動、**ノックバック**、（将来）銃器・特殊アイテム |
| **能動的な間合操作** | 専用行動は設けない。**カードで待機** を選ぶ形。狙ったカウントまで任意待機は不可 — 待機量は **手札（行動段階）** に従う |
| **絶対カウント指定** | 将来用。時限爆弾・ボス爆撃（黒鍵のアヴァンドナー的）・フィールド毒ガス等、**特定カウント** をエリアとして指定 |

**未決:** `{timeline.count_max}` 等の数値。draft へのエンゲージ追記（議題17確定後）。

## 議題 6: 攻撃・ダメージ算出 — [一部決定] 2026-07-09 / 2026-08-16

**決定:** 攻撃パイプライン（backup 5段）を採用。**武器はキャラ作成時の初期装備**。武器データに **間合・対象** を載せ、攻撃はそれを参照（[議題17](#議題-17-効果記述スキーマ錬金008-接続--一部決定-2026-07-09)）。

### 単体火力 — [方針] 2026-08-16

**アイテムの単体HP増減（主量）は `{品質}` を中心にする。** 品質式は動かさない。合わせるのは **武器の等級** と **敵HP**。

序盤は **2マナが並、3マナが強め**。直線目安はマナ1あたり約 +5.5（2マナ≈17）。Part4 の実測はそれより低い（下表）。2と3の差は到達する品質と、必要なら効果の質。単体の本文に強い倍率は足さない。

第二量（ノックバック等）、判定用の印記目標、範囲の総量は別枠。範囲は **1体あたり `{品質/2}`**（範囲攻撃の基準。2体で単体総量）。間合は系統の得意帯では二重に税を取らない。

熟練度は廃止済みなので、成長は **同一レシピを独立に錬金し直し、最良の完成品へ乗り換える**。試行 k 回の最良品質が「少し鍛えた」の量。検証は `sim/part4`。

### 等級・錬価 — 武器（防具）側

用語 **等級**（小さいほど強い）と **錬価＝⌊品質÷等級⌋** は、**係数表を使う攻撃（と防具）** に残す。表の整数比を守る除数。消耗品の単体火力には使わない。

\[
\text{錬価} = \left\lfloor \frac{\text{品質}}{\text{等級}} \right\rfloor,\qquad
\text{攻撃ダメージ} = \text{錬価} \times \text{表の係数}
\]

**規準セル** は **中量 × 中行動**（係数 **6**、待機 4）。等級の数字はここで切る。

\[
\text{中量中の1撃} = \left\lfloor \frac{Q}{G} \right\rfloor \times 6
\]

1撃の書き下しは **`{品質/7×C}`**（中量中なら `{品質/7×6}`）。除数 **7 は一旦確定**（2026-08-17）。**等級・錬価という用語は置かない方向**（[013](013_expression.md)）。

### 攻撃行動 — 受け側の順序 — [決定] 2026-07-11

```
1. 回避 … 攻撃効果を **そもそも受けるか**（完全回避で終了）
2. ダメージ算出 … 攻撃側の基本ダメージ
3. 防護 … **ダメージ量** の削減（境界をまたぐ場合は **カウントの障壁型** → 個人 `<障壁>` → 防御値。018 造園③）。**`<装甲>` はここではない**
4. 効果処理 … **耐性**（弱点・半減・無効・反射）
5. 適用 … **`<装甲>` が追加HPとして先に被ダメを吸う**（攻撃もアイテムも）→ 残りを本体HP
6. 効果後 … ノックバック・スタン等
```

| 段階 | 役割 |
|------|------|
| **回避** | 攻撃を **受けない** かどうか。**効果処理とは別** |
| **防護** | **ダメージ量** 決定用。**効果（耐性）とは無関係** |
| **効果処理** | **耐性** のみ。回復・付与・ダメージ **すべて** にも適用（アイテム経路） |

**アイテム使用／想成:** 上記 **4〜6**（効果処理以降）のみ。回避・防護は **通さない**。`<装甲>` は適用なのでアイテムでも吸う。

### 間合（相対カウント）— [決定]（旧称・距離 → 2026-08-07 改称）

使用者の **現在カウント** を基準に、**後方（大きいカウント側）** への相対帯。**この意味以外に使わない**（カウントを中心にした半径・AoE は間合と呼ばない）。

```
間合: 0~2  →  自身のカウント 〜 自身+2 まで
```

| ルール | 内容 |
|--------|------|
| 方向 | **後方のみ**。手番中、自身より手前のカウントにキャラはいない |
| 同カウント | 間合 **0** |
| 武器 | **間合** を指定可能（短剣 `0~0`、槍 `0~2` 等） |
| 銃器（将来） | クセの強い仕様可。例: スナイパー `間合: 3~6` + `対象: 単体` ＝ **遠方にいるキャラのみ** 選択可 |

**絶対カウント指定（将来拡張）** [方針決定・詳細未]:

- 時限爆弾 … 特定カウントを指定し、そのエリアの全員
- ボス能力 … 特定カウントへの爆撃（黒鍵のアヴァンドナー的）
- フィールド … 特定カウントに毒ガス等。そのカウントにいるキャラが継続的に状態を受ける

βの造園・爆弾時限は絶対指定ではなく **`対象: カウント`＋間合（相対帯）** で置く（[018](018_effect_catalog.md)）。爆弾④は「指定カウントが次に開始したとき」爆発。記法の細部はアイテム追加時に都度定義。

### 対象 — [決定]（2026-08-07: **カウント** 追加・用語整理）

**語の統一**

| 語 | 意味 |
|----|------|
| **コマ** | キャラクター（戦闘単位） |
| **カウント** | タイムライン上の目盛り＝**エリア**（行動順と位置を兼ねる。シノビガミ的） |
| **単体** | **コマ1つ** のみ。カウント（エリア）は単体では選べない |

| 対象 | 間合 | 意味 |
|------|------|------|
| **自身** | 省略可 | 使用者のコマのみ |
| **単体** | 要 | 間合内から **コマ1つ**（敵味方問わず・自身可）。**エリアは取れない** |
| **味方1体** / **敵1体** | 要 | 陣営＋コマ1つを明示 |
| **範囲** | 要 | 間合内の **全コマ**（敵味方問わず）。同カウント複数なら **全員** |
| **範囲選択** | 要 | 間合内から **コマを自由に選ぶ**（全員自動ではない） |
| **カウント** | 要 | 間合内から **エリア（マス）を1つ** 選ぶ。効果文の付与先はカウント自体 |
| **味方全体** / **敵全体** | **間合無視** | その陣営の **全コマ** |

**範囲の倫理（確定）:** 間合帯内のコマは **陣営フィルタなし** で効果対象。範囲回復で敵も回復する、範囲攻撃も同様。**陣営限定** は別記法（味方1体、味方全体 等）。

**単体の方針（追記 2026-08-14）:** `対象: 単体` は **敵味方どちらにも使える** のが基本。誤射・対象ずらしにも耐える。どちらかにしか使わせないものは `味方1体`／`敵1体` と明示する。

**印記の数値記法（018・2026-08-14）:** 効果文では `対象に <毒：{品質/10}> を付与する` のように **`<印記：値>`**。別行の `強度=` は寄せ替え予定。

**カウントへの付与（共通ルール・要約）** — 詳細は [018](018_effect_catalog.md):

- 本文の `対象に <印記> を付与` ＋ `対象: カウント` → 付与先は **エリア**
- そのマスにいるコマは、載っている印記を持つものとして扱う
- カウント上の印記は **tick 減衰しない**（障壁型の被ダメ消費は別）
- **そのカウントが終了したとき**、そのカウントから当該印記は消える（「終了」の定義は処理順サマリで確定）
- 強度 0 でも消滅（造園③の土壁など）

**例:**

```
# 近間合単体攻撃（短剣）— 単体＝コマ1つ
間合: 0~0
対象: 単体
効果: <斬> 強度=…

# 近間合範囲回復（敵も回復しうる）
間合: 0~1
対象: 範囲
効果: <回復> 強度=品質

# 味方だけ回復
対象: 味方全体
効果: <回復> 強度=品質

# 遠間合狙撃（将来）
間合: 3~6
対象: 単体
効果: <突> 強度=…

# 造園・滞在床（β）— 付与先はカウント（エリア）
発動: 滞在
間合: 0~3
対象: カウント
効果: 対象に <印記A>（仮）を付与する。強度={品質/10}
```

**攻撃行動:** 武器の **間合＋対象** を参照する想定（議題5・6と接続）。

## 議題 18: 耐性の再設計（弱点独立・複数付与・吸収／急所）— [一部決定] 2026-08-15

議題7の段階表（弱点／半減／無効／反射が同一スロット・排他）を崩す。弱点は体勢、耐性は量。複数は追加付与。競合は式。反射はゲートとして最先。

### 方針 — [方向合意]

| 項目 | 内容 |
|------|------|
| **段階をやめる** | 属性ごとに「どれか1段」ではない |
| **弱点は独立** | ノックバック1・スタン1。量の式には入れない |
| **耐性は複数可** | 半減・無効・反射・吸収・急所を同時に持てる。効果付与は **上書きせず追加** |
| **導出** | 競合は式で解く。**反射が最先**。無効は反射以外の最後に ×0 |
| **到達** | 「当たった／当たらなかった」を耐性の種類ごとに定義する |

### 2軸

| 軸 | 中身 | 例 |
|----|------|-----|
| **体勢（弱点）** | その属性が **届いた** とき KB1・スタン1 | `<弱点：火>` |
| **量（耐性）** | 通る大きさ・符号・行き先 | `<半減：火>` `<無効：火>` `<反射：火>` `<吸収：火>` `<急所：火>` |

同一属性に半減と弱点を並べてよい。急所は量の隙、弱点は体勢の隙。混ぜない。

**属性種 — [一旦] 2026-08-17:** 火・水・風・土・闇・光・無・斬・突・打（**10種**）。変異④のプールもこれ。

**看板:** 無効＋弱点、吸収＋弱点。量は通らない／回復になるが、弱点があれば同じ相を当て続けるとスタンが溜まる。[020 爆弾岩](020_data_builder.md) は吸収＋弱点で、**スタン最大到達時に爆発**（充填ゲージは使わない）。ぬるの初期は同属性半減、上位のつよ／めちゃ／ごくは無効／吸収／反射。

### 2026-08-15 合意（4点）

| # | 決定 |
|---|------|
| 1 | **急所は ×2**。1.5は不採用 |
| 2 | 反射・吸収の **2枚目は無意味**（フラグ）。反射は1枚でもその行を反射する。定義上いちばん強い |
| 3 | **無効＋弱点** も **吸収＋弱点** も、量の成否と別にスタンが溜まる。火を当て続けてスタンする爆弾岩を許容 |
| 4 | 反射は **素の量** を発生元へ直接。対象の他耐性も発生元の耐性も見ない。再計算しない |

### 種 — [方向合意]

| 種 | 対象 | 量 | スタック |
|----|------|-----|----------|
| **半減** | ダメージ・回復・付与すべて | 枚数ぶん ÷2 | 枚数 |
| **急所** | **ダメージのみ** | 枚数ぶん **×2** | 枚数 |
| **無効** | すべて | 1枚以上で最終 ×0 | フラグ（2枚目は無意味） |
| **吸収** | **ダメージのみ** | 最終量を HP 回復として適用 | フラグ（2枚目は無意味） |
| **反射** | すべて（012どおり付与も跳ねうる） | **素の量** を発生元へ。対象の他耐性は無視 | フラグ（2枚目は無意味）。**再反射なし** |

吸収は「攻撃のダメージ値を HP 回復にする」。回復や付与の符号反転ではない。

**素の量:** 効果処理に入る直前。攻撃なら **防護後**、アイテムなら効果文の量。防護は耐性ではないので、反射の前に済ませる。

### 導出式 — [方向合意]

行の属性フラグに含まれる属性の耐性だけを集める。切り捨ては **最後の除算1回**。

行に含まれる属性のうち、**反射が1つでもマッチ**すればその行は反射（他の量耐性は見ない）。

```
if 反射:
  発生元へ 素の量 を直接適用
  （発生元の回避・防護・耐性は見ない。対象自身には適用しない）
  対象は未到達 → 弱点なし
else:
  最終量 = {量 × 2^急所数 / 2^半減数}
  無効が1枚以上 → 最終量 = 0
  ダメージかつ吸収 → 対象の HP を最終量回復（HP減少ではない）
  それ以外 → 通常適用（ダメージなら HP 減、回復なら HP 増、付与なら強度）
  付与で最終強度 0 以下 → 付与失敗（012）
  対象は到達 → 弱点があれば KB1・スタン1
      （無効でも吸収でも乗る。量が0でもスタンは溜まる）
```

反射はゲート。半減・急所・無効・吸収より先。反射持ちに半減や吸収を重ねても、量の処理では反射だけが効く。

### 同時付与の読み（例・素の量10・火のみ）

| 所持 | 量 | 体勢 |
|------|-----|------|
| 半減 | ダメージ5 | — |
| 半減×2 | ダメージ2 | — |
| 急所 | ダメージ20 | — |
| 半減＋急所 | ダメージ10（打ち消し） | — |
| 無効 | 0 | 到達。弱点があればスタン |
| 急所＋無効 | 0 | 同上 |
| 半減＋吸収 | 5回復 | 到達。弱点があればスタン |
| 吸収＋無効 | 0（回復も0） | 到達。弱点があればスタン |
| 吸収＋弱点 | 10回復 | **スタン1・KB1**（爆弾岩：喰らいながら溜まる） |
| 無効＋弱点 | 0 | **スタン1・KB1**（通らないが崩れる） |
| 反射 | 発生元へダメージ10。対象は無傷 | 対象は未到達 |
| 反射＋吸収 | 発生元へダメージ10（吸収は無視） | 対象は未到達 |
| 反射＋無効 | 発生元へダメージ10（無効は無視） | 対象は未到達 |
| 半減＋弱点 | ダメージ5 | スタン1・KB1 |

### 付与は追加 — [方向]

012の同名印記は **最強1つのみが有効**。そのままだと半減の2枚目が死ぬ。

**案:** 耐性は強度＝枚数で **蓄積**（012の「効果文に明示がある場合のみ蓄積」例外）。`<半減：火：2>` で半減2枚。無効・吸収・反射は強度1で足りる（2枚目は無意味）。弱点はフラグ（複数付与しても KB1・スタン1のまま。仮）。

敵の生来耐性と効果付与は同じ袋。変異④を2回使うと半減が重なる。

**未:** 半減・急所の枚数上限。半減3＝1/8は後でキャップ可。

### 到達したか — [方向合意]

「当たった」を1語にしない。回避と無効を混ぜない（歯車④は D02 回避専用。D07 無効は別）。

| 用語 | 意味 |
|------|------|
| **未到達** | 効果処理に入らない、または反射で対象を飛ばした。効果後・弱点なし |
| **到達** | 対象に効果処理が乗った。量の成否とは別 |
| **適用** | 最終量が発生した（HP増減、付与成功） |

| 経路 | 到達 | 適用 | 「当たった」と呼ぶなら |
|------|------|------|------------------------|
| 回避成功 | しない | しない | 当たらなかった |
| 命中判定失敗（目潰等） | しない | しない | 当たらなかった |
| 半減・急所 | する | 量による | 当たった |
| **無効** | **する** | 量0。付与失敗 | **当たった**（通らなかった）。弱点は乗る |
| **吸収** | する | 回復として適用 | 当たった（代謝）。弱点は乗る |
| **反射** | **対象にはしない** | 発生元へ素の量 | 対象には当たらなかった |
| 弱点 | 到達していれば発火 | — | 量とは独立 |

無効を外れにしない。歯車の追撃（回避専用）と衝突するため。
