## 議題 2: タイムライン — [一部決定] 2026-07-09

**採用:** backup の **タイムライン CT**（カウント進行・待機値・ラウンド周回・初期カウント 1d10÷2・同カウント PC 先）。

**2026-07-09 追記 — エンゲージ（距離）:**

タイムラインは **手番順・行動コスト（待機値）** に加え、**エンゲージ（キャラ間の距離）** も同一カウント軸上で管理する。シノビガミのベロシティシステムを参考に、カウント位置＝相対距離の代理とする。

| 項目 | 内容 |
|------|------|
| **距離の方向** | **後方のみ** 有効。自分の手番中、自身より手前（小さいカウント側）にキャラは存在しない |
| **同カウント** | 距離 **0**。同プロットに複数いれば範囲 `0` でも全員対象になりうる |
| **距離の変化** | 待機値による後方移動、**ノックバック**、（将来）銃器・特殊アイテム |
| **能動的距離操作** | 専用行動は設けない。**カードで待機** を選ぶ形。狙ったカウントまで任意待機は不可 — 待機量は **手札（行動段階）** に従う |
| **絶対カウント指定** | 将来用。時限爆弾・ボス爆撃（黒鍵のアヴァンドナー的）・フィールド毒ガス等、**特定カウント** をエリアとして指定 |

**未決:** `{timeline.count_max}` 等の数値。draft へのエンゲージ追記（議題17確定後）。

### 攻撃行動 — 受け側の順序 — [決定] 2026-07-11

```
1. 回避 … 攻撃効果を **そもそも受けるか**（完全回避で終了）
2. ダメージ算出 … 攻撃側の基本ダメージ
3. 防護 … **ダメージ量** の削減（<装甲>→<障壁>→防御値）
4. 効果処理 … **耐性**（弱点・半減・無効・反射）
5. 適用 … HP 増減
6. 効果後 … ノックバック・スタン等
```

| 段階 | 役割 |
|------|------|
| **回避** | 攻撃を **受けない** かどうか。**効果処理とは別** |
| **防護** | **ダメージ量** 決定用。**効果（耐性）とは無関係** |
| **効果処理** | **耐性** のみ。回復・付与・ダメージ **すべて** にも適用（アイテム経路） |

**アイテム使用／想成:** 上記 **4〜6**（効果処理以降）のみ。回避・防護は **通さない**。

3. **効果後** … 弱点時ノックバック・スタン等

### 距離（相対カウント）— [決定]

使用者の **現在カウント** を基準に、**後方（大きいカウント側）** への相対帯。

```
距離: 0~2  →  自身のカウント 〜 自身+2 まで
```

| ルール | 内容 |
|--------|------|
| 方向 | **後方のみ**。手番中、自身より手前のカウントにキャラはいない |
| 同カウント | 距離 **0** |
| 武器 | **距離** を指定可能。間合いの違いを表現（短剣 `0~0`、槍 `0~2` 等） |
| 銃器（将来） | クセの強い仕様可。例: スナイパー `距離: 3~6` + `対象: 単体` ＝ **遠方にいるキャラのみ** 選択可 |

**絶対カウント指定（将来拡張）** [方針決定・詳細未]:

- 時限爆弾 … 特定カウントを指定し、そのエリアの全員
- ボス能力 … 特定カウントへの爆撃（黒鍵のアヴァンドナー的）
- フィールド … 特定カウントに毒ガス等。そのカウントにいるキャラが継続的に状態を受ける

記法・データ形式は **アイテム追加時** に都度定義。

---

### 対象 — [決定]

| 対象 | 距離 | 意味 |
|------|------|------|
| **自身** | 省略可 | 使用者のみ |
| **単体** | 要 | 距離内から **敵味方問わず1体**（**自身も可**） |
| **味方1体** / **敵1体** | 要 | 陣営＋体数を明示（例: 味方1体） |
| **範囲** | 要 | 距離内の **全コマ**（敵味方問わず）。同カウント複数なら **全員** |
| **範囲選択** | 要 | 距離内から **対象を自由に選ぶ**（全員自動ではない） |
| **味方全体** / **敵全体** | **距離無視** | その陣営の **全員** |

**範囲の倫理（確定）:** 距離帯内にいる対象は **陣営フィルタなし** で効果対象。範囲回復で敵も回復する、範囲攻撃も同様。**陣営限定** は別記法（味方1体、味方全体 等）。

**例:**

```
# 近距離単体攻撃（短剣）
距離: 0~0
対象: 単体
効果: <斬> 強度=…

# 近距離範囲回復（敵も回復しうる）
距離: 0~1
対象: 範囲
効果: <回復> 強度=品質

# 味方だけ回復
対象: 味方全体
効果: <回復> 強度=品質

# 遠距離狙撃（将来）
距離: 3~6
対象: 単体
効果: <突> 強度=…
```

**攻撃行動:** 武器の **距離＋対象** を参照する想定（議題5・6と接続）。
