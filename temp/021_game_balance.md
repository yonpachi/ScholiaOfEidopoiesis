# 021: 長寿RPG・学術のバランス方式とここへの写し

**日付:** 2026-08-18  
**ステータス:** [議論中]（調査。敵HP案は [020](020_data_builder.md)）

**関連:** [020](020_data_builder.md) / [013](013_expression.md) / [011](011_combat.md) / [008](008_alchemy.md) / `sim/part4`

公開された「公式の完全な敵バランス方程式」は、ドラクエにもアトリエにもほぼ無い。長寿作品がやっているのは、**見る指標を1〜2個に決めて、表かシミュレータで合わせ、連続戦闘で壊れたら直す**こと。

---

## このプロジェクトへの結論（先に）

感覚の代わりに置く観測は、次で足りる。新しい変数は要らない。

| 指標 | 意味 | いまの数字（初期） |
|------|------|-------------------|
| **倒す手数（TTK）** | 想定装備で敵1体を何手番で落とすか | 雑魚: 想成1／武器2。ボス: 想成10／武器17 |
| **落とされる手数（TTD）** | 敵の1撃でPCが何発耐えられるか | 火力を役で増やさない → 雑魚もボスも想成相当の1撃（品質20側） |
| **遭遇予算** | 1戦の総HP（または総点） | 雑魚3〜5＝60〜100。そこそこ2〜3＝60〜90。強敵1〜2＝40〜80。ボス＝200 |
| **帯** | その場のPCアイテムの強さ | 想定マナ×少し鍛え（k=3 p50）。初期雑魚HP20 |

D&DのCRは「目安の表＋必ず卓で確認」。PF2は「レベル×役の表」が公開されている一番きつい版。DQは公式数表が無く、公開されているのは「1か月手直し」「頭数制限」「特殊技が増えたら敵HPを上げた」系の失敗談。アトリエは敵HP式は非公開で、実質 **その帯の調合品に敵を合わせる**。ここはすでにそうしている（想定マナ）。

学術側に「唯一の正しい式」は無い。近年のTTRPG論文は、CRより **シミュレータ（勝率・手数）** の方が当たる、と繰り返し書いている。品質の実測は `sim/part4` がその役。

## D&D / Pathfinder（TTRPGでいちばん方式が露出している）

### D&D 5e

- 怪物に **CR（Challenge Rating）** と XP。遭遇はパーティーレベルごとの **XP予算** を使い切る
- 怪物1体のCRの出し方（2014 DMG「Creating a Monster」）:
  1. **守備CR**: HP帯とACから読む
  2. **攻撃CR**: 1ラウンド平均与ダメ（DPR）と命中／セーブDCから読む
  3. その平均をCRにする。特殊能力はHPやDPRに換算してから入れる
- 2014: 複数体には倍率（行動回数＝アクションエコノミーが効く）。2024: 倍率廃止・XPを足すだけ（SRD 5.2）。難易度は Low／Moderate／High
- 公式も「CRは近似。特殊能力は表から外れる。卓で確かめる」
- ソロボスは行動回数で負ける、は2024解説でも明記。頭数か追加行動が要る

ここへの写し: 想定マナ帯＝レベル、役×頭数＝予算の使い方。雑魚2＝強敵1は2014的な「体が多いほど厚い」。ボスHP×10で火力据え置きは「ソロの行動回数負け」を袋で吸っている。守備＝HP、攻撃＝品質火力、がCRの2軸と同じ。

### Pathfinder 2e（公開表がいちばん機械的）

[Building Creatures](https://2e.aonprd.com/Rules.aspx?ID=2874): **レベル行** × 各能力を Extreme／High／Moderate／Low。HPと1撃ダメージは別表。役（brute / soldier / spellcaster 等）で「どれをHighにするか」を決める。1撃がPCのHPを割らないよう、ダメージ上限が表にある。

ここへの写し: `f(マナ帯, 役)` はこれと同じ型。レベル＝マナ帯。HP列と火力列を分ける（いまの案どおり火力は雑魚品質に固定）。自由点＝Extremeだけ特技に振る、に近い。

## ドラゴンクエスト

公式の「敵HP＝プレイヤー攻撃×N」表は非公開。公開で使えるのは次。

- **基準攻撃の式が単純**（初期系の分析例: `(攻撃 − 防御/2) / 2` 前後。ターンを使う他の手段は、平均で素殴り以上になるよう置く）
- **DQ2（1987）:** 発売を1か月遅らせて手直し。序盤は1人旅なので死にすぎ、最初の大陸の同時出現を3体までに制限した。([shmuplations DQ2](https://shmuplations.com/dragonquestii/)) 中村光一は後半の敵バランスを「志に届かなかった」と後で言っている
- **DQ6:** 特技が増えて敵がすぐ死に、演出が終わる前に落ちたので敵ステを上げた（堀井）。手段が増えたらHPを足す、はここでも同じ型
- 堀井2000: 数値は自分でプレイして小さく直す。表で一発では決まらない

ここへの写し: 武器1撃が「素殴り」。想成はマナ＋手番なので素殴りより厚い（12対20）。複数体と連戦は頭数表と探索の危険度。1戦のHPだけ合わせない。PCの手段（想成・範囲）が増えたら敵HPか頭数を後から足す。

## アトリエ

敵ステの計算手順はインタビューに出てこない。出るのは次。

- 強さの主軸はレベルより **調合品**（品質・特性）。帯の敵は「その時点で作れるアイテム」に合わせないと、簡単すぎるか詰む。敵HPの計算手順はインタビューに出ない
- 従来作の長所として、福井（カリア）: 「すごく強いアイテムを作れればバトルは楽勝できる」——調合が勝敗の主軸であることが意図。カリアでは強力アイテムに待機とキャンセルを足して、戦闘操作も残す
- ユミアの反省（細井／カリアインタビュー）: RPG側が強くなりすぎて調合の手応えが落ちた。シリーズとしては調合を起点に戻す
- マナケミア系のターン／アイテム戦闘は backup の参照元。数値公開は無い

ここへの写し: **想定マナ×鍛え品質＝その帯の敵HP原点** は、アトリエ的に正しい軸。敵の1撃を同じ品質に揃えるのも、調合品が即死にならないため。想成の待機は「強いほど遅い」と同じ種類のブレーキ。

## 学術・準学術（入口）

「バランス論文」はジャンルが広い。戦闘数値に使える塊はこれ。

| 系統 | 何を言うか | 例 |
|------|------------|-----|
| **観測量** | TTK（倒す手数）、TTD（落とされる手数）、DPR（1ラウンドの与ダメ）、命中率 | D&D公式の守備CR／攻撃CRも実質これ。産業のRPGも同じ軸 |
| **動的難易度（DDA）** | プレイ中に敵を変える。卓のビルダー（作る前に点を決める）とは別メニュー | Hunicke ら MDA。XCOMは命中の裏修正で「体感」を合わせる（Jake Solomon）が、ここには要らない |
| **CRの限界** | 静的XPは位置・連携・連戦を見ない。モンテカルロの方が並びが変わる | [Fidelity Ladder（Zenodo, 2025）](https://doi.org/10.5281/zenodo.20837218)、[No Player Left Behind（AIIDE 2024）](https://doi.org/10.1609/aiide.v20i1.31883) |
| **怪物レベルの回帰** | Pathfinder怪物の数値からレベルを機械学習で近似できる＝**表に乗る一貫した設計がある** | [arXiv:2511.00084](https://arxiv.org/abs/2511.00084) / [arXiv:2607.09196](https://arxiv.org/abs/2607.09196) |
| **実践** | 数式の発明より「何を一定に保つか」 | 表はレベルと役（PF2）。点はGURPS。計測は勝率・残HP・手数 |

ここなら **雑魚＝想成1・武器2** が、業界がよく置く「雑魚の手数」ヒューリスティック。ボードゲーム／TRPGの公開方式としては PF2 の表が一番そのまま使える。

## いま採用してよい基準（020接続）

1. **帯の原点** 想定マナの少し鍛え品質＝雑魚HP＝基準火力（決定済みの初期20）
2. **手数** 雑魚は1〜2手番。ボスは10手番規模（200÷20）
3. **役の差はHPと頭数と自由点。** 1撃は同じ（PF2の「ダメージ列を上げすぎない」、アトリエの即死回避）
4. **役の袋** 雑魚20／そこそこ30／強敵40／ボス200（020。一旦。10刻み）
5. **表のあとで測る** 品質は Part4。戦闘手数は後で簡易でよい。DQ2どおり「1体」と「頭数・連戦」を分けて見る

まだやらない: CRのような中間ラベルを増やす。学術の強化学習遭遇生成。
