## 議題 3: プレイ形式 — [決定]（2026-07-03）

### GM・人数

| 項目 | 内容 |
|------|------|
| GM | **必要** |
| 基本構成 | **GM 1 + PL 4** |
| 一人回し | **可能であれば** ルール上もサポートしたい（目標。詳細ルールは未設計） |
| 人数別難易度 | **作れるといい** — 調整基準は未設計（別議題 or 各システムログで後日） |

### セッション単位・想定時間

| 項目 | 内容 |
|------|------|
| ゲーム内時間 | **1 セッション ＝ ゲーム内 1 日** |
| 標準の想定尺 | **1〜2 時間**（育成・日常進行向け） |
| 長時間セッション | ダンジョン攻略・イベント連続などで **5〜6 時間** になりうる |

**プレイのイメージ:**

- **平日など短時間** — 1 日分だけ進め、育成・工房・街の日常を回す
- **休日など長時間** — 本格的なダンジョン攻略、シナリオ本番、ロールを挟みたい展開のタイミングで時間を取る

### 未決（後日）

- 一人回し向けの GM 省略・代役ルール
- 人数（PL 1〜4 等）に応じた難易度・報酬・敵数の調整基準
