## 用語の整理

```
【錬金レイヤ】  規定タグ … 錬金消費・分解マナ（使用時効果なし）
                副作用タグ … スロット由来。タグマスタ効果文（使用時・主作用の後）
                カテゴリタグ … スロット条件
【効果レイヤ】  効果文 … レシピ／完成品に記載。MtG型（条件印記: 効果）
                印記 <> … 状態・属性フラグ・条件分岐
【解決レイヤ】  011 ダメージ処理・耐性・防護
```

| 用語 | 記法 | 役割 |
|------|------|------|
| **規定タグ** | `[]` | 錬金入力・分解。**使用時効果は発動しない** |
| **副作用タグ** | `[]` | タグマスタに効果文。使用時 **主作用の後** |
| **効果文** | テキスト | レシピ固有。対象への効果＋条件印記句 |
| **状態印記** | `<障壁>` `<毒>` 等 | 付与・強度・減衰 |
| **属性フラグ** | 主作用 **効果文ブロックの先頭** に1回。以降の行（`<特>:` 含む）に **継承** |
| **条件印記** | `<軽>`〜`<特>`、`<♤>`〜`<♣>` | 条件成立時のみ `:` 以降を発動 |
| **品質参照** | `{品質/2}` `{品質×3}` 等 — [013](013_expression.md) |
| **強度** | 数値 | **状態印記** のみ |

## 議題 1: タグ・印記・効果文の分担 — [一部決定] 2026-07-11

### 確定

| # | 決定 | 内容 |
|---|------|------|
| 1 | **属性タグなし** | `[火]` 等は **存在しない** |
| 2 | **規定タグ** | 錬金消費。**レシピごとに異なる**。使用時効果なし |
| 3 | **レシピ効果文** | **レシピごと unique**（アイテム一覧＝レシピ一覧） |
| 4 | **完成品** | **タグ名称のみ** ＋ 品質等。発動時 PC 側で解決 |
| 5 | **効果なしタグ** | **許可** |
| 6 | **副作用** | **効果文の全行処理が終わった後** |
| 7 | **複数対象** | 対象全員に **同じ効果** |
| 8 | **解決順** | 効果文を **上から順** に1行ずつ（手続き型） |
| 9 | **属性フラグ** | 主作用 **効果文の先頭** に `<火>` 等（副作用ブロックは別）。**以降の行にも及ぶ** |
| 10 | **各行** | **011 耐性** を通す（全効果） |

### 効果解決の流れ（確定）

```
1. タイミング／距離／対象 で対象決定
2. 効果文を **先頭行から順に** 処理
   各行: 条件判定（<特>: 等）→ 行頭属性フラグ → 効果本体 → 011 耐性
3. 副作用タグ（各タグの効果文も上から順）
4. 011 ダメージ後効果（弱点時スタン・ノックバック等）
```

### 走査例（ユーザー確認済み）

```
効果:
  <火> 対象の HP を {品質×3} 回復する
  <特>: 対象に <障壁> を付与する。強度={品質×0.3}
副作用タグ: [棘]

1. <火> … この使用の **主作用** のマナ属性＝火（以降の行に継承）
2. 1行目 … HP回復 → 011 耐性（弱点:火 等）
3. 2行目 … 特行動なら障壁付与（属性＝火のまま）→ 011 耐性
4. [棘] … 副作用ブロック（別。必要なら先頭に属性フラグ）
```

### 効果文 DSL

→ **[013_expression.md](013_expression.md)** に委譲。計算は **`{}`**、除算は **端数切り捨て**（都度記載不要）。

### 効果文の例

```
# 火属性回復＋特行動障壁
効果:
  <火> 対象の HP を {品質×3} 回復する
  <特>: 対象に <障壁> を付与する。強度={品質×0.3}

# 複数条件
  <特>×<♡>: 対象に <障壁> を付与する。強度=5
  <特>+<重>: 対象の HP を {品質/2} 追加回復する
```

## 議題 9: 条件印記（行動段階・スート）— [決定] 2026-07-11

**タグではなく印記** として追加。β から **必須**。

### 印記一覧（条件）

| 印記 | 条件 |
|------|------|
| `<軽>` | プレイカードが **軽行動**（A〜3） |
| `<中>` | **中行動**（4〜7） |
| `<重>` | **重行動**（8〜10） |
| `<特>` | **特行動**（J〜K） |
| `<♤>` | スペード（火） |
| `<♡>` | ハート（水） |
| `<♢>` | ダイヤ（土） |
| `<♣>` | クラブ（風） |

### 記法（MtG 型）

```
<条件印記>: 効果
<条件A>×<条件B>: 効果    … **AND**（両方成立）
<条件A>+<条件B>: 効果    … **OR**（どちらか成立）
```

- 条件を満たすとき **のみ** `:` 以降を **その行として** 実行
- 効果文は **上から順** に走査
- **想成スート割引**（011）は **ルール記述**。効果文に **含めない**

### 例

```
<特>: 対象に <障壁> を付与する。強度=品質×0.3
# → 特行動でカードをプレイして使用／想成したときのみ発動
```

## 議題 3・7: 属性印記と 011 耐性 — [決定] 2026-07-11

| 項目 | 内容 |
|------|------|
| **記述** | 主作用 **効果文の先頭** に `<火>`（副作用ブロックは別） |
| **意味** | その **使用の主作用** のマナ属性＝火。**以降の行に継承** |
| **重複** | 複数回書いてもよい |
| **耐性** | **効果処理**（011）の **耐性** 部分のみ。全効果に適用 |
| **例** | `<火>` 回復 → 弱点:火 → 回復はするが **スタン・ノックバック** |
| **例** | `<火>` 障壁付与 → 弱点:火 なら **付与時** にも弱点／反射が面白く効く |
| **半霊** | 属性印記には **不适用** |

**011 改定:** [011 議題7](011_combat.md) — **効果処理**（旧ダメージ処理の耐性部分）。**回避・防護は別軸**（行動）。弱点と反射は **排他**。

## 議題 2: 状態印記の共通ルール — [決定] 2026-07-11（転記 2026-08-06）

**方針:** backup / 既存案を採用。**強度を持つ印記**の共通挙動と `<毒>` の個別定義を下記に転記。`<障壁>` `<装甲>` `<回避>` 等の **個別効果** は一覧マスタ作成時に追記。

### 強度

- **強度を持つ印記**のみ、数値の **強度** を持つ
- **強度を持たない印記**は、減衰・強度減少・「強度を減らす」効果の対象に **ならない**

### 同名印記の共存

- **同名**の印記は、同時に **最強の1つだけ** が有効
- それより **弱い同名印記** は **待機** し、有効な印記が消えたとき **繰り上がる**
- `<障壁>` など有利印記も **同じルール**

### 再付与（上書き）

- デフォルトは **蓄積しない**
- 新しい強度が **現在より大きい** とき、有効印記の強度を **更新**（最強の値に置き換え）
- 新しい強度が **現在以下** のとき、有効印記は変わらず **待機** に入る（上書き失敗）
- **蓄積**（加算など）は、効果文に明示がある場合のみ
- **上書き失敗**（待機に入るだけ）は **付与とみなさない**（半霊の ±1 等の「付与時」効果は発動しない）

### 強度 0・除去

- 強度が **0 以下** になった印記は **即時に除去** される
- 「強度を減らす」効果で 0 になった場合も同様（**解除** 効果とは別扱い）
- 強度 **0** での付与は **できる** が、付与直後に除去ルールで **即時解除** される
- 強度 0 でも **付与は成立** する（将来の「印記を付与した時」効果用）。**半霊** の ±1 は **0 でも発動**
- 011 耐性等で最終強度が **0 以下** になった場合、付与は **失敗**（付与扱いにならない）

### 減衰・解除の用語

| 用語 | 意味 |
|------|------|
| **発動時減衰** | 印記が **効果を発動した直後** に強度を減らす（例: `<毒>` の tick 後） |
| **終了時減衰** | **手番終了時** など、別タイミングで強度を減らす（印記ごとに定義） |
| **開始時解除** | **自分の手番開始時** などに印記を除去する（印記ごとに定義） |
| **解除**（効果文） | 明示的な解除効果。強度減少による 0 除去とは **別** |

### 半霊（再掲）

強度印記の **付与時** のみ ±1（005）。属性フラグ・条件印記には不适用。

### 状態印記 `<毒>` — [決定] 2026-08-06

| 項目 | 内容 |
|------|------|
| **発動** | 対象の **自分の手番開始時** |
| **効果** | その時点の強度と **同量** の HP ダメージ |
| **発動時減衰** | 上記のあと、強度 **−1** |
| **強度 0** | 除去（共通ルール） |
| **再付与** | 共通ルール（最強のみ有効・弱い方は待機） |
| **β** | `<猛毒>` 等の派生印記は **なし**。強度の **上限なし** |
| **解毒** | 専用印記・レシピは **β では用意しない**。明示的 **解除** 効果で除去可能 |

**例（強度3で付与、毎手番 tick）:** 開始時 3 ダメージ → 強度2 → 次手番 2 ダメージ → 強度1 → … → 1 ダメージ → 強度0 → 除去。

### その他の状態印記（概要・個別定義は後日）

| 印記 | backup 継承（概要） |
|------|---------------------|
| `<障壁>` | 被ダメで **消費**（同名・最強ルールは上記共通） |
| `<装甲>` | 防御 **行動** で取得 |
| `<回避>` | 回避 **行動** で取得。上限9 |
