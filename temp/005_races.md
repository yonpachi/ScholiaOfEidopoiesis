## 開示: 判定時能力（仮決定・現行採用）

### 人間 — 翻転

- **タイミング:** 反応中
- **コスト:** 発動時点でのダイス総数を、最終達成値から差し引く
- **効果:** 未反応ダイス1つを対象。出目を裏返す。対象を反応済みにする

### 獣裔 — 転機

- **タイミング:** 反応中
- **効果:** ダイス1つを振り直す
  - 新出目 < 元出目 → 出目 **1**
  - それ以外 → 新出目を採用
- 振り直し後、対象は **未反応**

### 機巧 — 素読

- **タイミング:** ダイスロール前
- **効果（1）:** プール内 **d10 を1個 d12 に換装** してロール（d10 が無い場合は使用不可）
- **効果（2）:** この判定では **澱みが発生しない**（出目 1 も 1 として読む）
- d20 の ⌊出目÷2⌋ は **素読の効果ではない**（[002](002_dice_system.md) / `docs/rules/dice.md` の通常達成値換算）
- 反応は通常どおり

> **2026-07-03:** 素読の効果は **換装 + 澱みスキップの2つ** に整理。d20 半減を能力効果から除外。

### 錬生 — 進化（3択から1つだけ）

#### 修正

- **タイミング:** 澱み発生前
- **効果:** 次の **澱み発生** を **スキップ** する

#### 発現

- **タイミング:** 達成値決定
- **効果:** 反応済みダイスの個数の半分（端数切り捨て）を達成値に加算

#### 収束

- **タイミング:** 反応開始前
- **効果:** プール内の **すべてのダイス** の出目を **⌊面数÷2⌋** にそろえる。その後 **反応も澱みも行わず** 達成値を決定する
- **コスト:** なし（反応フェーズを行わない）

> 均質化効果（旧称: 変異・案E）。能力名 **収束** に改称（セットA、2026-07-02）。

### 付喪 — 手馴

- **タイミング:** 反応開始前
- **効果:** プール内の **すべてのダイスを振り直す**
- **コスト:** 発動時点の n を最終達成値から減算

> 2026-07-03: 1枚振り直し → **全振り直し + −n**（sim で avg_Δ ≈ +4.3 に収束）。

### 半霊 — 越境

- **タイミング:** 反応中（反応可能が0になる前）
- **効果:**
  - **反応が1つも起きなかった:** 最終達成値に **+1** する
  - **反応済みが1つ以上ある:** 反応済みダイス1つを **未反応** にする。反応フェーズを **続行** する

> **2026-07-03:** 反応0時 +1 フォールバック追加（議題27–28）。反応強制前提（002 議題7）。

## 議題 3: 判定時能力 sim — [議論中]

### 目的

- 種族ごとの判定時能力が、**意図した強さ順**（002 / part1 前提）と整合するか検証
- 能力間の相対パワーを定量化（期待達成値リフト等）

### 前提（002 から継承）

- 反応モデル: **貪欲最善手**（greedy）
- 属性ダイス強度順: d12 > d10 > d6(大) > d4/d8/d20 > d6(小)

### 能力ごとのパイプライン位置

| 能力 | タイミング | pkg/dice 拡張の要点 |
| ---- | ---------- | ------------------- |
| 素読 | ロール前 | d10→d12 換装、澱みスキップ |
| 翻転 | 反応中 | 裏返し + 反応済み + 終了時コスト（nDice） |
| 転機 | 反応中 | 条件付き振り直し、未反応維持 |
| 手馴 | 反応開始前 | 全ダイス振り直し + 達成値 −n |
| 越境 | 反応中 | 反応0→+1 / 反応済み→未反応 + 続行 |
| 進化・修正 | 澱み前 | 次の澱み発生をスキップ（→ 達成値換算で −1 換算なし） |
| 進化・発現 | 達成値決定 | reacted 数 // 2 加算 |
| 進化・収束 | 反応開始前 | 全出目を ⌊s/2⌋ に均質化 → 反応・澱みスキップ → 達成値合算 |

### sim 指標（案）

```
能力リフト(種族, プール) = E[達成値 | 能力を最善タイミングで1回使用] − E[達成値 | 能力なし]
```

- プール: part1 と同様、全構成列挙 or 代表プールセット
- ホムンクルス: **修正 / 発現 / 収束** を別々に計測（3能力分）
- 能力使用タイミング: **greedy**（達成値最大化の発動タイミング・対象も最善）

## 議題 5: 判定時能力 — 処理難易度ランキング — [議論中]

**目的:** ルール簡素化の優先順位づけ。ホムンクルス「3 択があること」自体は問題視しない。**各能力1つの処理・説明・運用の難しさ** を評価する。

**評価軸（TRPG テーブル運用の目線）:**

1. 判定フローへの割り込み（反応ループの途中で状態を戻す・プールを変える等）
2. 例外ルールの数（澱み無効、d20 半減、裏返し、循環±1 等）
3. プレイヤー/GM が追う状態（反応済みフラグ、発動時 n の記憶、対象 eligibility）
4. 初見説明に要する時間

### ランキング（難しい → 易しい）

| 順位 | 能力 | 種族 | 要点 |
| ---: | ---- | ---- | ---- |
| 1 | **変異** | ホムンクルス | 反応中に **最高値ダイスを判定から除外** + 残り **循環+1** + 発動時 n の **終了時コスト**（旧版。改稿前） |
| 2 | **越境** | 半霊 | **反応済み**ダイスを **未反応に戻し** 反応ループを再開。対象は「反応済みかつ再反応可能（Triggers）」に限定され、低 n では対象が無いことも多い。ループの巻き戻し感がテーブルで分かりにくい |
| 3 | **素読** | 機巧 | ~~d20 半減を含む二重例外~~ → **換装 + 澱みスキップの2効果**（d20 半減は基礎ルール。2026-07-03 整理） |
| 4 | **修正** | ホムンクルス | 澱み発生前に **次の澱み1回をスキップ**。澱みフェーズの理解が前提。効果自体は1行だが、「次」とはいつかを GM が裁定する必要がある |
| 5 | **翻転** | 人間 | 未反応1つを **裏返し** → 反応済み + **発動時 n を最終から減算**。裏返し表と終了時コストの2点。反応中の定位置介入なので変異ほどは壊れない |
| 6 | **転機** | 獣裔 | 振り直し + 「下振れなら 1」+ **未反応のまま**。振り直し自体は直感的だが、未反応維持で反応が続く点を説明する必要がある |
| 7 | **手馴** | 付喪 | 振り直し + 「上振れのみ採用」+ 反応済み + 達成値 **+1**。転機の「安全版」に flat ボーナスが乗った程度。テーブルで一番説明しやすい部類 |

## 議題 6: 進化・変異 — 改稿案 — [議論中]

### 設計前提（合意）

- **種族能力のモチベ:** プレイヤーは **達成値を上げる** ために使う。減点・ギャンブルで期待値を下げる案は採用しない
- **処理は1つ:** 各能力の **効果** は1操作・1文に絞る。強さの調整は **使用条件** と **コスト（最終達成値からの減算）** で行う
- **フレーバー:** 遺伝子由来の3能力名 **修正 / 発現 / 収束**（セットA）。旧称「変異」は **収束** に改称（2026-07-02）
- **旧版変異（除外 + 全体循環+1 + 発動時 n コスト）** および交差・吸収・中央化は不採用

### 改稿案 B：一点突然変異 — **[却下]**

sim 上 +2 / +3 / −1 / −3 いずれも強すぎる、または方針と合わないため不採用。

### 改稿案（現行試行）：ダイス1つ除外 — **[sim 上強すぎ・保留]**

**フレーバー:** 不要な遺伝子が脱落する。プールから1個消え、残りで判定が進む。

| 項目 | 内容 |
|------|------|
| タイミング | **反応開始前** |
| 効果（1つ） | プール内 **ダイス1つ** をこの判定から **取り除く** |
| 使用条件 | なし |
| コスト | なし |

**sim 所感（2026-07-01）:** 直感上「1枚 ≈ −5点」程度に見えるが、反応の **やり直し + greedy 最善除外** のため三択の **40%超** を占め、Hom 全体も強すぎる。実装は `scoreHomunculusMutateDPrime` に残るが、**採用見送り**。

**処理負荷:** 「ダイス1つ除外」の1操作（低）。強さの問題。

---

### 変異 — 次候補3案 — [議論中・sim 未実装]

案B / 案D′ / 全反転 / 全振り直し / ダイス1つ除外 など **変異系の試行は sim 上いずれも強すぎた**。  
修正・発現・変異の **枠組み（3択・遺伝子モチーフ）は維持** し、**変異枠** を次の3案から選んで試す。

共通方針:

- **効果は1操作・1文**（処理1つ原則）
- **達成値を上げる** 使用モチベを満たす
- 条件・コストは sim 比較で詰める（初期案は **なし** 想定）
- sim: 対象・組み合わせは **greedy 最善**（プレイヤー任意はルール確定後）

#### 交差 — **[却下]**

sim 上・体感とも不採用（2026-07-02）。

#### 吸収 — **[却下]**

sim 上・体感とも不採用（2026-07-02）。

#### 中央化 — **[却下]**

sim 上・体感とも不採用（2026-07-02）。

**変異は元の実装（最高値除外 + 循環+1 + 発動時 n コスト）に sim を戻した**（2026-07-02）。

### 案E：均質化 — **[sim 試行中]**

**フレーバー:** 遺伝子が中庸に収束する。出来上がっていないから、極端な出目を捨てて「とりあえずここまで」に持ち込む。

| 項目 | 内容 |
|------|------|
| タイミング | **反応開始前** |
| 効果（1つ） | プール内 **すべてのダイス** の出目を **⌊面数÷2⌋** にそろえる |
| 反応 | **行わない**（澱みフェーズも省略） |
| 使用条件 | なし |
| コスト | なし（反応を捨てる機会費用） |

**設計意図:**

- 修正（澱み前）・発現（達成値決定）と **タイミングが被らない**
- 良出目では反応・発現の方が上振れするため **自己限定型**（敗戦処理・失敗不可判定の保険）
- 効果は `DieValue(s, ⌊s/2⌋)` の和のみ。レシピ固定なら **出目に依存しない定数**

**早見表（達成値換算）:**

| ダイス | 出目 | 達成値 |
|--------|------|--------|
| d4 | 2 | 2 |
| d6 | 3 | 3 |
