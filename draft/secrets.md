| 層             | 誰が知る                         | 置き場の目安                                 |
| -------------- | -------------------------------- | -------------------------------------------- |
| **PL 向け**    | プレイヤーに提示する設定         | `docs/about.md` 等                           |

## スコーリオン（Scolion / Scholia）

- **scholion**（スコーリオン）— 写本の余白や行間に書かれた **注釈**
- **scholia**（スコーリア）— その複数形。ゲーム名「想成のスコーリア」の語源

世界形成の比喩として：

| 段階     | 比喩           | 内容                                                                 |
| -------- | -------------- | -------------------------------------------------------------------- |
| 元の状態 | 余白のみ       | 何の記述もない空間（**霧域**）                                       |
| 途中     | 注釈の積み重ね | 人々の解釈・考察が **scholion** として重なる                         |
| 確定     | 本文           | 一定の人数の **共通認識** となったものが、確固たる場所として存在する |

「余白から本文になるまで」の間に、意識を持つ者たちの読み・解釈が注釈として蓄積されていくイメージ。

### 界標用スコーリオンの成り立ち（設計者のみ）

1. 様々な人が **霧域** を訪れ、調査・考察を繰り返す
2. 「どのような場所か」が徐々に **収束** していく
3. 注釈が一定量積み重なると、**スコーリオン** として **表出** する
4. それを **界標** に据える → その認識に **形を与える**（地景が拓かれる）

人々の解釈・注釈の結晶がスコーリオン。**住人はこのメカニズムに気づいていない。**

### 住人の見方（PL／住人層）

- スコーリオンは **界標** として扱う
- 霧域で見つけ、据えることで **その地景へ迷わず辿り着ける** ようになる
- 「注釈の表出」という真因は知らない — 遺物・道標としての常識

### 想成用スコーリオン（設計者＋ルール接続）

- **個人の注釈** が表出したもの — 界標用（多数の収束）とは別系統
- 錬金師がアイテムを **はっきりと思い描く** ことで生じる（ハンターハンターの念能力に近いイメージ）
- 想成＝その個人注釈 ＋ マナ で、登録した「形」を弱く呼び出す（ルール詳細は `008_alchemy.md`）

界標用と想成用は **別種**（009 想定 B と一致）。

### 区別と効果の条件

- どちらも **遺物らしい** 見た目 — 入手場所が違うので、持ち主本人は区別できる
- **それが何であるかを認識できない** と、ただのガラクタになる
- **使い道がわからない／使い道を規定できない** 限り、効果は発生しない

→ 認識世界の原則：**知覚と用途の規定** が効果の前提。

## 世界の成立

- 世界は **意識を持つもの**（人間に限らない可能性あり）によって形成される
- 最初から地形や法則があったわけではなく、認識の蓄積と共有によって **縁取られていく**
- **世界自体が存在するかは分からない** — 様々な人が「どのようにあるか」を把握することで、はじめて成り立つ

### 認識の濃淡（人によって違う）

同じ場所でも、人によって「そこに世界がどこまで存在するか」はバラバラ。

| 例                                         | 認識の厚み                   |
| ------------------------------------------ | ---------------------------- |
| 「あの方角には火山がある」                 | 薄い                         |
| 「麓は火山灰で覆われている」               | やや厚い                     |
| 「あの木にはかつて私が掘った落書きがある」 | 確定的                       |
| 引きこもりにとっての世界                   | 自分の部屋だけ、かもしれない |

**共通認識があるときだけ**、その場所に世界は「そこにある」。

### 一人でも形を作れるか

はっきりと形を思い描き、**誰かに伝える能力** があれば、**たった一人** でも世界を形作りうる。
ただし通常は、多様な解釈の重なりで場所が安定する。

### 街

長い注釈の果てに **本文として確立しつつある** 場所。

**PC の拠点となる街：** 霧域探索のなかで **長く続いていると認識された道** の **端点** に拓かれた土地。開拓最前線として人が集まり、多くの者が住むようになった結果、本文足り得るに至った。

（小さな例：流浪人が「少し開けている」と解釈した地に家を立て、訪問が重なり集落→街になる — 同じ仕組みの縮図）

### 「認識がなくなる」とは

「共通認識が崩れる」＝ **誰もその場所を知覚しなくなる** こと。  
世界は人ごとに見え方が違うので、知覚する者がいなくなれば、そこに世界はない。

## 霧域・地景・街

| 場所 | 状態 | メモ |
|------|------|------|
| **霧域** | 余白。記述・収束前 | 同じ場所に辿り着けないのは **認識が収束していない** から |
| **地景** | 界標で形を与えられた場所 | スコーリオン据置で拓かれる |
| **街** | 本文として確立しつつある | 道の端点・開拓最前線（上記） |

### 隣接地景とイベント（ゲーム ↔ 世界観）

- イベント表に **隣接する地景からの効果** を適用するイベントあり
- 周囲が **霧域だけ** なら **ランダム** なイベント

認識世界としての読み：

- 隣に **何があるかわからない** → 何が起こってもおかしくない（ランダム）
- **既に何があるかわかっている** → 何が起こるか想像がつく（隣接地景イベント）
- **本人が知っているかどうか** の影響が大きい

## マナ

現時点では、住人が世界のでき方について共有している **共通見解の形態** が「マナ」に過ぎない。

- 住人層の認識フレーム — 世界の真因（認識による形成）そのものではない
- **将来：** 原子論が支配的になると、世界の認識は **四元素 → 原子** へ移行する（時代・設定上の変化）

## 四元素（住人層の常識）

### 万物四元素

- **すべての物体** は **火・土・風・水** の四元素からできている、と誰でも知っている
- 物体を細かくしていくと **マナ** に置き換わる
- マナを集めると **何かしらが生まれる** — そう信じている
- 四種類のマナから物が **出来上がっている**、という見方

### 錬金との距離

- 四元素を **知っている** ≠ **錬金ができる**
- 非錬金師にとって錬金は **魔法のように見える**（現代の「誰でも家で簡単化学」vs 本格化学の差に近い）
- **鋼の錬金術師** のように物体の **形そのものを書き換える** 力は **ない**（アトリエ的）
- 錬金の到達点 ≒ **物を作り出せる** 程度

### 分解・想成との接続

| 操作 | 住人の理解 |
|------|------------|
| **分解** | 物体 → 細かく → マナ |
| **錬金** | マナを集めて何かを生む |
| **想成** | 錬金師が **成立過程・成分の知見** を持つから **はっきり思い描ける** → マナで一時再現（念能力に近い） |

マナが **集まりすぎた地点** から **化物** が出る、と危惧する者もいる。

使い魔に **マナを多く含む生物** を使役するのは、住人にとって不思議ではない。

### 各元素のイメージ（住人層）

| 元素 | キーワード | ルールとの接続（設計メモ） |
|------|------------|----------------------------|
| **火** | 熱、増殖 | 延焼 — 活性化・強烈化・触媒的に広がる |
| **水** | 冷、減衰 | 流転 — 状態の入れ替え・洗い流し・形を替える |
| **土** | 静、蓄積 | 変動 — 止まっているが **微調整** できる安定 |
| **風** | 動、消耗 | 旋回 — 方向転換・運搬・使い切り |

**加えて持てそうな軸**（未確定・住人が語りうる程度）：

| 元素 | 時間性 | 触れ方 | 錬金での役割イメージ |
|------|--------|--------|----------------------|
| 火 | 瞬発 | 触れると変わる | **起こす** — 反応を始める |
| 水 | 緩慢・循環 | 浸すと変わる | **替える** — 形を入れ替える・薄める |
| 土 | 長期 | 載せると定着 | **留める** — 形を保持・蓄える |
| 風 | 一過性 | 通すと運ぶ | **運ぶ** — 移す・散らす・方向を変える |

古典の **乾湿** とも一部重なる：火＝乾、水＝湿、土＝乾、風＝湿（住人の教材程度に使える）。

## 光・闇と四元素の関係

### 住人の見方（現状）

- 四元素＝ **モノの材料** として誰でも知っている
- 光・闇＝ **なんとなく別枠**（四元素で説明しきれない領域）
- **マナとして存在は知っているが、働きはわからない**

### 住人視点の書き方（方針案）

**設計者層のニュアンスはそのまま。** 住人層には **本体論ではなく現象** だけ載せる。

| 層 | 光・闇の扱い |
|----|--------------|
| 設計者 | 存在／解釈・可能性（本ファイル） |
| 住人 | 「あるが、よくわからないマナ」— **観察できること** だけ |
| PL 向け | 当面は四元素中心。光・闇は **ルール上の属性名** として触れる程度で可 |

**住人が観察できそうなこと**（現象のみ）：

| | 光のマナ | 闇のマナ |
|---|----------|----------|
| 存在 | 分解で **たまに** 混じる。四元素より **少ない** | **どこにでも感じる** が、単体では **掴みにくい** |
| 体感 | **定まった**・変わりにくい・完成品に近い | **定まらない**・霧域で濃い・試行錯誤のときに増える |
| 錬金師の実務 | **そもそも反応しづらい**。レシピに混ぜにくい | **反応の制御が難しい**。操作の揺らぎそのもの |
| 錬金師の評価 | 使い道が **あまりわかっていない** | 同上 |
| 民間の語り | 「定マナ」「澄マナ」等（未確定） | 「候マナ」「淀マナ」等（未確定）— **善悪の比喩にしない** |

**学者・錬金師の派閥**（争いがある — どちらも完全には正しくない）：

| 派閥 | 主張 |
|------|------|
| **マナ未知説** | 光・闇も **マナの一種**。存在は認めるが **使い道がわかっていない** |
| **非マナ説** | そもそも **マナとは別のもの** ではないか — 四元素の枠組みに収まらない |

**住人の通説（半分正しい／用途は不明）：**

- 「四元素で説明できない分が、光と闇として **余る**」
- 「光は **もう決まった** マナ、闇は **まだ決まっていない** マナ」
- 上記 **派閥** の論争 — 完全な説明はない（認識世界と整合）

**意図的に書かないこと（設計者のみ）：** 光＝世界に満ちる存在、闇＝形を与える解釈層、エーテル比喩。

**PL ルールとの接続：** 判定は常に d10 から始まるが、住人はこれを「闇マナ」として **意識していない** 可能性が高い。「基本のマナ」「最初に足すマナ」程度の実務感覚。

### エーテル（現実世界の参照・設計メモ）

古典の四元素説では、地上の **火・空気（風）・水・土** に対し、アリストテレスは天体を構成する **第五元素・エーテル（アイテール）** を置いた。中世錬金術では **クィンタ・エッセンチア（第五精髄）** として、四元素の **深奥に閉じ込められた天界のエッセンス** と考えられた。

本設定への当てはめ（設計者メモ）：

| 古典 | 本設定の読み |
|------|--------------|
| 四元素＝地上の万物 | **火土風水マナ** ＝ 住人の **材料論**（物体の説明枠） |
| エーテル＝天界・純粋・変形しない | **光** ＝ ただ **存在する** もの（世界に満ちる。材料ではない） |
| （古典に相当する概念なし） | **闇** ＝ **解釈・可能性**（形を与える働き。材料でも天界でもない） |

光をエーテル的「存在の基底」、闇を「読む・描く・注釈する」層と分け、**四元素はあくまでモノの語彙** に留める、という三層構造。

## 光と闇（設計者層）

文字通りの明暗ではない。**既知・存在** と **未知・可能性** の対比。

|                | 光                           | 闇                                       |
| -------------- | ---------------------------- | ---------------------------------------- |
| 本質           | あるもの、存在するもの       | 考察・思考・未知・可能性                 |
| 誤解しやすい点 | 完璧・全能 **ではない**      | 不完全 **ではない**                      |
| 世界での役割   | 常に世界に満ち、ただ存在する | 解釈と可能性を与え、**世界に形をつくる** |

- **光** — すでにそこにある。それ自体は解釈を要しない
- **闇** — 光に対する読み・問い・まだ形になっていないもの。世界を「読む」働き

## 意識とダイス（ルールとの接続メモ）

意識を持つものは、未知や可能性（闇）を内包する。

- PC は判定で常に **1d10（闇）** を振る — 上記の性質の表れ
- **自我＝闇** — 解釈・揺らぎが挟まる。錬金操作にも大いに解釈が介在する

### 機巧（マキナ）

判定時、一時的に **自我を失い**、機械として振る舞う。

- 世界を **解釈せず**、ただ **あるものとして受け取る** 存在になる
- だから **d12（光）** を振れ、**澱みが発生しない**
- 自我を捨てる＝闇を外に出す＝存在側（光）に寄って操作する、というイメージ

※ ダイス上の光＝d12・闇＝d10 は `docs/rules/dice.md` と一致。種族能力「素読」「明鏡止水」と接続。

## 生物・野生生物・化物

### 基本的な位置づけ

- 霧域・地景に現れる敵は、**野生生物**・**原住民** と同じイメージ
- 生き物は **マナからできている** — 化物だから特別なのではない
- マナを多く含んだ生き物は存在するが、それは **特殊な事例**
- 外見はファンタジー寄りだが、世界観上は「その場所にいる生き物」に過ぎない

### 認識と生物の出現（設計者のみ）

- 「生き物がいる地点」という認識が積み重なれば、野生生物が出る
- 誰も知らない状態で探索すれば、生物ゼロの地景が成立することもある
- **知っている人間が訪れると「何かいるはずだ」という想像が働き、結果として野生生物が現れ始める**
- これは認識が地景の内容を決定する、という原則の自然な帰結

## 意識を持つ者と世界形成

### すべての意識が主体

- **意識を獲得した存在はすべて世界を形作る主体**
- 生き物が地景について考え・見聞きするだけで、**その地景への注釈を貯める行為** になる
- 知性レベルに関わらず、**認識する存在足りうる**

### 闇が光の前に現れる瞬間

- 意識ある者が誰も訪れなければ、そこは **霧域のまま**
- 一度闇が光の前に姿を現すと、そこに **光と影** が生まれる
- 影があること ＝ **そこに実体がある** ということ ＝ **存在がある**
- 光の中に物があって影が生まれるのではない。**光の中に闇があることで影が生じ、影が物体の存在を導く**

### 認識が地景に及ぼす影響

- 地景の住人が「街の住人は敵だ」と認識すれば、その認識は街に影響を及ぼす
- 認識が積み重なれば、**攻撃行動** すら起きうる
- 意識ある者同士の認識が干渉し合い、世界が動く

### 機巧（マキナ）の設計者向け解釈

- **機械・計測器には自我＝闇がない** — 尺度に沿って計測・操作を返すだけ
- 数値を **解釈するのは闇（知性）** の仕事
- 機巧は **機械に闇（知性）が宿った存在**
- 「素読」＝ 機巧が意識的に知性を持ち出さず、**ただ手順に沿って計測・操作する** こと
- 他の種族は知性をもって行動するため、闇が介入せざるを得ない

### 使い魔

- **特定のマナを多く含み、かつ人間と友好的な関係を築けた生き物**（ペットに近い）
- マナを多く含む生き物は、生きているだけでそのマナの **入出力が大きい**
- 結果として、その生き物の **周辺にマナが漏れ出て漂っている**
- 主人はその使い魔の近くで、**そのマナを呼び出しやすくなる**

## スコーリオン成立の仕組み（設計者のみ）

### 認識の伝播

特定の誰かの認識が効く、というわけではない。**様々な意識が互いに干渉し、余白に何かを埋めることで、いつか誰かの手元に表出する**。

例：

> 「虹色の羽を拾った」（個人の経験）  
> ＋「あの辺りは密林っぽい」（複数人の薄い認識）  
> ＋「極彩色の鳥が住まうジャングル」（新たな結論）  
> → 様々な意識が積み重なり **「ここは極彩の密林だ」という表出が生じる**  
> → スコーリオン（その地景の界標）が誰かの手元に現れる

不思議物体として **突然**現れるのではなく、認識の蓄積が自然に **形として収束** した結果。

## 世界のスコープ

### 他の集落・国・文明

- **他の集落・国・文明は存在する**
- ただし **ルールには記載しない** — GM と PC の設定による
- PC の拠点街の由来（王国の先兵隊 / 亡国の王族 / ならず者の溜まり場 / 研究者の足がかり 等）も GM・PC 次第

### 街へのアクセス

- 外部からたどり着くには、霧域の中に生成された **「未確定だが歩ける」一本の細い道** を辿るしかない
- 霧域を彷徨って偶然たどり着く例はあるが、**基本は道を通る**

### 霧域の広さ

- 霧域は **どこまでも広がっている**（未開拓領域のメタファー）
- 時代が進み、**世界の意識が「世界の大きさ」を結論づけた時**、はじめて限りが生まれる

### 「世界の真理を探求してもいい」の意味

- **PL・キャラとして：** 霧域の正体、世界の始まり、マナとは何かに思いを馳せるキャラクターがいていい
- **PL・GM・設計として：** ルールブックが答えを明示するつもりはない。このシステムを通じて現実世界の見方を改めて考えてもいい
- この背景設定は **設計者の世界の見え方** を根底に据えたもの — フレーバーとして感じてもらえれば十分

| **設計者（私たち）** | 世界の真因すべて（本ファイルの内容） |
| **GM** | ルールブックに書かれた世界観設定・フレーバーのみ |
| **PL** | PL 向けに提示された設定のみ |

- 究極の真因（認識世界・光闇の本質・スコーリオン成立など）は **設計者のみ**
- ルールブックで匂わせる程度はよい。ただし **規定しすぎない**（面倒な設定のあるシステムになるだけ）
- これは **「何も答えのないシステム作り」の指針** であり、テーマ性

### 光・闇の「使い方がわかる」程度

錬金師にとっての光・闇は、「**使い方がよくわからないが、なんとなくうまくいった**」の積み重ね。

> 絶対的な形も存在理由も動作原理も存在しない — AI も、世界も、使い方・見え方がなんとなくわかっているだけ。  
> 深くまでは分からないけれど、使えることがある。それで十分。
