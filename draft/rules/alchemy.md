# 錬金

関連: [ダイスシステム](../../docs/rules/dice.md) / [戦闘](combat.md) / [種族](../../docs/rules/ancestry.md)

---

## 概要

工房で素材を投入し **完成品** を作る。完成品は探索・戦闘で **携行** し、**使用** または **想成** する。

| 操作                   | 場所             | 消費   | 結果                                              |
| ---------------------- | ---------------- | ------ | ------------------------------------------------- |
| **錬金**               | 街・工房（手番） | 素材   | 完成品1個。レシピを記憶する                       |
| **使用**               | 探索・戦闘       | 完成品 | 効果を発動する（[戦闘](combat.md)）               |
| **想成**               | 探索・戦闘       | マナ   | 効果を発動する。完成品は残る（[戦闘](combat.md)） |
| **界標用スコーリオン** | 霧域             | 据置   | 地景を固定する                                    |

---

## 錬金（工房）

### 入力

1. **レシピ** を1つ選ぶ。
2. レシピの **材料スロット** に、条件を満たす素材を1つずつ投入する。
3. 投入した素材は消費する。錬金時にマナは消費しない。
4. 錬金は街の **手番** を1消費する。

### 判定

[ダイスシステム](../../docs/rules/dice.md) に従い、レシピの属性ダイス（想成マナ）をプールに加えて判定する。

- **目標値** … レシピごとに定める。
- **達成値** … 判定の結果。目標値以上で成功する。

### 成功

- **完成品** を1個得る。

### 失敗

- 素材は返却されない。
- 完成品は得られない。

---

## レシピ

### 構成要素

| 要素         | 内容                                       |
| ------------ | ------------------------------------------ |
| 材料スロット | 複数。各スロットは3種のいずれか（混在可）  |
| 規定タグ     | 完成品に必ず付くタグ。分解時マナ算出の根拠 |
| 想成マナ     | 判定プール用属性ダイス。想成時の支払いマナ |
| 目標値       | レシピごと                                 |
| 成果物タイプ | 消耗品 / 界標用SC / 装備 等                |

### 材料スロット3種

各スロットに **素材を1つ** 投入する。

| スロット種別     | 記述例     | 投入条件                  | 副作用                  |
| ---------------- | ---------- | ------------------------- | ----------------------- |
| **特定素材**     | `虹色の羽` | その素材のみ              | なし                    |
| **カテゴリタグ** | `<草>`     | 当該カテゴリを持つ素材1つ | 投入素材の **全タグ**   |
| **性質タグ**     | `火` 等    | 当該タグを持つ素材1つ     | **指定タグ以外** のタグ |

### 完成品のタグ

| 種類           | 内容                                         |
| -------------- | -------------------------------------------- |
| **規定タグ**   | レシピに記載。完成品の本体                   |
| **副作用タグ** | スロットルールで付与。使用・想成時の副次効果 |

副作用タグは **次の錬金に引き継がない**。

### 分解・マナ

完成品または素材を分解すると、**規定タグ** に対応するマナを得る。副作用タグは分解に含めない。

---

## 完成品の属性

### 品質

完成品に記録する数値。**達成値** と **副作用タグ** を含む。

戦闘・探索での効果量は、品質にカテゴリ別係数を掛けて求める（[戦闘](combat.md)）。

### 重量

すべての完成品に **重量**（軽量 / 中量 / 重量）を設定する。

[戦闘](combat.md) の待機値に影響する。

| 重量 | 待機値補正                                 |
| ---- | ------------------------------------------ |
| 軽量 | {{ alchemy.item_weight_correction.light }} |
| 中量 | {{ alchemy.item_weight_correction.mid }}   |
| 重量 | {{ alchemy.item_weight_correction.heavy }} |

## 使用・想成

|                | 使用                                     | 想成                                   |
| -------------- | ---------------------------------------- | -------------------------------------- |
| 前提           | 当該 **完成品** を携行している           | 同左                                   |
| コスト         | 完成品を **消費** する。マナは支払わない | **マナ** のみ。完成品は消費しない      |
| 効果（消耗品） | 完成品に記録された効果                   | **使用と同じ効果**                     |
| 効果（装備）   | 装備スロットで常時効果                   | 一時バフ（障壁・防護等。レシピに記載） |

完成品を携行していなければ、想成できない。

戦闘中の手順は [戦闘](combat.md) を参照する。

---

## 携行

| 枠             | 内容                                                   |
| -------------- | ------------------------------------------------------ |
| **アイテム枠** | 消耗品等。想成に使う完成品もここに入れる               |
| **界標SC枠**   | 界標用スコーリオン（据置前）。アイテム枠とは別         |
| **装備枠**     | 装着中の武器・防具（[キャラクター作成](character.md)） |

アイテム枠の上限は **{{ alchemy.carry_limit.item }}**（工房の成長で拡張する）。

界標SC枠の上限は **{{ alchemy.carry_limit.landmark_sc }}**。
