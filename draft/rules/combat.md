# 戦闘

関連: [錬金](alchemy.md) / [キャラクター作成](character.md) / [種族](../../docs/rules/ancestry.md) / [ダイスシステム](../../docs/rules/dice.md)

探索中のイベントとして戦闘が始まる。探索と **トランプの山札・手札** を共有する。戦闘終了後、特記がなければ探索に戻る。

---

## タイムライン

戦闘は **タイムライン** 上でカウントが進む CT 方式で進行する。

- タイムラインは **0 〜 {{ combat.timeline.count_max }}** のカウントで構成する。
- 0 から 1 ずつ進み、現在カウントにコマがあるキャラクターが **手番** を行う。
- 手番終了時、**待機値** ぶんコマを後方へ進める。最大カウントを超えた分は **次ラウンド** の対応カウントへ進める。
- 現在カウントの全コマが手番を終えたら、次のカウントへ進める。
- 最大カウントから 0 に戻ったとき、**ラウンド** が1進む。

### 同カウント内

同カウントに複数キャラがいる場合、**PC から** 処理する。PC 同士の順番は PL が決める。敵同士の順番は GM が決める。

### 戦闘開始

1. **初期カウント** … 各 PC・敵は 1d10 を振る。出目の半分（端数切り捨て）を初期カウントとし、コマをその位置に置く。
2. **手札** … 探索中の山札をそのまま使う。盤面に配置済みの札は戦闘では使わない。各 PC・GM は山札から **3枚** を引く。山札が尽きたら、捨て札をシャッフルして新しい山札を作る。

---

## 手番

自身の手番では、次の順に処理する。

1. 行動宣言
2. カードプレイ
3. 行動段階決定
4. 行動解決
5. カウント変更
6. 手番終了

### 行動宣言

この手番で行う **行動** を1つ宣言する。

### カードプレイ

宣言した行動に対し、手札を **1枚** プレイする。手番では **必ず1枚** プレイする。

手札が **0枚** になったら、即座に山札から **3枚** 補充する。

### 行動段階

プレイしたカードの **数字** から **行動段階** を決める。

| カードの数字 | A〜3 | 4〜7 | 8〜10 | J〜K |
| --- | --- | --- | --- | --- |
| 行動段階 | 軽行動 | 中行動 | 重行動 | 特行動 |

どの数字でも任意の行動を宣言できる。効果側の指定がなければ、数字は行動種別を制限しない。

### カードのスート

| スート | スペード | ハート | ダイヤ | クラブ |
| --- | --- | --- | --- | --- |
| 対応属性 | 火 | 水 | 土 | 風 |

闇・光のマナはカードスートでは得られない。

**Joker** は、使用時に任意のスート・任意の数字として宣言できる。

### 待機値

```
待機値 ＝ 行動段階の基本待機値 ＋ 重量補正
```

| 行動段階 | 軽行動 | 中行動 | 重行動 | 特行動 |
| --- | --- | --- | --- | --- |
| 基本待機値 | {{ combat.base_action_wait.light }} | {{ combat.base_action_wait.mid }} | {{ combat.base_action_wait.heavy }} | {{ combat.base_action_wait.special }} |

**重量補正** は、行動で参照するアイテム・武器・防具の重量による（[錬金](alchemy.md) 参照）。

アイテム・武器を使わない行動では、重量補正は 0 とする。

行動段階は、待機値以外に **効果量** の算出にも使う。

---

## 行動一覧

| 行動 | 概要 |
| --- | --- |
| **攻撃** | 武器（または素手）で対象にダメージを与える |
| **防御** | 防具で `<装甲>` を得る |
| **回避** | 防具で `<回避>` を得る |
| **分解** | アイテム・素材を消費しマナを得る |
| **使用** | 完成品を **消費** し効果を発動する（マナなし） |
| **想成** | 携行中の完成品を指定し **マナ** を支払って効果を発動する（完成品は残る） |
| **離脱** | 戦闘離脱の準備をする |

消耗品・完成品によるダメージ・回復等は **攻撃行動ではない**。**使用** または **想成** として処理する。

---

## 攻撃

武器（[キャラクター作成](character.md) の初期装備等）または素手で対象にダメージを与える。

待機値 … 行動段階 ＋ **武器の重量** 補正。

1. 攻撃に使用する武器と対象を指定する。
2. 武器属性・マナ属性を確認する。
3. ダメージを算出する（品質・等級・攻撃係数。行動段階と武器重量を参照する）。
4. 攻撃効果を適用する。
5. [ダメージ処理](#ダメージ処理) を行う。

### 武器属性・マナ属性

- **武器属性** … 斬・打・突
- **マナ属性** … 火・土・風・水・闇・光・無。武器に設定がなければ **無属性** とする

---

## 使用

[錬金](alchemy.md) の **使用** に従う。

1. 携行中の **完成品** を1つ選び、消費する。
2. 完成品に記録された効果を処理する。消耗品は **想成と同じ効果** とする。
3. マナは支払わない。

待機値 … 行動段階 ＋ **完成品の重量** 補正。

ダメージ等が発生する場合は [ダメージ処理](#ダメージ処理) に従う。

---

## 想成

[錬金](alchemy.md) の **想成** に従う。

1. 携行中の **完成品** を1つ指定する。
2. 完成品の **想成マナ** を支払う。
3. **スート割引** … プレイしたカードのスートに対応する属性マナが支払いに含まれる場合、その属性を **1つ無料** にできる。
4. 完成品は消費しない。
5. 完成品に記録された効果を処理する。消耗品は **使用と同じ効果** とする。

待機値 … 行動段階 ＋ **完成品の重量** 補正。

種族能力 **明鏡止水**・ **炉火純青** は [種族](../../docs/rules/ancestry.md) に従う。

---

## 分解

1. アイテムまたは素材を1つ選び、消費する。
2. その完成品の **規定タグ** に対応するマナを得る。
3. プレイしたカードのスートに対応するマナを **1** 得る。

待機値 … 行動段階の基本待機値のみ（重量補正なし）。

種族能力 **窮余一策** は [種族](../../docs/rules/ancestry.md) に従う。

---

## ダメージ処理

確定したダメージを対象に適用する。次の順に処理する。

1. **耐性**（弱点 / 半減 / 無効 / 反射）
2. **回避** … 回避値を持つ場合、1d10 ≦ 回避値で成功 → ダメージ0・追加効果なしで終了する
3. **防護** … `<装甲>` → `<障壁>` → 防御値 の順
4. **ダメージ適用** … HP を減らす
5. **ダメージ後効果** … ノックバック、スタン値等

### 耐性

- **弱点** … ノックバック1・スタン値1を追加する（反射時は弱点追加効果なし）
- **半減** … ダメージを半分（端数切り捨て）にする
- **無効** … ダメージを0にする（追加効果は発生しうる）
- **反射** … ダメージを発生元に適用する。反射ダメージに回避・防護・追加効果は適用しない

### 効果量

ダメージ・回復・印記強度等は、完成品または武器の **品質** にカテゴリ別係数を掛けて求める。

---

## ノックバック

**ノックバック X** … 対象のコマを X カウント後方へ進める。タイムライン周回時は次ラウンドの対応位置へ移す。

---

## スタン

各キャラクターは **スタン値** と **スタン最大値** を持つ。

スタン値 ≧ スタン最大値のとき:

1. スタン値を 0 に戻す（超過分は持ち越さない）
2. 手札からランダムに1枚選ぶ
3. 選ばれたカードの行動段階の基本待機値分、ノックバックを受ける
4. 選ばれた手札を捨てる

スタン値は戦闘中に蓄積する。戦闘終了時に 0 に戻す。

---

## 離脱

- 宣言から次の自身の手番まで、回避・防護処理を行えない
- 次の手番開始時に戦闘から離脱する。コマをタイムラインから除去する。再参加できない
- 待機値 … 行動段階＋防具重量の後 **+2** する
- 効果・イベントで離脱不可と指定されている場合は離脱できない

---

## 戦闘不能

HP ≦ 0 で **戦闘不能** になる。コマをタイムラインから除去する。

**使用** または **想成** 等、効果によって解除できる。

解除後は、解除した味方の **次の手番開始** から行動できる。戦闘不能中も **マナは失わない**。

---

## 戦闘終了

- 敵コマが全て除去された → **勝利**
- PC コマが全て除去された → **撤退**（勝利なし）
- PC 全員が戦闘不能 → **全滅**
- **簡易戦闘** のラウンド上限 **{{ combat.simple_combat_rounds }}** に達した → 終了
- 効果・イベントによる終了指定

探索中イベントとしての戦闘は **簡易戦闘** とする。ラウンド上限まで生存するか、敵を全滅させれば勝利とする。

終了時、残り手札は捨て札へ送る。特記がなければ探索に戻る。

---

## 全滅

PC 全員が戦闘不能になった場合、 **全滅** として扱う。

1. 戦闘中であれば、即座に戦闘を終了する
2. 素材カゴの素材を **{{ combat.wipeout.material_loss_ratio }}** 以上ランダムに失う
3. 探索に参加していた PC 全員の HP を **{{ combat.wipeout.hp_after }}** にする
4. その時間の行動を終了し、街に帰還する
