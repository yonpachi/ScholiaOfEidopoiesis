# ダイスシステム

> **WIP** — `temp/002_dice_system.md` から整理した下書き。探索・戦闘への適用は別文書。

## 概要

判定では **d10（闇）** を基本とし、必要に応じて **属性ダイス** をプールに加えて振る。  
出目は **反応** フェーズで操作でき、最終的に各ダイスを換算して合計した値が **達成値** となる。

達成値は、目標値との比較（成功/失敗）や、錬金など他システムでの成果値として使われる。

---

## ダイスプール

### 構成

ダイスプールは、原則 **d10（闇）1個** から始め、判定ごとに属性ダイスを追加して構築する。

| 属性 | ダイス | 反応（キーワード） | 反応条件 | 反応効果                                                     |
| ---- | ------ | ------------------ | -------- | ------------------------------------------------------------ |
| 火   | d4     | 延焼               | 3以上    | 自身の出目を **4** にする。d4を1個追加して振り、未反応とする |
| 土   | d6     | 変動               | 6        | 他ダイス1個の出目を **循環±1 または ±2** する                |
| 風   | d8     | 旋回               | 8        | 他ダイス1個を **半回転** する                                |
| 水   | d20    | 流転               | 20       | 他ダイス1個を **振り直す**                                   |
| 闇   | d10    | 覚醒               | 10       | 他ダイス1個を **裏返す**                                     |
| 光   | d12    | 昇華               | 12       | 他ダイス1個の出目を **最大値** にする                        |

- 属性はタグ・印記（`<火>` `<土>` など）と対応する。
- ベースの d10 は **闇属性** とみなす（上表の闇 d10 と同一）。

### プールの決め方（錬金時）

錬金の判定では、**レシピに指定された属性ダイス** だけをプールに追加して振る。  
このダイス判定そのものでは **マナを消費しない**。

## 用語

| 用語                  | 意味                                                  |
| --------------------- | ----------------------------------------------------- |
| **循環**              | 出目を環状に数える。最大値の次は 1、1 の前は最大値    |
| **未反応 / 反応済み** | 各ダイスはどちらか一方の状態を持つ                    |
| **反応可能**          | 未反応であり、反応条件を満たしている                  |
| **循環±k**            | 出目を k 進める、または k 戻す                        |
| **半回転**            | 面数 N のダイスを、循環で **N÷2** だけ進める          |
| **裏返す**            | 出目を反対側にする（**N＋1−出目**）。d4 なら 1↔4、2↔3 |
| **振り直す**          | そのダイスをもう一度振り、出目を置き換える            |
| **澱み**              | 達成値の計算で、そのダイスを **−1** として扱う        |

---

## 判定の流れ

### 1. ダイス決定

ダイスプールにダイスを追加し、今回の判定で振るダイスを決める。

### 2. ダイスロール

プール内のダイスを **すべて** 振り、すべて **未反応** にする。

### 3. 反応

反応可能なダイスがあり、かつプレイヤーが反応を選ぶ限り、次を繰り返す。

1. 反応可能なダイスを1つ選ぶ（**任意**。選ばなければ反応フェーズを終了する）
2. そのダイスの反応効果を適用する（対象ダイス、土の ±1/±2 も **任意**）
3. そのダイスを **反応済み** にする
4. 新たに反応条件を満たした未反応ダイスがあれば、反応可能になる

**任意性:** 反応可能でも、反応しなくてよい。反応するダイス・効果の対象・土の ±1/±2 はいずれもプレイヤーが選ぶ。

**状態:** 反応効果で出目が変わっても、ダイスの **未反応 / 反応済み** の状態は変わらない。

**対象:** 効果の対象を選ぶとき、特に指定がなければ、未反応・反応済みを問わず選べる。

**連鎖:** 火（延焼）で追加された d4 が反応条件を満たせば、さらに反応可能になる。適用するかは任意。

### 4. 澱み

次の出目のダイスに **澱み** が発生する。

| ダイス    | 澱みになる出目 |
| --------- | -------------- |
| 水（d20） | **3以下**      |
| それ以外  | **1**          |

### 5. 達成値決定

各ダイスを次のように換算し、合計を **達成値** とする。

| ダイス               | 達成値への換算                 |
| -------------------- | ------------------------------ |
| 澱み                 | **−1**                         |
| 水 d20（澱みでない） | **⌊出目 ÷ 2⌋**（端数切り捨て） |
| その他（澱みでない） | 出目そのまま                   |

目標値が指定されているとき、**達成値 ≧ 目標値** なら成功、未満なら失敗とする。

## 属性ダイスと反応効果

### 火（d4）— 延焼

- **反応条件:** 3以上
- **反応効果:** 自身の出目を **4** にする。ダイスプールに **d4 を1個追加** して振り、それを未反応として扱う

### 土（d6）— 変動

- **反応条件:** 6
- **反応効果:** 自身以外のダイス1個を選び、出目を **循環±1 または ±2** する

### 風（d8）— 旋回

- **反応条件:** 8
- **反応効果:** 自身以外のダイス1個を選び、**半回転** する

### 水（d20）— 流転

- **反応条件:** 20
- **反応効果:** 自身以外のダイス1個を選び、**振り直す**

### 闇（d10）— 覚醒

- **反応条件:** 10
- **反応効果:** 自身以外のダイス1個を選び、**裏返す**

### 光（d12）— 昇華

- **反応条件:** 12
- **反応効果:** 自身以外のダイス1個を選び、出目を **最大値** にする
