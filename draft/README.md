# 下書き（draft）

このフォルダは、議論ログ（`temp/`）から公開ドキュメント（`docs/`）へ移す**中間段階**の下書き置き場です。

- Git 管理対象（バックアップ・履歴用）
- MkDocs には掲載しない（`docs/` のみ公開）

## フロー

```
temp/ で話し合う → draft/ に下書き → docs/ に正式化
```

## 構成

- `rules/` — ルール文書の下書き
  - `alchemy.md` — 錬金（α″・材料スロット）
  - `combat.md` — 戦闘（タイムライン・カード・使用／想成）
  - `character.md` — キャラクター作成（初期装備）
  - `ancestry.md` — 種族（docs コロケーション）
- `glossary.md` — 用語集の下書き（必要時）
