`txt/`のファイルは他AIへの比較質問の回答まとめですね。把握した上で、こちらは「できる限り多く」の系統案を出します。

品物の「品物らしさ（見た目・製法・使い方）」を軸に、責務カバーとゲーム的役割の独自性を意識して12系統を整理しました。

---

## 前置き: 各系統の独自性をどこで作るか

同じ責務が被っても問題ない（問題文に明記あり）ので、以下3つの軸で系統ごとの個性を出しています。

| 軸             | 内容                                               |
| -------------- | -------------------------------------------------- |
| **対象の方向** | 自己・単体味方・単体敵・範囲・武器に塗る・地面設置 |
| **タイミング** | 即時発動・設置後条件発動・継続維持・事前準備       |
| **役割設計**   | 攻勢強化型 / 消耗削り型 / 陣地構築型 / 自陣バフ型  |

## 12系統 一覧

---

### 1. 薬（やく）

**フレーバー:** 瓶詰め液薬・固形錠。錬金術師の定番。飲む・かける・投げる。

| レシピ案 | 責務                               |
| -------- | ---------------------------------- |
| 回復薬   | ①HP回復（自己・即時大）            |
| 再生薬   | ①HP回復（自己・`<再生>`DoT型回復） |
| 毒薬     | ④継続デバフ（`<毒>`付与）          |
| 硬化薬   | ③防護付与（`<障壁>`）              |

**責務:** ①◎ ③○ ④○  
**独自性:** 「飲む」対象が基本自己・単体。即時かリジェネかで同系統2人の差がつく最も汎用的な系統。

---

### 2. 焔薬（えんやく）

**フレーバー:** 投擲爆発物・閃光弾・衝撃筒。投げたその瞬間に戦況を変える。

| レシピ案 | 責務                                    |
| -------- | --------------------------------------- |
| 焔弾     | ②直接ダメージ（範囲・火属性）           |
| 轟弾     | ⑤ノックバック（衝撃で後方に吹き飛ばす） |
| 閃光弾   | ⑥スタン付与（スタン値+X）               |
| 毒煙弾   | ④継続デバフ（着弾点に`<毒>`煙を展開）   |

**責務:** ②◎ ④○ ⑤◎ ⑥○  
**独自性:** **⑤ノックバックの主力系統**。タイムラインCTとの相性が最高。回復なし・防護なし→高リスク高速決着型。

---

### 3. 印符（いんぷ）

**フレーバー:** 紙・布・石板に刻んだ符。対象に「貼る・渡す」。

| レシピ案 | 責務                  |
| -------- | --------------------- |
| 障壁符   | ③防護付与（`<障壁>`） |
| 装甲符   | ③防護付与（`<装甲>`） |
| 縛符     | ⑥スタン付与           |
| 再生符   | ①HP回復（`<再生>`）   |

**責務:** ①○ ③◎ ⑥○  
**独自性:** **「自分以外の味方に渡せる」ことを前提にできる系統**。射程が「接触」であれば、サポーターとしての立ち位置が自然に決まる。攻撃手段は武器のみ。

---

### 4. 霧薬（きりやく）

**フレーバー:** 燃やすと有毒・麻酔の霧が広がる薬品。地面に叩きつける・火を付ける。

| レシピ案 | 責務                            |
| -------- | ------------------------------- |
| 毒霧薬   | ④継続デバフ（範囲に`<毒>`）     |
| 麻酔霧   | ⑥スタン付与（範囲・スタン値+X） |
| 燃焼薬   | ②直接ダメージ（範囲・炎ダメ）   |
| 煙幕薬   | ③防護付与（`<回避>`）           |

**責務:** ②○ ③△ ④◎ ⑥○  
**独自性:** **敵向け範囲継続効果に特化**。味方ではなく「地面・空間」を汚染する感覚。薫香（→後述）と対になる敵向けバージョン。

---

### 5. 薫香（くんこう）

**フレーバー:** 焚き香・薫煙。火を付けると周囲の味方に効果が広がる。

| レシピ案 | 責務                                        |
| -------- | ------------------------------------------- |
| 癒香     | ①HP回復（自分中心範囲・`<再生>`）           |
| 護香     | ③防護付与（自分中心範囲・`<障壁>`）         |
| 鼓舞香   | ③防護付与（自分中心範囲・`<装甲>`）         |
| 怯香     | ④継続デバフ（自分中心範囲・敵に`<怯懦>`等） |

**責務:** ①○ ③◎ ④○  
**独自性:** **自分中心の範囲バフに特化**。霧薬が「敵に撒く」のに対し、薫香は「自陣に焚く」。前線に立って自分を核とした支援ができる。

---

### 6. 機巧（きこう）

**フレーバー:** 錬金で作った罠・設置型仕掛け・自動起動装置。

| レシピ案 | 責務                                  |
| -------- | ------------------------------------- |
| 雷撃罠   | ②直接ダメージ（踏んだ対象にダメージ） |
| 反発罠   | ⑤ノックバック（踏んだ対象を弾く）     |
| 障壁機   | ③防護付与（周囲の対象に`<障壁>`）     |
| 縛罠     | ⑤⑥（踏んだ対象を停止・スタン）        |

**責務:** ②○ ③○ ⑤○ ⑥○  
**独自性:** **設置→条件発動型**。戦闘開始前や移動読みで配置する「準備・陣地構築」プレイスタイル。発動条件（敵が踏む等）をレシピで定義する必要がある。

---

### 7. 膏薬（こうやく）

**フレーバー:** クリーム状・粘性の塗り薬。武器・自分の皮膚・地面に塗る。

| レシピ案 | 責務                                                       |
| -------- | ---------------------------------------------------------- |
| 毒塗薬   | ④継続デバフ（武器に塗る→次の攻撃命中時に`<毒>`付与）       |
| 腐食塗薬 | ②直接ダメージ（武器に塗る→次の攻撃に酸ダメ追加）           |
| 硬化膏   | ③防護付与（自身の皮膚に塗る→`<装甲>`）                     |
| 滑脂     | ⑤ノックバック（地面に塗る→踏んだ対象がスリップ・後方移動） |

**責務:** ②○ ③○ ④◎ ⑤○  
**独自性:** **「武器に乗せる」という独特の使用経路**。武器攻撃に化学効果を付与できる唯一の系統。「塗ってから攻撃する」という2アクションの流れが戦術の個性になる。

---

### 8. 結晶（けっしょう）

**フレーバー:** マナを封じた魔石・宝石。砕く・投げる・手の中で共鳴させる。

| レシピ案 | 責務                                        |
| -------- | ------------------------------------------- |
| 炸裂石   | ②直接ダメージ（投げて単体高威力・属性ダメ） |
| 封縛石   | ⑥スタン付与（砕いてスタン値+大）            |
| 障壁石   | ③防護付与（手に持ったまま→`<障壁>`持続）    |
| 共鳴石   | ①HP回復（自己・マナ属性に対応した回復）     |

**責務:** ①○ ②◎ ③○ ⑥◎  
**独自性:** **「持ち続けると効果が持続する」レシピ**（障壁石）が作れる。想成イメージとの接続が自然（石を手元に置いたまま想成→石のマナを複製）。

---

### 9. 縛索（ばくさく）

**フレーバー:** 錬金で作った粘着糸・魔法縄・蜘蛛糸状の拘束材。投げて絡める。

| レシピ案 | 責務                                                        |
| -------- | ----------------------------------------------------------- |
| 粘着索   | ⑤位置操作（対象を固定→ノックバック無効・移動制限）          |
| 引き縄   | ⑤ノックバック（引き寄せ方向のKB。後方ではなく前方引き付け） |
| 毒縄     | ④継続デバフ（絡まった状態で`<毒>`継続）                     |
| 封縛索   | ⑥スタン付与（がんじがらめにしてスタン大）                   |

**責務:** ④○ ⑤◎ ⑥◎  
**独自性:** **「引き付け（前方KB）」という逆方向のノックバック**が実装できる唯一の候補。敵を近づけて武器で仕留める前衛戦術との相性が高い。回復・防護なしで純粋なコントロール特化。

---

### 10. 食薬（しょくやく）

**フレーバー:** 薬膳料理・強化菓子・毒入り食品。食べる・食べさせる（毒系）。

| レシピ案 | 責務                                                      |
| -------- | --------------------------------------------------------- |
| 強壮食   | ①HP回復（自己・大回復。ただし「重い行動」限定）           |
| 護身菓   | ③防護付与（自己・`<装甲>`。戦闘開始前服用で開幕から有効） |
| 毒入菓子 | ④継続デバフ（敵に「食べさせる」想定→`<毒>`）              |
| 気つけ薬 | ①HP回復（戦闘不能解除。緊急蘇生）                         |

**責務:** ①◎ ③○ ④△  
**独自性:** **「戦闘前に服用して開幕から効果が出ている」レシピ設計**が可能。事前準備型の回復・バフ系。毒入り菓子は「食べさせる」という独特の使用条件が可能（相手が受け取る必要がある等）。

---

### 11. 人形（にんぎょう）

**フレーバー:** 錬金で作った身代わり人形・小型構築物。自分の代わりに置く・壊す。

| レシピ案     | 責務                                               |
| ------------ | -------------------------------------------------- |
| 身代わり人形 | ①HP回復（ダメージを人形が肩代わり→等価HP回復効果） |
| 囮人形       | ③防護付与（敵の攻撃を引き付ける→実質回避付与）     |
| 破裂人形     | ②直接ダメージ（敵の攻撃を受けた瞬間に爆発する）    |
| 縛人形       | ⑥スタン（人形に触れた対象をスタン）                |

**責務:** ①○ ②○ ③○ ⑥○  
**独自性:** **「自分の身代わりを置く」という完全に他系統にない使い方**。能動的に使うのではなく「置いて待つ」形。想成イメージも「人形をキーとして完成品を参照」と自然。

---

### 12. 炎石（えんせき）

**フレーバー:** 発火石・冷却石・雷石など、属性ごとの特殊鉱石。置く・放つ・砕く。

| レシピ案 | 責務                                           |
| -------- | ---------------------------------------------- |
| 発火石   | ②直接ダメージ（設置後に踏むと炎爆発）          |
| 凍結石   | ⑤ノックバック（着弾点を凍結→スリップ後方移動） |
| 雷石     | ⑥スタン（雷放電でスタン値+X）                  |
| 毒石     | ④継続デバフ（砕くと有毒粉末が周囲に拡散）      |

**責務:** ②○ ④○ ⑤○ ⑥○  
**独自性:** **「属性」ごとにレシピを分け、マナスートとの相性設計が深まる**系統。カードのスート（火水土風）と属性が対応しているので、スート割引との組み合わせが最も多彩になる。焔薬と似るが「設置・持続」寄り。

## 系統同士の「対になる関係」

設計のときに覚えておきやすいペア・グループです。

```
【回復・バフ 双璧】
  薬（自己即時）     ←→   薫香（自陣範囲継続）

【デバフ 双璧】
  霧薬（範囲・敵向け） ←→  膏薬（武器経由・単体）

【位置操作 双璧】
  焔薬（吹き飛ばし）  ←→  縛索（引き付け・固定）

【防護 双璧】
  印符（味方に渡す）  ←→  薫香（自分中心拡散）

【設置系 トリオ】
  機巧（条件発動罠）  ←→  炎石（属性フィールド）
  人形（身代わり設置）

【高火力アタッカー 双璧】
  焔薬（即時爆発）   ←→  結晶（魔力砲撃）
```

## βに向けた絞り込み目安

12系統全部をβに入れるのは過剰です。以下のような段階で考えると整理しやすいと思います。

| 優先度                    | 系統                         | 理由                                       |
| ------------------------- | ---------------------------- | ------------------------------------------ |
| **必須（β確定候補）**     | 薬、焔薬、印符、霧薬         | 責務カバーが広く初心者にも分かりやすい     |
| **面白さ追加（β有力）**   | 縛索、膏薬、機巧             | ユニークな使い方で個性が際立つ             |
| **拡張（β後半〜正式版）** | 薫香、結晶、炎石、食薬、人形 | 設定やルール整合に時間がかかるが個性は高い |
