## A. 系統テーマ案（4系統）

品物の「手触り・製法・見た目」でテーマを切りました。3系統でいく場合の縮小案も末尾に添えます。

| 系統名（仮）         | 品物イメージ                               | 代表レシピ（各4本）            |
| -------------------- | ------------------------------------------ | ------------------------------ |
| **薬（やく）**       | 瓶詰めの液薬・固形薬。飲む・かける・投げる | 回復薬、毒薬、硬化薬、腐食液   |
| **焔薬（えんやく）** | 投擲・設置する爆発物・閃光弾。衝撃と爆発   | 焔弾、轟弾、閃光弾、毒煙弾     |
| **印符（いんぷ）**   | 紙・布・石板に刻む印記。貼る・置く・渡す   | 障壁符、装甲符、縛符、再生符   |
| **霧薬（きりやく）** | 発火・溶解させると煙・霧が広がる薬品       | 毒霧薬、麻酔霧、煙幕薬、燃焼薬 |

## C. 同系統2人でも差がつくか

### 結論: つく。ただし「軸」を系統内レシピに意図的に仕込む必要がある

#### 薬系統の例

```
キャラA（サポーター特化）
  携行: 回復薬×2 + 硬化薬×1
  → 想成で毎ターン回復・防護を供給。味方のHP維持役

キャラB（デバッファー特化）
  携行: 毒薬×2 + 腐食液×1
  → `<毒>`DoT+酸ダメで敵のHPを継続削り。武器と合わせて総火力役
```

同じ「薬専門」でも選ぶレシピ3本で**役割が分かれる**。

#### 差がつかなくなるリスクと対策

同系統2人でも差がつかなくなるのは、「4レシピが全員にとって1本しか正解がない場合」です。これを防ぐには、系統内レシピに以下の軸の差を持たせます。

| 差の軸             | 例                                                     |
| ------------------ | ------------------------------------------------------ |
| **対象**           | 自分にかける薬 vs 敵に投げる薬（射程・タイミング違い） |
| **即時 vs 継続**   | 即時回復 vs `<再生>`で毎ラウンド少量回復               |
| **要求マナスート** | 回復薬（水）vs 毒薬（風）→ スート割引の相性が変わる    |
| **重量**           | 軽量の小回り系 vs 重量の高威力系（待機値に影響）       |

4本のうち2本が「同じ責務の別バリアント」でもよい。たとえば薬系統に「即時回復薬（軽・水マナ）」と「再生薬（重・全属性）」の2本の回復レシピがあれば、キャラごとに選択が分かれ自然に差がつきます。

## D. 「1系統＋武器」で一人でも回るか

### 武器が前提として確保するもの

攻撃行動（武器）は全員持っているので、**②直接ダメージは錬金なしで確保済み**です。錬金は補助・特殊効果の担当。この前提で各系統を検証します。

| 系統     | 単独自走力   | 問題点                                 |
| -------- | ------------ | -------------------------------------- |
| **薬**   | ★★★★ 高い    | ①③④をカバー。武器＋薬で何でもこなせる  |
| **焔薬** | ★★☆ 条件付き | 回復・防護ゼロ。HPが削られたとき詰まる |
| **印符** | ★★★ 中程度   | ③防護で粘れるが攻撃リソースは武器のみ  |
| **霧薬** | ★★★ 中程度   | 回復なしだが④デバフで被ダメを間接軽減  |

### 焔薬系統の問題が最大

**①回復・③防護の両方がない**のは4系統中で焔薬のみです。「1人でも最低限戦える」を満たすために3つの補完案があります。

```
補完案A: 焔薬系統に③防護を1本追加
  → 「煙幕弾（自分に<回避>付与）」など、爆発物らしさを崩さずに防護を追加
  → 重量は重くして待機値ペナルティを大きくし「使いにくいが効く」印象に

補完案B: 汎用レシピ（議題13確定済み）を補完手段にする
  → 汎用レシピに①回復効果を持つ素材（タグ）を組み合わせれば最低限の回復が可能
  → 焔薬専門キャラも初期から汎用レシピを持つ前提

補完案C: 焔薬は「2人以上向け」と明記し、ソロ運用非推奨にする
  → 「早期決着を狙うアグレッシブ系統。長期戦は苦手」として個性化
  → 複数人時は、別系統のPC（薬・印符）が回復役を担う前提
```

補完案Aが最もルールとして美しいです（系統内で完結するので）。煙幕弾は炸薬として自然な見た目を保ちつつ`<回避>`付与という防護に近い役割を担えます。

### まとめ：1系統1選択は「ほぼ成立」するが焔薬に要手当て

```
薬・印符・霧薬 → 武器＋1系統で最低限自走できる
焔薬のみ      → 補完案A（煙幕弾追加）or 補完案B（汎用で補完）のどちらかが必要
```

「2系統選択案」については、今の設計（各系統2責務以上）であれば1系統で十分なロールカバーができるので、**1系統1選択で正解**だと思います。2系統にするとアイテム枠の配分が複雑になるほうがデメリットに見えます。

## 全体を通した観点

**①〜⑥のうち、⑤ノックバックは焔薬だけが◎になる設計が面白い**と思います。位置操作はタイムラインCTとの相性が特に高く（ノックバックXでカウント後方に飛ばす）、焔薬専門キャラが「敵の行動順を操作する」という独自戦術を担えます。他の系統にはない強みなので、焔薬の「①③弱い」という弱点への補完として「⑤での行動制御」が機能する、という設計意図を持たせるのが良いと思います。
