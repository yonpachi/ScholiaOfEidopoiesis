## 1. ゲームの基本構造

1セッション＝ゲーム内1日。大まかなループは以下の通り。

```
探索（霧域）→ 素材入手 → 街に帰還 → 錬金（工房） → 再び探索
```

- **探索** と **戦闘** はトランプの山札・手札を共有する
- **戦闘** は探索中のイベントとして発生し、終了後は探索に戻る

---

## 2. トランプシステム（共通）

戦闘・探索を通じて共通のトランプデッキを使う。

| スート     | 対応属性 |
| ---------- | -------- |
| スペード ♠ | 火       |
| ハート ♥   | 水       |
| ダイヤ ♦   | 土       |
| クラブ ♣   | 風       |

- **Joker**：使用時に任意のスート・数字として宣言できる
- **闇・光**属性はカードスートでは得られない

## 3. 戦闘システム

### 3-1. タイムライン（CT方式）

戦闘はタイムライン上でカウントが進む **CT（カウントタイム）方式**。

- タイムラインは `0 〜 count_max` のカウントで構成
- 0から1ずつ進み、現在カウントにコマがあるキャラクターが **手番** を行う
- 手番終了時、**待機値** ぶんコマを後方へ進める
- 最大カウントを超えた分は次ラウンドの対応カウントへ進める
- 最大カウントから0に戻ったとき、**ラウンド** が1進む

**同カウント内の順序**：PCが先（PC同士はPLが決定）、次いで敵（GMが決定）

#### エンゲージ（距離）

タイムラインはカウント位置が**エンゲージ（相対距離）**を兼ねる。

- 距離は**後方のみ**有効（自手番中、自身より手前のカウントにキャラは存在しない）
- 同カウント＝距離 **0**
- 距離の変化：待機値による後方移動、ノックバック等

```
距離: 0~2  →  自身のカウント 〜 自身+2 まで対象可
```

### 3-2. 戦闘開始

1. **初期カウント**：各PC・敵は1d10を振り、出目÷2（端数切り捨て）のカウントにコマを置く
2. **手札**：探索中の山札をそのまま使う。全員が山札から **3枚** を引く

### 3-3. 手番の流れ

```
1. 行動宣言
2. カードプレイ（手札から1枚。必須）
3. 行動段階決定（プレイしたカードの数字で決まる）
4. 行動解決
5. カウント変更（待機値ぶん後方へ）
6. 手番終了
```

手札が0枚になったら即座に山札から **3枚** 補充する。

### 3-4. 行動段階と待機値

プレイしたカードの数字が**行動段階**を決める。

| カードの数字 | A〜3   | 4〜7   | 8〜10  | J〜K   |
| ------------ | ------ | ------ | ------ | ------ |
| 行動段階     | 軽行動 | 中行動 | 重行動 | 特行動 |

```
待機値 ＝ 行動段階の基本待機値 ＋ 重量補正
```

- **重量補正**：使用する武器・防具・完成品の重量（軽量/中量/重量）による
- アイテム・武器を使わない行動では重量補正＝0
- どの数字でも任意の行動を宣言できる（数字は行動種別を制限しない）

### 3-5. 行動一覧

| 行動     | 概要                                                           |
| -------- | -------------------------------------------------------------- |
| **攻撃** | 武器（または素手）で対象にダメージを与える                     |
| **防御** | 防具で `<装甲>` を得る                                         |
| **回避** | 防具で `<回避>` を得る                                         |
| **分解** | アイテム・素材を消費しマナを得る                               |
| **使用** | 完成品を消費して効果を発動（マナなし）                         |
| **想成** | 携行中の完成品を指定しマナを支払って効果を発動（完成品は残る） |
| **離脱** | 戦闘離脱の準備をする                                           |

消耗品・完成品によるダメージ・回復は **攻撃行動ではない**（使用または想成として処理）。

### 3-6. 攻撃の受け処理（攻撃行動のみ）

```
1. 回避 … 1d10 ≦ 回避値で完全回避 → 終了
2. ダメージ算出 … 品質 × カテゴリ別係数
3. 防護 … <装甲> → <障壁> → 防御値 の順でダメージ削減
4. 効果処理（耐性） … 弱点 / 半減 / 無効 / 反射
5. ダメージ適用 … HP 減少
6. 効果後 … ノックバック・スタン等
```

**アイテム使用・想成**の場合：ステップ4〜6（効果処理以降）のみ。回避・防護は通さない。

### 3-7. 耐性

| 耐性     | 内容                                                   |
| -------- | ------------------------------------------------------ |
| **弱点** | ノックバック1・スタン値1を追加（反射時は追加効果なし） |
| **半減** | ダメージを半分（端数切り捨て）                         |
| **無効** | ダメージを0（追加効果は発生しうる）                    |
| **反射** | ダメージを発生元に適用（弱点と排他）                   |

### 3-8. ノックバック

**ノックバック X**：対象のコマをXカウント後方へ進める。タイムライン周回時は次ラウンドの対応位置へ。

### 3-9. スタン

各キャラクターは**スタン値**と**スタン最大値**を持つ。

スタン値 ≧ スタン最大値のとき：

1. スタン値を0に戻す
2. 手札からランダムに1枚選ぶ
3. そのカードの行動段階の基本待機値分ノックバックを受ける
4. 選ばれた手札を捨てる

### 3-10. 分解（戦闘中）

1. アイテムまたは素材を1つ選び消費する
2. 完成品の**規定タグ**に対応するマナを得る
3. プレイしたカードのスートに対応するマナを **1** 得る

待機値：行動段階の基本待機値のみ（重量補正なし）

### 3-11. 離脱

- 宣言から次の自身の手番まで、回避・防護処理を行えない
- 次の手番開始時に戦闘から離脱。コマ除去・再参加不可
- 待機値：行動段階＋防具重量の後 **+2**

### 3-12. 戦闘不能・全滅

- HP ≦ 0 → **戦闘不能**。コマをタイムラインから除去
- 使用・想成等で解除可能。解除後は解除者の次の手番開始から行動できる。戦闘不能中もマナは保持
- PC全員が戦闘不能 → **全滅**：素材の一部をランダムに失い、HP最低値で街帰還

### 3-13. 戦闘終了条件

| 結果             | 条件                                 |
| ---------------- | ------------------------------------ |
| **勝利**         | 敵コマが全て除去                     |
| **撤退**         | PCコマが全て離脱（勝利なし）         |
| **全滅**         | PC全員戦闘不能                       |
| **簡易戦闘終了** | ラウンド上限に達した場合も終了・勝利 |

探索イベントとしての戦闘は**簡易戦闘**（ラウンド上限あり）。終了時、残り手札は捨て札へ。

## 4. 錬金システム

### 4-1. 概要

工房で素材を投入し **完成品** を作る。完成品は探索・戦闘で携行し、**使用** または **想成** する。

| 操作                       | 場所             | 消費   | 結果                     |
| -------------------------- | ---------------- | ------ | ------------------------ |
| **錬金**                   | 街・工房（手番） | 素材   | 完成品1個。レシピを記憶  |
| **使用**                   | 探索・戦闘       | 完成品 | 効果を発動               |
| **想成**                   | 探索・戦闘       | マナ   | 効果を発動。完成品は残る |
| **界標用スコーリオン据置** | 霧域             | 据置   | 地景を固定               |

### 4-2. 錬金（工房）

1. **レシピ**を1つ選ぶ
2. レシピの**材料スロット**に、条件を満たす素材を1つずつ投入する
3. 投入した素材は消費する（錬金時マナは消費しない）
4. 錬金は街の**手番**を1消費する
5. ダイスで判定し、目標値以上なら**完成品**を1個得る。失敗時は素材のみ消費

### 4-3. レシピの構成

| 要素             | 内容                                          |
| ---------------- | --------------------------------------------- |
| **材料スロット** | 複数。各スロットは下記3種のいずれか（混在可） |
| **規定タグ**     | 完成品に必ず付くタグ。分解時マナ算出の根拠    |
| **想成マナ**     | 判定プール用属性ダイス。想成時の支払いマナ    |
| **目標値**       | レシピごとに設定                              |
| **成果物タイプ** | 消耗品 / 界標用SC / 装備（将来）等            |

#### 材料スロット3種

| スロット種別     | 記述例     | 投入条件                  | 副作用（完成品に付く追加タグ） |
| ---------------- | ---------- | ------------------------- | ------------------------------ |
| **特定素材**     | `虹色の羽` | その素材のみ              | なし                           |
| **カテゴリタグ** | `<草>`     | 当該カテゴリを持つ素材1つ | 投入素材の**全タグ**           |
| **性質タグ**     | `火` 等    | 当該タグを持つ素材1つ     | **指定タグ以外**のタグ         |

### 4-4. 完成品のタグ

| 種類           | 内容                                               |
| -------------- | -------------------------------------------------- |
| **規定タグ**   | レシピに記載。完成品の本体。分解時のマナ算出に使う |
| **副作用タグ** | スロットルールで付与。使用・想成時の副次効果       |

- 副作用タグは**次の錬金に引き継がない**（完成品ごとに完結）
- 分解時のマナは**規定タグのみ**から算出（副作用タグは含まない）

### 4-5. 完成品の属性

#### 品質

錬金判定の**達成値**が品質となる。戦闘・探索での効果量は `品質 × カテゴリ別係数` で求める。

#### 重量

全完成品に**重量**（軽量/中量/重量）を設定。戦闘の待機値に影響する。

### 4-6. 使用・想成

|                | **使用（実体）**           | **想成**                         |
| -------------- | -------------------------- | -------------------------------- |
| 前提           | 当該完成品を携行           | 同左                             |
| コスト         | 完成品を**消費**。マナなし | **マナのみ**。完成品は消費しない |
| 効果（消耗品） | 完成品に記録された効果     | **使用と同じ効果**               |
| 効果（装備）   | 装備スロットで常時効果     | 一時バフ（障壁・防護等）         |

**想成の鍵**：完成品を携行していなければ想成不可。レシピを「知っている」だけでは不可。

#### スート割引（想成）

プレイしたカードのスートに対応する属性マナが支払いに含まれる場合、その属性を**1つ無料**にできる。

### 4-7. 携行枠

| 枠             | 内容                                           |
| -------------- | ---------------------------------------------- |
| **アイテム枠** | 消耗品等。想成に使う完成品もここ               |
| **界標SC枠**   | 界標用スコーリオン（据置前）。アイテム枠とは別 |
| **装備枠**     | 装着中の武器・防具                             |

アイテム枠の上限は工房の成長で拡張できる。

## 5. 効果記述システム（印記・タグ）

### 5-1. 記法

- `[]`：**タグ**（錬金・素材の属性・分解用）
- `<>`：**印記**（状態・属性フラグ・条件分岐）

### 5-2. 印記の種類

#### 条件印記

| 印記                        | 条件                   |
| --------------------------- | ---------------------- |
| `<軽>` `<中>` `<重>` `<特>` | プレイカードの行動段階 |
| `<♠>` `<♥>` `<♦>` `<♣>`     | プレイカードのスート   |

```
<条件A>×<条件B>: 効果    … AND（両方成立）
<条件A>+<条件B>: 効果    … OR（どちらか成立）
```

#### 属性フラグ

効果文の先頭に書く（例: `<火>`）。以降の行全体に継承される。マナ属性・耐性判定に使用。

#### 状態印記

`<障壁>` `<装甲>` `<回避>` `<毒>` 等。付与・強度・減衰のある状態。

### 5-3. 効果解決の流れ

```
1. タイミング／距離／対象 で対象決定
2. 効果文を先頭行から順に処理
   各行: 条件判定 → 属性フラグ確認 → 効果本体 → 耐性（弱点/半減/無効/反射）
3. 副作用タグの効果文を処理（主作用の後）
4. 効果後処理（弱点時スタン・ノックバック等）
```

### 5-4. 効果文の書き方例

```
効果:
  <火> 対象の HP を {品質×3} 回復する
  <特>: 対象に <障壁> を付与する。強度={品質×0.3}
```

- `{品質×3}` のように `{}` 内で計算式を記述。除算は端数切り捨て
- 規定タグは使用時の効果文を持たない（錬金・分解専用）

## 6. キャラクター作成

PC はキャラクター作成時に以下を選ぶ。

- **種族**（6種族から1つ）：判定時能力・戦闘時能力を得る
- **初期装備**：武器（攻撃行動で使用）＋ 防具（防御値・防御・回避行動の参照）
- **レシピ系統**(１つ)：自身が錬金可能なアイテム種を決定。追加は後からできるようになる

### 種族と戦闘能力（仮案）

| 種族 | 戦闘時能力                           |
| ---- | ------------------------------------ |
| 人間 | **形勢一変**：手札の引き直し系       |
| 獣裔 | **猪突猛進**：ノックバック+1         |
| 機巧 | **明鏡止水**：想成スートボーナス追加 |
| 錬生 | **窮余一策**：手番消費なし分解1回    |
| 付喪 | **炉火純青**：想成待機値-1           |
| 半霊 | **曖昧模糊**：強度印記付与時±1       |
