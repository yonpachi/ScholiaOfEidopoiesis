## 結論

この条件なら、**4系統・キャラクターは1系統を専門**にする形がかなり相性よさそうです。

特におすすめなのは、次の4系統です。

- **薬剤系統**：回復・毒・麻痺
- **爆具系統**：攻撃・防御・位置操作・スタン
- **護符系統**：回復・防護・弱体
- **機巧系統**：攻撃・防護・位置操作

「薬剤と護符」「爆具と機巧」は一部の責務が重複しますが、**効果の出し方や得意な戦況が異なる**ように設計します。

---

# A. 系統テーマの案

## 1. 薬剤系統

飲み薬、塗り薬、毒瓶、香薬など、**生物の身体に作用する液体・粉末**を扱う系統です。

| レシピ例 |        責務 | 効果の方向性                 |
| -------- | ----------: | ---------------------------- |
| 活命薬   |     ①HP回復 | 単体を即座に大きく回復       |
| 癒霧薬   |     ①HP回復 | 範囲内を少量ずつ回復         |
| 蝕毒瓶   | ④継続デバフ | `<毒>`を付与                 |
| 麻痺香   |     ⑥スタン | 対象を一時的に行動不能にする |

同じ回復でも、活命薬は「瀕死者を救う」、癒霧薬は「複数人を立て直す」という違いがあります。どちらも効果文としては回復のみです。

### 系統としての戦い方

武器で攻撃しながら、自分や仲間を回復し、毒と麻痺で敵を弱らせる**持久戦型**です。

---

## 2. 爆具系統

爆弾、煙幕筒、閃光筒、衝撃弾など、**投擲して即座に戦況を変える消耗品**の系統です。

| レシピ例 |          責務 | 効果の方向性                   |
| -------- | ------------: | ------------------------------ |
| 炸裂弾   | ②直接ダメージ | 範囲内に直接ダメージ           |
| 煙幕筒   |     ③防護付与 | 味方に一時的な `<障壁>` を付与 |
| 斥力爆弾 |     ⑤位置操作 | 爆心から対象をノックバック     |
| 閃光筒   |       ⑥スタン | 範囲内の対象をスタンさせる     |

煙幕筒は「命中低下」など複数の効果を持たせず、単純に煙幕による防護を `<障壁>` などの状態で表現します。

### 系統としての戦い方

敵の集団を崩し、危険な敵を止め、必要なら煙幕で凌ぐ**瞬発力・戦況操作型**です。

---

## 3. 護符系統

護符、刻印札、呪符、封印紙など、**対象に貼り付けて効果を与える品物**の系統です。

| レシピ例 |        責務 | 効果の方向性           |
| -------- | ----------: | ---------------------- |
| 治癒符   |     ①HP回復 | 対象のHPを回復         |
| 障壁符   |   ③防護付与 | `<障壁>`を付与         |
| 装甲符   |   ③防護付与 | `<装甲>`を付与         |
| 衰耗符   | ④継続デバフ | 継続的な弱体状態を付与 |

薬剤と異なり、護符の回復は純粋な回復量では劣る代わりに、射程、持続、事前設置などで差をつけられます。

### 系統としての戦い方

味方を守りながら、敵に呪符を貼って弱らせる**安定支援型**です。

---

## 4. 機巧系統

罠、杭、展開装置、小型自動機械など、**設置して働かせる錬金機構**の系統です。

| レシピ例 |          責務 | 効果の方向性                     |
| -------- | ------------: | -------------------------------- |
| 雷撃罠   | ②直接ダメージ | 条件を満たした対象に直接ダメージ |
| 防壁機   |     ③防護付与 | 周囲の対象に `<障壁>` を付与     |
| 装甲架   |     ③防護付与 | 対象に `<装甲>` を付与           |
| 反発杭   |     ⑤位置操作 | 対象を一定方向へ押し出す         |

機巧系統は、同じ直接ダメージでも武器や爆具より**設置場所や発動条件が重要**になります。

### 系統としての戦い方

防壁や罠を配置し、有利な陣地を作って敵を迎え撃つ**準備・陣地構築型**です。

---

# B. 各系統の責務組み合わせ

| 系統 | ①回復 | ②直接ダメージ | ③防護 | ④継続デバフ | ⑤位置操作 | ⑥スタン |
| ---- | :---: | :-----------: | :---: | :---------: | :-------: | :-----: |
| 薬剤 |   ○   |               |       |      ○      |           |    ○    |
| 爆具 |       |       ○       |   ○   |             |     ○     |    ○    |
| 護符 |   ○   |               |   ○   |      ○      |           |         |
| 機巧 |       |       ○       |   ○   |             |     ○     |         |

この配置では、すべての責務が最低2系統に存在します。

## 各系統の弱点

### 薬剤系統

**弱い部分：**

- 即座に大ダメージを出せない
- 敵味方の位置を動かせない
- `<障壁>`や`<装甲>`で事前に守ることができない

武器で攻撃しながら生き残ることは得意ですが、敵の数が多い場面を一気に解決するのは苦手です。

### 爆具系統

**弱い部分：**

- HPを戻せない
- 長期戦で息切れしやすい
- 味方を巻き込みやすい設計にすると、狭い場所で扱いにくい

煙幕による防護はありますが、受けた損害そのものは戻せません。

### 護符系統

**弱い部分：**

- 即効性のある攻撃手段が少ない
- 敵を押し退けられない
- スタンによる緊急停止ができない

事故を防ぐ能力は高い一方、既に崩れた戦況を一発でひっくり返すのは苦手です。

### 機巧系統

**弱い部分：**

- HP回復がない
- スタンがない
- 移動戦や奇襲戦では、設置物を活用しにくい

準備できた戦場では強いですが、敵に主導権を握られると性能を出しにくくなります。

# C. 同系統2人でも差がつくか

この4系統なら、レシピ選択による役割分担は可能です。

## 薬剤系統が2人の場合

- 活命薬＋癒霧薬を覚えた**治療担当**
- 蝕毒瓶＋麻痺香を覚えた**妨害担当**

かなり明確に分かれます。

## 爆具系統が2人の場合

- 炸裂弾＋斥力爆弾の**攻撃・吹き飛ばし担当**
- 煙幕筒＋閃光筒の**防御・スタン担当**

同じ爆具使いでも、破壊役と戦況制御役になります。

## 護符系統が2人の場合

- 障壁符＋装甲符の**防護担当**
- 治癒符＋衰耗符の**回復・弱体担当**

一方は被害を防ぎ、もう一方は被害を戻しながら敵を弱らせます。

## 機巧系統が2人の場合

- 雷撃罠＋反発杭の**罠・位置操作担当**
- 防壁機＋装甲架の**陣地防衛担当**

攻撃的な技師と、防御的な技師に分かれます。

## 差を残すために必要な制約

レシピが4本しかなく、成長後に全員が4本すべてを自由に使えるなら、最終的には同じ構成になります。

そのため、次のどれかは必要です。

- 初期習得は4本中2本
- 成長しても習得上限は3本
- 習得自体は全レシピ可能だが、冒険に持ち込める「登録レシピ」は2〜3本
- レシピごとに専門化や派生強化があり、全強化は取得できない

特に扱いやすいのは、**レシピは覚えられるが、一度に準備できるのは3本まで**という方式です。習得したものを無駄にせず、セッションごとに役割を変えられます。

## 系統内で持たせるべき差の軸

単に数値だけ変えたレシピではなく、次の軸で差をつけると自然です。

- 単体か範囲か
- 即時発動か設置・遅延発動か
- 軽い行動で小さく使うか、重い行動で強く使うか
- 確実に効くか、条件付きで強いか
- 自分中心か、遠距離の対象を選べるか
- 攻勢を伸ばすか、失敗を立て直すか

たとえば「炸裂弾」と「雷撃罠」がどちらも直接ダメージでも、

- 炸裂弾：即時、範囲、敵の密集に強い
- 雷撃罠：設置、単体、高威力、誘導が必要

なら、責務が同じでも完全に別の道具になります。

# D. 「1系統1選択」で一人でも回るか

## 基本的には回る

全員が武器を持つため、錬金系統に直接ダメージがなくても攻撃不能にはなりません。

今回の案では、すべての系統が少なくとも次のどちらかを持っています。

- HPを回復する
- 受ける被害を防ぐ

そのため、武器と組み合わせれば最低限の戦闘能力は成立します。

| 系統 | 一人での戦い方           | 判定                 |
| ---- | ------------------------ | -------------------- |
| 薬剤 | 武器＋回復＋毒・麻痺     | 安定して回る         |
| 爆具 | 武器＋爆発＋煙幕＋制御   | 短期戦なら回る       |
| 護符 | 武器＋回復＋防護＋弱体   | 安定するが決着が遅い |
| 機巧 | 武器＋罠＋防壁＋押し出し | 準備できれば回る     |

爆具と機巧は戦闘中のHP回復を持たないため、少しだけシステム側の補助が必要です。

## 全員に必要な共通ルール

### 1. 通常の防御行動を用意する

錬金レシピがなくても、行動を使って被害を軽減できるようにします。

たとえば、

- 防御姿勢を取る
- 遮蔽物へ移動する
- 次に受けるダメージを軽減する

といった基本行動です。

これがないと、回復や防護を持たない構成が極端に不安定になります。

### 2. 戦闘外の回復手段を共通化する

休息、応急処置、拠点への帰還などによって、戦闘間ではある程度回復できるようにします。

ただし、**戦闘中に使える共通回復は弱くするか、存在させない**方がよいです。強い共通回復があると、薬剤系統や護符系統の価値が落ちます。

### 3. すべての系統に自分を守れるレシピを置く

支援系のレシピは、原則として自分にも使用できるようにします。

「味方にしか使えない障壁符」などが多いと、一人での戦闘が成立しません。

### 4. 特定責務を攻略の必須条件にしない

「スタンさせないと絶対に倒せない敵」「ノックバックさせないと詰む敵」は避けた方がよいです。

スタンや位置操作は、

- 敵の大技を止められる
- 危険な地形を利用できる
- 戦闘が明確に楽になる

程度に留めれば、どの系統でも攻略できます。

## 1系統と2系統のどちらがよいか

今回の設計なら、**最初は1系統だけでよい**と思います。

2系統選択にすると、

- 苦手な責務を簡単に補えてしまう
- 系統ごとの個性が薄くなる
- 同系統を選んだ仲間との役割分担が起こりにくくなる
- 選択肢が増え、初期キャラクター作成が重くなる

という問題が出ます。

代わりに成長要素として、

- 他系統のレシピを1本だけ習得できる
- 師匠やイベントによって例外的に取得できる
- 他系統レシピは想成時のマナが重い

といった**副専攻的な越境**を用意するのがよさそうです。

基本は「1系統の中で何を覚えるか」に個性を置き、他系統のレシピは後半の特別な成長にする形が、現在の設計目標に最も合っています。
