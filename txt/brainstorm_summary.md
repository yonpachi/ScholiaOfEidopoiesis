# ブレインストーミングアイデア集（整理版）

C1〜C4のアイデアを系統別にまとめたもの。似た意見は統合済み。

---

## タイムライン・カウント操作

### 移動・位置制御

- 後ろに下がりながら遠距離攻撃し、敵の射程外をキープする
- 意図的にノックバックして敵の攻撃を誘導したり、味方の射程に押し込む
- 自分と対象のカウントを交換（手番順と距離が同時に入れ替わる）
- 対象が移動した直後、自分も同じ方向へ一定量追従する
- 2つのカウントを一時的に隣接扱いにする（距離の折り畳み）
- 自分が後方移動すると、連結した味方も同じだけ移動する（牽引）

### カウントそのものの変形

- 指定カウントを一時的に欠番にして飛ばす
- `count_max` を増減させて全員の距離・手番間隔を圧縮/伸長する
- 偶数/奇数カウントにいる対象だけが影響を受ける
- ラウンド境界（最大→0へ戻る瞬間）に発動する効果

### 待機値・手番速度の操作

- 待機値を増やす印記（スロウ）で敵の次の手番を遅らせる
- 今回待機値を減らす代わりに次回を増やす「時間債務」
- 今回あえて後方へ進み、差分だけ次回の待機値を減らす「時間貯蓄」
- 先読みして敵の次カウントより前に割り込む

### ノックバック応用

- ノックバックした対象が別キャラと同カウントに着地したとき追加効果（衝突）
- 同カウントにいる全員をまとめて後方へ押す（反発）
- ノックバックを無効化してその分をスタン値/設置物強度に変換（係留）
- 限界を超えたノックバック量をダメージ・スタン・マナに変換
- 連結した敵の片方がノックバックを受けると、もう片方も受ける（共倒れ鎖）
- 敵の後方に設置物があるときノックバックさせると追加ダメージ（追い込み）

## 設置物・罠・フィールド

### 設置・起動

- 携行品をタイムライン上に置き、罠・起点・障害物として機能させる（設置行動）
- 同カウントにある設置物を携行枠へ戻す（回収行動）
- 完成品を消費せず放棄して即座に特殊効果を発生させる（投棄行動）
- カードと完成品を伏せ、指定カウントで自動解決する（予約行動）
- 敵が指定カウントに到達した際、伏せていたカードで反応する（割り込み地点）
- 探索中に設置した界標SCが同じ場所での戦闘中に「場の効果」として機能する

### 通過・到達トリガー

- 通過した瞬間に発動する罠（待機値移動でもノックバックでも反応）
- 現在カウントからX後方に効果マーカーを置き、到達時に発動する時限錬成
- 指定カウントへ到達したとき回復や強化が発生する（到着薬）
- 次のラウンドで再び同じカウントへ到達したとき再発動する（回帰効果）

### 時間経過トリガー

- ラウンドごとに1カウント移動しながら周囲へ効果を出す（秒針設置物）
- タイムライン上に長く置くほど品質係数が高くなる（発酵）
- 指定カウントになった瞬間だけ強い障壁を発生させる時限式障壁
- 設置物を戦闘中に起爆して一度だけ大きな効果を出す（自爆スコーリオン）

### 陣形・領域

- 味方が同カウントに集まるほど効果が強くなる（同調陣）
- 味方同士の距離が離れているほど効果が強くなる（分散陣）
- 2つの設置物の間にいる敵へ効果を与える（挟撃線）
- 指定カウントにいる間、障壁や耐性を得る（安全地帯）
- 設置物のカウントを起点として想成の対象や射程を計算する（中継点）
- 同カウントで分解・使用・想成すると追加マナや追加効果（錬成炉カウント）

## カード・手札操作

### 山札・手札の操作

- 捨て札の上のカードを再プレイしたように処理する（捨て札踏み倒し）
- 山札上部を数枚めくり特定スートだけ取得（スート指定ドロー）
- 山札上部を見て並べ替える（予見・先読み）
- 捨て札から特定スートを1枚回収する（抽出）
- 手札を任意枚数捨ててボーナスを得る（手札破壊）
- カードを戦闘中除外してマナを得る（焼却）→ 闇マナ生成源

### 手札の加工・保存

- カードを完成品の下に伏せ、後で使うときに強化された状態で利用（仕込み）
- カードをアイテムに記録し、携行中は同スートを想成に使える（封札）
- 同じカードを長く持つほど効果が強くなる（手札発酵）
- カードに一時的な不利タグを付けて使うと強いが副作用も出る（汚染札）
- 戦闘終了時に1枚だけ探索へ持ち越す（持ち越し札）

### 数字の操作

- プレイしたカードの数字を±1する
- 数字を倍にする代わりに使用後除外する / 半分にして次の手番でも使う
- 偶数を1段階軽く、奇数を1段階重く扱う
- AをKとして、KをAとして扱う
- J〜Kを任意数字として扱うが特行動でなくなる
- 前回より大きい数字なら効果強化
- 現在カウントとカード数字の差を効果量にする / カード数字と距離が一致で追加効果
- 重行動（8〜K）を捨てて軽行動用の仮想カード2枚へ分割（札割り）
- 2枚を同時に捨て、組み合わせた特殊行動を行う（札融合）

### スートの操作

- カードを別スートへ染める / 元のスートと変更後を両方持たせる
- スートを失わせ無属性カードにする
- 赤札を光・黒札を闇として扱う（一時的）
- 同じスートを連続使用で属性濃縮 / 3回重ねると闇マナを得る
- 4スートを一巡させると光マナを得る
- 捨て札の一番上とスートを交換する
- 連続する数字を順に使うと完成する効果（連番錬成）
- 味方が同じ数字を出すと連携効果（同数共鳴）
- 赤札と黒札を組み合わせて光/闇を生成（対札反応）
- パーティ全体で4スートを揃えると大技解禁（四元素完成）
- 相手が最後に使ったスートへ自分のカードを変える

### 手札の共有・渡し

- 同カウントの味方同士でカードを交換する
- 味方の行動に自分のカードを1枚加えスートだけ提供する（献札）
- 山札を見ずにプレイする代わりに効果量が高い（盲打ち）
- ジョーカーを「数字だけ任意」「スートだけ任意」「両方任意」と使い分ける

## 使用・想成・分解の錬金操作

### 分解の応用

- 戦闘中に素材を分解→同ターン即座に想成（分解即想成コンボ）
- 強力な攻撃が飛んできた瞬間にアイテムを分解してマナを得て防御を想成するカウンター
- 敵の障壁・設置物・地形効果を壊してマナや素材に変える（解体行動）
- 戦場の属性・状態・設置物・敵の一部を「残滓」として回収する（採取行動）

### 想成の拡張

- 毎手番マナを払い続けることで効果を維持する（維持想成）
- 設置した触媒を起点として効果を発生させる（遠隔想成）
- 次のラウンドに品質を下げて同じ効果を再発生させる（反響想成）
- 対象を2つに分け低品質でそれぞれへ効果（二重像）
- 複数人でマナを分担する（共同想成）→ 光マナ生成源
- 味方が携行する完成品を許可を得て想成する（代理想成）
- 想成後に完成品を一時的に使用不能にして大幅強化（崩壊想成）
- 必要マナより多く支払って品質倍率を上げる（過剰想成）
- マナ不足分をHP・カード・次回待機値で支払う（不足想成）
- 想成した像をタイムライン上の設置物として残す（投影固定）
- 敵が維持している想成を分解してマナとして奪う（想成破り）
- 想成が反射された際、支払ったマナの一部が別属性として戻る（逆流）

### 使用と想成の差別化（後処理）

- 使用後に空瓶・灰・破片などの残滓が残り、戦場で再分解できる
- 使用時だけ複数対象へ散布できる
- 使用時だけ副作用タグを対象と別の場所に残せる
- 使用した完成品を敵に投げ渡せる
- 使用ならマナ無効化の影響を受けない

### コンボ・特殊活用

- 1手番目に想成で状態印記付与→2手番目に同アイテムを使用で起爆させる（時差起爆）
- マナを2倍払うことで効果を倍以上にする（マナ過負荷）
- マナ払いと消費を同時に行い効果を2〜3倍にする（オーバーヒート・自壊想成）
- 他のPCが使用した完成品を自分が想成できる（影写し）
- アイテムに事前に保険をかけ、誰かが使用しても想成1回分のストックが残る（携行保険）
- 1つのアイテムに対し複数PCが同ターン内に順番に想成して効果を累積（想成連鎖）

## マナ操作

### 変換・生成

- 2マナを別属性1マナへ変換する
- 同じ属性を連続して使うと変換効率が上がる
- 戦闘終了時に失われる代わりに、大量の一時マナを得る
- 耐性で無効化されたダメージをマナへ変える
- 障壁が破壊されたとき残り強度をマナへ変換する
- ノックバック量に応じて風マナ・回復量に応じて水マナ・軽減値に応じて土マナ・スタン値に応じて火マナを得る
- 2つの属性を混ぜた汚染マナを作る（支払うとランダム副作用が付く）
- マナをカードへ付着させて次の手番まで保持する

### 共有・貯蓄

- 仲間同士を導線でつなぎマナを共有する
- マナを完成品へ貯蔵して後で一気に放出する（マナストック）
- 対象が使った属性と同じマナを得る（吸収）
- 敵が持つマナを属性ごと吸収する
- マナを借り、戦闘終了時または次の手番に返済する

### 光・闇マナの生成（特殊条件）

- 光：複数人でマナを共同支払い / 4スートを一巡 / 味方への副作用を引き受ける / 完成品を完全消費する
- 闇：カードを戦闘中除外 / HPや次の手番を代償にする / 副作用タグを受け入れる / 敵の状態やマナを奪う
- 反対属性を支払って主効果を反転する（回復をダメージ、ノックバックを係留、など）

## タグ・副作用操作

### タグの付与・転送

- 自分の完成品についているタグを別の完成品や対象に写す（タグ転写）
- 対象の完成品に不要なタグを後付けして次の想成の効果を変質させる（タグ汚染）
- 副作用タグを別の対象へ付ける / 主作用はAへ・副作用はBへ与える（副作用転嫁）
- 副作用だけを現在カウントへ罠として残す（副作用設置）
- 副作用を瓶へ戻し次の完成品へ装填する（副作用回収）
- 対象から副作用タグを取り除き別の対象へ付ける（副作用移植）

### タグの強化・変形

- 副作用タグの効果だけ倍化する（副作用増幅）
- 今回は副作用を発生させず次回まとめて発生させる（副作用封印）
- 複数の副作用から使用者または対象が一つ選ぶ（選択毒）
- 副作用を複数対象に分ける（副作用分配）
- 同名タグが複数ある場合、回数ではなく強度として統合する（同タグ濃縮）
- 対象がすでに同じタグを持つ場合、周囲にも伝播する（副作用共鳴）
- 発生からラウンドをまたぐほど強くなる（副作用発酵）
- 副作用を即時発動させず条件効果に変える（条件化）
- 主効果を反射させ副作用だけを元の対象へ残す（反射誘発）

### タグの反応・合成

- 特定のタグ組み合わせで第三の効果を発生させる（異種反応）
- 対立するタグを打ち消して無属性残滓を得る（相殺）
- 副作用タグを発生させず消費して主作用の品質係数を上げる（触媒化）
- 「この効果処理では火を水として扱う」と宣言して耐性の穴を突く（属性変換）
- 対象の弱点属性に対応する副作用だけを強化する（耐性触媒）
- 対象の副作用タグを一つ消しそれに対応するマナを得る（副作用解体）
- 主規定効果と副作用タグの処理順や役割を入れ替える（主副反転）

## 品質・状態を資源にする

### 品質の操作

- 敵の装甲を割ったとき削れた強度の一部を品質ボーナスとして次行動に乗せる（品質盗用）
- 仲間がさっき使った完成品の品質を自分の次行動に合算する（品質転移）
- 達成値が目標を大きく超えたとき、通常とは異なる高品質ボーナス効果が開く
- あえて低品質に仕上げて通常品では出ない特殊効果を持つ「失敗品」を作る（不完全錬金）
- 長時間携行すると品質が落ちる代わりに分解時のマナが増える（完成品の劣化）

### 状態を物として扱う

- 対象の毒を瓶に移して毒状態を解除する
- 対象の障壁を剥がして設置物へ移す
- 自分の装甲を消費して攻撃力へ変える
- スタン値をマナへ変換する
- ノックバックされる代わりに移動量を瓶に保存する
- 受けた火属性ダメージの一部を「熱」として保存する
- 回避成功を「残像」として記録し後で他者へ付与する
- 敵の弱点を一時的なタグとして採取する / 敵の耐性を剥がして味方へ一時付与する
- 状態を分解して素材タグを持つ一時素材にする
- 二つの状態を混ぜて別状態へ変換する
- 状態の強度と残り時間を交換する / 状態の減衰を停止する代わりに解除不能にする
- 戦闘終了時まで残った状態を探索用の資源へ変換する
- 自分が持つ状態の数だけ完成品を強化する
- 解除した状態をそのまま別の敵へ移植する

## リスク・代償系

- 自分のHPを消費してその分だけ効果が跳ね上がる（自傷爆発）
- カードを戦闘中除外してマナや効果を得る（焼却・黒札系）
- 完成品を破壊（消費）しながらマナも払うことで大幅強化（オーバーヒート）
- マナ不足分をHP・カード・次回待機値で補う（不足想成）
- 今回待機値を減らす代わりに次回増やす（時間債務）
- 敢えて手札を早めに使い切って欲しいスートを引くギャンブルプレイ

## パーティ連携

### 位置・タイムラインを使った連携

- AがノックバックさせてBの射程圏内に押し込む（激突コンボ）
- 一人が罠を設置し、もう一人が敵を押し込む（押し込み）
- AがわざとHPを低くして囮になり、Bがバックアタックで殴る（囮と追撃）
- Bのコマが前方にいて「代わりに受ける」宣言をする（カウントカバー・庇護交換）
- 同カウントの味方全員で装甲・障壁を共有する（連結防御）
- 戦闘不能になった味方のカウントへ別の味方が移動する（位置継承）

### カード・マナの連携

- 同カウントで完成品を渡し受け取った側が即座に想成する（受け渡し想成）
- 味方が自分のカードを伏せておき、別の味方の手番に使わせる（先払い連携）
- 味方が分解した直後そのマナを別の味方が使用できる（分解援護）
- 複数人が同一対象へ異なる捕獲条件を揃えることで捕獲成立（共同捕獲）

### 属性リレー・連鎖

- 前の味方と異なるスートなら効果上昇（属性リレー）
- 前の味方と同じスートなら属性強度上昇（同属性濃縮）
- 火・水・土・風を順に使うと最後に光属性効果（四元素連鎖）
- 赤札と黒札を交互に使うと闇属性効果（相反連鎖）
- 同カウントの味方が連続して攻撃すると後の攻撃にスタン値追加（同カウント攻撃）
- AがAiの状態印記を付与→Bがその印記を爆発させる（コンボ起動）

## 探索連動

### 探索中の山札・手札操作

- 山札上部を見て次のイベント傾向を知る
- カードを1枚捨てて進路を変更する
- 特定スートを捨てその属性の地形を探す
- カードを場所に埋め帰路で回収する
- 探索で使用したカードへ地形タグを付ける
- 霧の影響で山札へ一時的な「傷札」が混ざる / 界標を置くことで次回傷札を除去する

### ルート・地形操作

- 先のイベントを一つ見る（霧見）
- 2つの候補から片方を恒久的な道として固定する（分岐固定）
- 帰還時に一部イベントを飛ばせる（帰路標定）
- 2つの発見済み地点を一時的につなぐ（道の折り畳み）
- 追跡してくる敵を別ルートへ誘導する（偽道）
- 危険イベントの確率を下げる代わりに素材品質が下がる（霧圧操作）
- 逆に危険度を上げて希少素材の出現率を上げる（濃霧化）
- 一定区間だけ特定の環境タグを維持する（天候固定）

### 採取・素材

- 素材を採取せずタグだけ抽出する
- 素材の副作用タグを現地で除去する / 地形由来の副作用タグを追加する
- 2つの低品質素材を1つの仮素材へまとめる
- 採取地点へ完成品を設置し帰路で熟成素材を回収する
- 敵を倒さず観察して「行動タグ」を採取する
- 危険な素材を完成品の中へ封じて持ち帰る
- 戦闘で発生した状態を素材として回収する

### 野外錬金

- 工房外で素材1つだけ組み合わせて低品質の一回限り完成品を作る（未完成錬金）
- 材料スロットを1つ省略してランダム副作用を得る（応急調合）
- 地形タグを材料スロットの1つとして扱う（現地代用）
- 携行中の完成品を分解してその場で別系統の仮完成品に変える（解体再錬金）
- 2つの完成品を一時的に束ね両方の副作用を持つ一回限り効果にする（携行品合成）

### 戦闘への接続

- 探索中に設置した罠が戦闘タイムラインへ引き継がれる
- 探索時の手札配置によって初期カウントを調整する
- 奇襲成功時に敵の手札を1枚減らす
- 現地で付けた地形タグが戦闘フィールドに残る
- 探索で救助した生物や装置が一度だけ戦闘に介入する

## 敵ギミック・特殊戦闘

### タイムライン型ボス

- 未来のカウントに攻撃マーカーを置く「予告攻撃」（到達前に避ける・壊す・ずらす）
- 頭・腕・尾などが別々のタイムラインコマとして存在する（部位コマ）
- 弱点部位が毎ラウンド別カウントへ移動する（移動する弱点）
- プレイヤーの待機値を吸収してボスの待機値を減らす（時間捕食）
- 特定カウントを危険地帯または欠番にする（カウント破壊）
- ラウンド終了時に設置物や状態の一部を前ラウンド開始時へ戻す（ラウンド巻き戻し）
- 毎カウント隣へ移動する攻撃領域（時計回り攻撃）
- ラウンドが変わるたびに属性や耐性が変わる（境界形態変化）

### カード型の敵

- 敵の次のカードを表向きにして予告する
- 敵が使ったカードを山札へ「汚染札」として戻す
- 特定スートを使うほど強くなる / 同スートを続けると耐性を獲得する
- プレイヤーの手札枚数を参照して攻撃する
- 山札へ寄生カードを混ぜてくる
- Jokerを食べて形態変化する

### 錬金型の敵

- プレイヤーが発生させた副作用タグを吸収し、一定数集めると新しい技を錬成する
- 自身の部位を素材として分解する / 倒れた雑魚を分解して回復する
- プレイヤーの完成品を一時的に模倣・コピーする
- プレイヤーの携行品を奪い想成を封じる
- 自身に付いた状態を瓶へ回収して投げ返す
- 耐性を素材スロットのように入れ替える

### HP以外の勝利条件

- 敵の身体に指定された4つのタグを揃える
- すべての部位を同じカウントへ集める
- ボスの攻撃マーカーをすべて分解する
- 特定のスート順を完成させる
- ボスが作る完成品を横取りする
- スタンさせた後に捕獲行動を成功させる
- 敵の耐性をすべて瓶へ移す
- ボスを倒さず、界標材料として固定する

## 汎用行動の拡張案（基本行動として追加するもの）

- **設置**：携行品をタイムライン上のオブジェクトにする
- **回収**：設置物を携行枠へ戻す
- **仕込み**：手札1枚を完成品の下に伏せておき、後で使用時に参照する
- **調律**：カードの数字またはスートを変更する
- **受け渡し**：同カウントの味方へ完成品・素材を渡す
- **連携**：同カウントの味方が手札を1枚追加して主行動を強化する
- **待機**：意図的に待機値を増やす代わりにカード・マナ・状態解除などの利益を得る
- **観測**：敵の手札・次の行動・耐性・所持タグなどを一部公開する
- **採取**：戦場の属性・状態・設置物・敵の一部を残滓として回収する
- **解体**：敵の障壁・設置物・地形効果を壊してマナや素材に変える
- **捕獲**：HPを0にする以外の条件（スタン・特定タグ・同カウント拘束）で敵を除去する
- **投棄**：完成品を消費せず放棄して即座に特殊効果を発生させる

## レシピ系統の方向性案

| 系統名 | 操作対象 | 完成品イメージ |
|--------|----------|---------------|
| **時律系** | カウント・待機値・ラウンド | 秒針釘・回帰砂時計・遅効薬・時限爆薬 |
| **界杭系** | タイムライン上の地点・領域 | 反発杭・通過感応糸・守護灯・想成中継鏡 |
| **刻札系** | カードの数字・スート・手札 | 染札インク・封札瓶・予見レンズ・四元素札環 |
| **導脈系** | マナの生成・変換・共有 | 蓄魔槽・属性転換炉・共鳴導線・四相合流器 |
| **幽像系** | 想成の方法そのもの | 投影レンズ・反響鏡・遠隔触媒・二重写しの枠 |
| **封相系** | 状態・耐性・属性フラグ | 毒収瓶・熱封蝋・弱点標本・反射鏡片 |
| **連環系** | タグ同士の反応と副作用 | 連鎖触媒・反応促進液・転嫁針・異相混合皿 |
| **代償系** | HP・カード・未来の手番・品質 | 血燃炉・前借り時計・黒札焼却器・苦痛触媒 |
| **共鳴系** | 味方同士の位置・カード・マナ | 共鳴腕輪・受け渡し糸・肩代わり人形・合奏触媒 |
| **霧航系** | 探索ルート・イベント・帰還 | 霧見鏡・帰路糸・仮設界標・霧圧計 |
| **採譜系** | 敵・地形・現象の情報 | 弱点写し・行動記録針・霧象カメラ・未知相解析器 |
| **誘生系** | 霧域の生物・遭遇 | 誘香餌・捕獲繭・擬態皮膜・霧獣呼笛 |
| **残滓系** | 使用済み完成品・破壊物・戦場の跡 | 灰寄せ箒・空相瓶・残熱坩堝・再生触媒 |
| **界標系** | 霧域の恒久的な変化 | 帰還界標・採取界標・防衛界標・霧晴らし界標 |
